# 概述

本页按 A 股上市公司常见激励方式梳理实施流程：第一类限制性股票、股票期权、第二类限制性股票，以及与股权激励常被并列表述的员工持股计划。这里的“强制性时间”指法律、证监会规则或交易所规则明确给出的期限；“通常办理时间”只是项目排期建议，不构成法定期限。

> 具体项目应以适用板块规则、交易所业务专区要求、中国结算办理口径、公司章程和当期监管问答为准。涉及国资、金融机构、外籍员工、回购股份来源、向特定对象发行股份来源时，通常还需要增加专项核验。
{.is-warning}

# 总体流程

| 阶段 | 主要动作 | 强制性时间 | 通常办理时间 |
|:----|:----|:----|:----|
| 方案筹划 | 明确激励工具、股票来源、激励对象范围、考核指标、会计费用、税务影响和内幕信息知情人管理 | 预留权益应在股东会审议通过后12个月内明确授予对象；超过12个月未明确的，预留权益失效[^csrc-equity] | 2-4周，复杂项目或国资审批项目更长 |
| 董事会审议草案 | 董事会审议计划草案，关联董事回避；薪酬与考核委员会发表意见；同步准备法律意见书、独立财务顾问报告（如需） | 董事会审议通过股权激励计划草案后应及时公告董事会决议、计划草案和薪酬与考核委员会意见[^csrc-equity] | 董事会当日或次一交易日完成公告较常见 |
| 公示与股东会 | 内部公示激励对象名单；披露名单审核及公示说明；召开股东会 | 激励对象姓名和职务内部公示不少于10天；股东会审议前5日披露薪酬与考核委员会对激励名单审核及公示情况的说明；股权激励计划须经出席会议股东所持表决权2/3以上通过[^csrc-equity] | 从草案公告到股东会通常预留3-5周 |
| 授予/授权 | 股东会后召开授予董事会，确认授予条件、授予日、授予对象和数量；办理公告、登记或后续归属安排 | 股权激励计划经股东会审议通过后60日内授予权益并完成公告、登记；有获授权益条件的，自条件成就后60日内完成；不得授出权益的期间不计入60日[^csrc-equity] | 授予董事会与公告1-3个交易日；需登记的通常再预留1-3周 |
| 后续行权/解限/归属 | 每期条件成就时，董事会审议并披露，薪酬与考核委员会和律师发表意见，向交易所和中国结算办理 | 限制性股票授予日至首次解除限售日不少于12个月；股票期权授权日至首次可行权日不少于12个月；每期行权或解除限售时限不少于12个月，单期比例不超过50%[^csrc-equity] | 每期启动前预留2-4周准备审议、公告、申请和登记 |
| 变更、终止、回购注销 | 调整授予价格/数量、作废、注销、回购注销或终止实施 | 股东会审议未通过或终止实施后3个月内不得再次审议股权激励计划；已通过股东会后的激励方案变更或终止一般需再提交股东会审议[^csrc-equity] | 视事项复杂程度预留2-6周 |

# 第一类限制性股票

第一类限制性股票是在授予时即登记到激励对象名下，但在限售期内转让等权利受限的股票。科创板和创业板指南均将其与第二类限制性股票区分：第一类限制性股票侧重“授予登记”，第二类限制性股票侧重满足条件后的“归属登记”。[^sse-kcb-guide][^szse-cyb-guide]

| 步骤 | 办理要点 | 强制性时间 | 通常办理时间 |
|:----|:----|:----|:----|
| 制定方案 | 明确授予价格、股票来源、限售期、解除限售安排、回购条款和绩效考核指标 | 计划有效期自首次授予日起不得超过10年；授予价格应符合《上市公司股权激励管理办法》的定价规则或说明其他定价方法[^csrc-equity] | 2-4周 |
| 草案审议与股东会 | 董事会、薪酬与考核委员会、法律意见书、内部公示、股东会2/3通过 | 公示不少于10天；股东会前5日披露名单审核及公示说明[^csrc-equity] | 3-5周 |
| 授予和登记 | 股东会后董事会确认授予条件，确定授予日并申请交易所确认、中国结算登记 | 股东会通过后60日内完成授予、公告、登记；授予日必须为交易日[^csrc-equity] | 董事会与公告1-3个交易日，缴款/验资/登记通常1-3周 |
| 解除限售 | 每期解除限售前审议条件是否成就，披露董事会决议、薪酬与考核委员会意见和法律意见 | 授予日至首次解除限售日不少于12个月；每期解除限售时限不少于12个月，单期比例不超过50%[^csrc-equity] | 拟解除限售日前2-4周启动 |
| 回购注销 | 条件未成就、离职或终止实施等情形，按计划约定和规则回购注销 | 出现回购情形后应及时召开董事会审议回购方案，并依法提交股东会批准；律师需发表专业意见[^csrc-equity] | 2-6周，涉及减资公告和工商变更时更长 |

# 股票期权

股票期权在授予时登记的是未来按行权价格购买公司股票的权利，不立即取得股票。实务上要提前确定行权方式：自主行权通常需要证券公司、交易系统和中国结算配合；集中行权则按单次或分批行权安排推进。

| 步骤 | 办理要点 | 强制性时间 | 通常办理时间 |
|:----|:----|:----|:----|
| 制定方案 | 明确授权日、可行权日、行权有效期、行权安排、行权价格、注销情形和考核指标 | 行权价格应符合《上市公司股权激励管理办法》定价规则或说明其他定价方法[^csrc-equity] | 2-4周 |
| 草案审议与股东会 | 与限制性股票相同，履行董事会、薪酬与考核委员会、公示、法律意见和股东会程序 | 股东会2/3以上通过；内幕信息知情人在草案公告前6个月买卖公司股票及衍生品种情况应自查[^csrc-equity] | 3-5周 |
| 授权和登记 | 股东会后董事会确认授权条件，确定授权日、授权对象和数量，申请期权登记 | 股东会通过后60日内完成授权、公告、登记；授权日必须为交易日[^csrc-equity] | 授权公告1-3个交易日，期权登记通常1-2周 |
| 行权 | 每期行权前审议行权条件是否成就，披露董事会决议、薪酬与考核委员会意见和法律意见，办理行权登记 | 授权日至首次可行权日不少于12个月；每期行权时限不少于12个月，后一行权期起算日不得早于前一行权期届满日，单期比例不超过50%[^csrc-equity] | 自主行权系统准备通常2-4周；集中行权按批次预留1-3周 |
| 注销 | 未满足行权条件、行权期届满未行权或激励对象不再符合条件时注销对应期权 | 股票期权各行权期结束后，未行权的当期期权应终止行权并及时注销[^csrc-equity] | 1-3周 |

# 第二类限制性股票

第二类限制性股票主要见于科创板、创业板规则体系。其核心差异是：授予时不立即登记股票，激励对象满足归属条件后，公司再将股票登记至激励对象账户；归属日必须为交易日。[^sse-kcb-guide][^szse-cyb-guide]

| 步骤 | 办理要点 | 强制性时间 | 通常办理时间 |
|:----|:----|:----|:----|
| 制定方案 | 除一般股权激励要素外，应写明归属安排、归属条件、归属日、未满足归属条件时的处理方式 | 创业板指南要求计划披露限制性股票的归属安排，并明确公司授予权益和激励对象行使权益的程序[^szse-cyb-guide] | 2-4周 |
| 草案审议与股东会 | 与其他股权激励一致，履行董事会、薪酬与考核委员会、公示、法律意见和股东会程序 | 公示不少于10天，股东会前5日披露审核及公示说明，股东会2/3通过[^csrc-equity] | 3-5周 |
| 授予 | 股东会后董事会确认授予条件，确定授予日、对象、数量和授予价格；不在授予阶段办理股票登记 | 创业板指南明确，授予第二类限制性股票的，应在股东会通过后60日内授出权益并公告；不得授出权益期间不计入60日[^szse-cyb-guide] | 授予董事会与公告1-3个交易日 |
| 归属 | 每个归属期条件成就时，董事会审议归属条件，薪酬与考核委员会和律师发表意见，办理归属登记 | 科创板指南要求公司在第二类限制性股票归属前审议归属条件是否成就，并在激励对象归属后及时履行信息披露义务[^sse-kcb-guide] | 每个归属期前2-4周启动，归属登记通常1-3周 |
| 作废或调整 | 对未满足归属条件、离职或其他不符合计划约定的部分，按计划约定作废或调整 | 计划和公告应披露不符合归属条件的限制性股票处理方式[^szse-cyb-guide] | 1-3周 |

# 员工持股计划

员工持股计划不是《上市公司股权激励管理办法》项下的股票期权或限制性股票，但在实务中常与股权激励并行比较。2025年修订后的员工持股指导意见将资金来源收窄为员工合法薪酬及法律、行政法规允许的其他方式，并要求薪酬与考核委员会或独立董事专门会议发表意见。[^csrc-esop]

| 步骤 | 办理要点 | 强制性时间 | 通常办理时间 |
|:----|:----|:----|:----|
| 员工意见征求 | 通过职工代表大会等组织充分征求员工意见 | 实施员工持股计划前应当通过职工代表大会等组织充分征求员工意见[^csrc-esop] | 1-2周 |
| 董事会审议草案 | 董事会提出员工持股计划草案，薪酬与考核委员会发表意见；如委托管理，同时准备资产管理协议 | 董事会审议通过员工持股计划草案后2个交易日内，应公告董事会决议、草案摘要、薪酬与考核委员会意见及资产管理协议[^csrc-esop] | 董事会当日或次一交易日公告较常见 |
| 股东会审议 | 聘请律师出具法律意见；关联董事、股东按规则回避 | 法律意见书应在召开审议员工持股计划的股东会前公告；股东会决议经出席会议股东所持表决权半数以上通过[^csrc-esop] | 3-5周 |
| 股东会后披露 | 披露经通过的主要条款 | 股东会审议通过员工持股计划后2个交易日内，上市公司应披露员工持股计划的主要条款[^csrc-esop] | 1-2个交易日 |
| 买入或过户 | 根据股票来源完成二级市场购买、回购股份非交易过户、认购向特定对象发行股票或股东赠与等 | 二级市场购买方式应在股东会审议通过后6个月内完成购买，并每月公告一次购买股票的时间、数量、价格、方式等；完成购买或过户后2个交易日内临时公告[^csrc-esop] | 账户/产品/过户准备1-3周；购买期可短可长，但不得超过6个月 |
| 存续与退出 | 锁定期届满后按计划约定处置股份、分配权益或展期/终止 | 每期员工持股计划持股期限不得低于12个月；以向特定对象发行方式实施的不得低于36个月；计划届满前6个月公告到期计划持有的股票数量[^csrc-esop] | 届满前6-9个月开始准备退出或展期安排 |

# 强制性时间清单

| 时间要求 | 适用方式 | 说明 |
|:----|:----|:----|
| 预留权益12个月内明确授予对象 | 限制性股票、股票期权 | 超过12个月未明确激励对象的，预留权益失效[^csrc-equity] |
| 内部公示不少于10天 | 限制性股票、股票期权 | 公示激励对象姓名和职务，且在股东会前完成薪酬与考核委员会审核[^csrc-equity] |
| 股东会前5日披露审核及公示说明 | 限制性股票、股票期权 | 披露薪酬与考核委员会对激励名单审核及公示情况的说明[^csrc-equity] |
| 股东会2/3以上通过 | 限制性股票、股票期权 | 按出席会议股东所持表决权计算，关联股东回避，中小投资者单独计票[^csrc-equity] |
| 股东会通过后60日内授予并完成公告、登记 | 第一类限制性股票、股票期权 | 不得授出权益期间不计入60日；第二类限制性股票在创业板指南下为60日内授出并公告[^csrc-equity][^szse-cyb-guide] |
| 首次解除限售或首次可行权间隔不少于12个月 | 第一类限制性股票、股票期权 | 限制性股票看授予日至首次解除限售日；股票期权看授权日至首次可行权日[^csrc-equity] |
| 每期时限不少于12个月，单期比例不超过50% | 第一类限制性股票、股票期权 | 适用于分期解除限售和分期行权安排[^csrc-equity] |
| 董事会通过员工持股草案后2个交易日内公告 | 员工持股计划 | 公告董事会决议、草案摘要、薪酬与考核委员会意见及资产管理协议[^csrc-esop] |
| 员工持股股东会通过后2个交易日内披露主要条款 | 员工持股计划 | 员工持股计划股东会通过后的专门披露节点[^csrc-esop] |
| 二级市场购买6个月内完成并每月公告进展 | 员工持股计划 | 从股东会审议通过员工持股计划后起算[^csrc-esop] |
| 完成购买或过户后2个交易日内公告 | 员工持股计划 | 披露获得标的股票的时间、数量等情况[^csrc-esop] |
| 持股期限12个月/36个月 | 员工持股计划 | 一般不得低于12个月；以向特定对象发行方式实施的不得低于36个月[^csrc-esop] |
| 届满前6个月公告到期持股数量 | 员工持股计划 | 公告到期计划持有的股票数量[^csrc-esop] |

# 通常排期模板

| 激励方式 | 从启动到股东会 | 股东会后首个实施节点 | 后续周期办理 |
|:----|:----|:----|:----|
| 第一类限制性股票 | 5-9周 | 1-4周完成授予公告、缴款/验资和登记 | 每期解除限售前2-4周启动 |
| 股票期权 | 5-9周 | 1-3周完成授权公告和期权登记 | 行权系统或集中行权安排通常提前2-4周准备 |
| 第二类限制性股票 | 5-9周 | 1-2周完成授予董事会和公告，授予时通常不做股票登记 | 每期归属前2-4周启动，归属登记另预留1-3周 |
| 员工持股计划 | 5-10周 | 股东会后2个交易日披露主要条款；账户、产品、过户或买入准备1-3周 | 二级市场购买最长6个月；届满前6-9个月准备退出、展期或终止 |

# 常见排期风险

1. 股票来源会改变路径。回购股份来源要同时核对回购规则、回购专户、过户安排和三年内转让或注销要求；向特定对象发行股份来源还要叠加再融资或发行登记流程。
2. 板块差异会改变口径。第二类限制性股票主要依据科创板、创业板规则办理，主板项目不应直接套用“归属”流程。
3. 60日期限很容易被禁止交易窗口、监管问询、名单调整、外籍员工证券账户、缴款验资或中国结算材料问题挤压。
4. 员工持股计划若采用二级市场购买，要把6个月购买期限、每月进展公告和内幕信息管理放进交易安排。
5. 国有控股、金融类国有控股、境外员工、持股5%以上股东或实际控制人亲属参与等情形，应在草案前单独做适格性和审批路径核验。
