# 概述
并购 SPV（Special Purpose Vehicle，特殊目的载体）通常指为某一项收购、融资、持股或风险隔离安排而设立或使用的项目公司、合伙企业、资管产品等载体。SPV 不是单独的法定组织形式，具体法律属性取决于其采用的公司、合伙企业、信托、资管计划等结构；公司型 SPV 至少应回到现行公司法判断组织、出资和治理安排。[^company-law]

# 核查要点
- **控制权与合并范围**：确认 SPV 是否被收购方、投资人或管理人控制，以及是否需要纳入合并报表。
- **资金来源与担保**：核查出资、借款、股东借款、并购贷款、差额补足、回购、担保等安排是否触发审批、披露或监管限制。
- **税务与退出**：关注股权转让所得、分红、利息、印花税、增值税以及未来退出路径中的税负和扣缴义务。
- **穿透披露**：证券、基金、国资、外资或反垄断场景下，可能需要穿透识别实际控制人、最终出资人和一致行动关系。

> 本页仅为并购结构核查清单，不构成交易方案建议。具体项目应结合交易文件、监管口径和专业意见判断。
