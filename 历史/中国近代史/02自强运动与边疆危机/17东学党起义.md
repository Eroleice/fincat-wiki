# 摘要

东学党起义，又称东学农民运动，是 1894 年朝鲜爆发的大规模农民和宗教社会运动。它以反地方贪腐、反苛政、反外来压力和东学信仰组织为基础，迅速冲击朝鲜王朝地方秩序。朝鲜政府请求清朝出兵协助平乱，日本随即以 1885 年中日天津约定为依据派兵入朝；清日双方出兵后，日本拒绝共同撤军并强行推进朝鲜改革和军事控制，局势最终滑向甲午战争。[^paine][^seth]

东学党起义的意义，不只是“甲午战争导火线”。它首先是朝鲜社会内部矛盾的爆发，其次才是清日竞争的触发点。若忽视朝鲜农民、东学组织和地方政治，就会把它误写成中日外交的附属事件；若忽视清日竞争，又无法解释为何一场朝鲜内乱会迅速变成东亚战争。[^schmid][^lee]

# 背景

东学由崔济愚在 19 世纪中叶创立，带有宗教、伦理和反外来压力的色彩。朝鲜王朝长期把东学视为可能挑战正统和地方秩序的力量，但东学在基层社会中持续传播。[^lee][^seth]

19 世纪后半期，朝鲜社会承受沉重压力：地方官贪腐、税负和杂役、军制矛盾、米价与贸易冲击、开港后外来势力进入，以及王朝内部派系斗争。农民不满不仅针对地方官，也与更大的国家危机和外部压力相连。

清日竞争则使朝鲜内乱具有国际后果。1885 年天津约定使清日双方都保留了在朝鲜危机中派兵的可能。到 1894 年，东学党起义为双方出兵提供了现实契机。[^paine]

# 直接原因

第一，全罗道地方官贪腐和苛政激化民怨，东学信众和农民组织起来反抗地方行政。全琫准等人成为起义的重要领导者。[^seth]

第二，朝鲜王朝地方治理和中央财政无法有效安抚基层社会。农民诉求从惩办贪官扩大到反对腐败、减轻负担和抵制外来压迫。

第三，朝鲜政府面对起义扩展，请求清朝派兵协助。清朝按宗藩关系和天津约定出兵并通知日本，日本也派兵入朝，使内乱立即国际化。[^paine]

# 根本原因

根本原因在于朝鲜王朝的社会和国家危机积累已久。地方官僚腐败、财政压力、土地和税役矛盾，使农民对王朝基层治理失去信任。东学提供了组织、信仰和共同语言，使分散不满得以动员。

另一个根本原因是朝鲜处在帝国竞争交汇处。清朝、日本和列强都把朝鲜视为战略空间，朝鲜内部改革和社会调整难以在相对自主的环境中完成。外部压力越强，内部矛盾越容易被国际化。

# 经过

1894 年初，朝鲜全罗道一带民变扩大，东学农民军在全琫准等人领导下迅速发展。起义军提出惩治贪官、减轻民困和抵制外来压力等诉求，获得大量农民响应。

起义军在春夏间取得一系列胜利，并进入全州。朝鲜政府一方面试图镇压，一方面与起义军谈判，形成暂时停战和改革承诺。但王朝对局势缺乏足够控制，仍向清朝请求援助。[^seth][^lee]

清政府派兵进入朝鲜，并按 1885 年约定通知日本。日本随即出兵，并迅速把目标从保护侨民和应对内乱扩大为控制朝鲜政局。清日双方在朝鲜半岛形成军事对峙。

即使东学农民军一度与政府达成妥协，清日军队仍未随之撤出。日本要求朝鲜改革并排除清朝影响，随后控制汉城王宫，清日冲突由外交争执转向军事对抗。1894 年夏，甲午战争爆发。

# 结果

最直接的结果，是朝鲜内乱引发清日同时出兵。起义本身一度通过谈判降温，但外部军队进入后，危机不再由朝鲜政府和农民军单独决定。

第二个结果，是日本利用出兵机会控制朝鲜政局，要求改革并排除清朝影响。清朝试图维护宗藩关系，日本则以朝鲜独立和改革为名推进自身优势。

第三个结果，是甲午战争爆发。东学党起义不是战争的唯一原因，却是把长期清日竞争转化为军事冲突的直接触发点。[^paine]

# 影响

对朝鲜而言，东学党起义显示基层社会已无法承受旧有治理方式。农民军的诉求虽未完全实现，却推动朝鲜改革和社会危机进入更公开阶段。

对中国而言，起义使清朝宗藩政策接受最后检验。清政府仍把援朝视为维护传统秩序和东北安全，但面对日本近代国家动员时，传统宗藩框架已经难以维持。

对东亚而言，东学党起义把朝鲜内部社会危机、清日战略竞争和近代国际秩序连接起来，成为甲午战争前夜最关键的转折。

# 历史评价

评价东学党起义，首先要承认它的朝鲜社会史意义。它不是清日战争的背景板，而是朝鲜农民、宗教组织和地方社会对腐败、贫困和外来压力的集体反应。

其次，它确实具有东亚国际政治意义。清日双方出兵说明朝鲜已经成为两种秩序的碰撞点：清朝宗藩秩序、日本明治扩张和近代条约外交在这里正面冲突。

最后，东学党起义揭示了一个近代东亚的共同困境：内部改革若被外部竞争强行包围，社会运动很容易从民生和政治诉求转化为国际战争导火线。

# 与前后事件的关系

它上承甲午战争前朝鲜问题。江华条约、壬午兵变、甲申政变和天津约定，都让朝鲜内政与清日竞争越来越难分开。

它下启甲午战争。清日以东学党起义为出兵契机，但真正爆发战争的原因，是双方对朝鲜地位、东亚秩序和区域霸权的根本冲突。东学党起义因此是第二阶段的终点事件，也是下一阶段“甲午失败到辛亥革命”的开端前奏。
