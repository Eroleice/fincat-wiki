# 摘要

轮船招商局是李鸿章支持创办的官督商办航运企业，1872 年筹设，1873 年正式营业，是洋务运动从“自强”转向“求富”的代表事业之一。它试图用中国资本和中国船队参与长江、沿海和漕粮运输竞争，减少外国轮船公司对航运利润的垄断。[^feuerwerker][^hsu]

**关键词**：轮船招商局、李鸿章、官督商办、唐廷枢、徐润、盛宣怀、航运、求富、洋务运动。

# 背景

19 世纪中后期，通商口岸和长江航运迅速发展，外国轮船公司依靠资本、技术、保险、航线和条约优势，在中国沿海和内河运输中占据重要地位。清政府既担心航运利润外流，也担心军需、漕粮和沿海交通受制于人。[^spence][^feuerwerker]

洋务派最初强调军工“自强”，但很快意识到军工、海防和赔款都需要财政支撑。由此，“求富”成为洋务运动的重要方向，轮船招商局就是这一转向的标志性企业。

# 直接原因

直接原因是争夺航运和漕运。李鸿章希望通过招商集股、官府保护和商人经营，建立中国自己的轮船公司，与外国航运企业竞争，并承担部分政府运输任务。[^feuerwerker]

另一个原因是洋务事业需要商业收入。军工厂和海防建设长期消耗财政，洋务派希望通过航运、矿务、电报等企业积累资本，反过来支持国家建设。

# 根本原因

轮船招商局的根本原因，是晚清在条约口岸经济中尝试重建经济主权和财政能力。外商企业已经进入航运、金融和贸易网络，清政府若完全依赖外商运输，不仅利润外流，也会削弱战略机动和海防能力。

但它采用官督商办模式，说明晚清仍缺乏现代企业制度和清晰产权环境。官府保护能够帮助企业起步，也容易带来行政干预、人事依附和经营效率问题。

# 经过

轮船招商局在李鸿章支持下筹设，由唐廷枢、徐润等买办和绅商参与经营，后来盛宣怀也在洋务企业网络中发挥重要作用。企业以招集商股、购买或经营轮船、承运漕粮和开辟航线为主要业务。[^feuerwerker]

招商局在与外国轮船公司竞争中曾取得一定成绩，并通过兼并、降价、航线调整和政府运输合同扩大影响。它也成为晚清官督商办企业的样板，影响矿务、电报、纺织等后续事业。

同时，招商局长期处在官府控制与商业经营之间。资本募集、利润分配、人事任用和政策保护都带有官商混合色彩，这既是它能够成立的条件，也是后来治理困难的来源。

# 结果

轮船招商局使中国资本进入近代轮船航运领域，在长江和沿海运输中形成一定竞争力。它也为晚清官督商办企业提供了组织经验。

但招商局没有摆脱官僚控制和制度不稳。它既要承担政府任务，又要追求商业利润；既依赖官府保护，又需要商股和市场经营。这种双重身份使其效率和治理长期受限。

# 影响

对国家而言，轮船招商局把洋务运动从军工扩展到商业和交通领域，显示晚清已经意识到经济能力与国防能力相互支撑。

对人民和社会而言，它带来近代船员、职员、股东和航运服务，也改变了长江与沿海交通结构。但普通商民能否从中受益，取决于运价、竞争、官府保护和地方市场环境。

对近代企业史而言，招商局是官督商办模式的典型。它证明中国商人和官员能够组织近代企业，也暴露了产权不清、行政干预和资本市场不足的难题。[^feuerwerker]

# 历史评价

轮船招商局的积极意义在于，它让中国在近代航运领域拥有自己的企业和船队，并把“求富”纳入洋务运动。

它的局限在于，官督商办没有真正建立现代公司治理。企业既不是纯粹官办，也不是完全商办，因而容易在公共目标、官员权力和商业利润之间摇摆。

# 与前后事件的关系

轮船招商局上承[洋务运动](/历史/中国近代史/02自强运动与边疆危机/03洋务运动)的军事自强，下启矿务、电报、纺织和铁路等“求富”事业。

它与江南制造总局、福州船政局不同，重点不在造武器或造船，而在经营航运和积累资本；这说明洋务运动已经从单纯军事技术扩展到经济组织和市场竞争。
