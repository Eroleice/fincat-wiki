# 摘要

派遣留美幼童是清政府在 1872 年至 1875 年分批派出少年赴美国学习的教育计划，总人数通常记为 120 人。计划由容闳倡议并推动，得到曾国藩、李鸿章等洋务官员支持，后来因政治疑虑、文化冲突和美国军校限制等原因，于 1881 年被提前撤回。[^yung][^rhoads]

**关键词**：留美幼童、容闳、曾国藩、李鸿章、陈兰彬、詹天佑、唐绍仪、近代留学、洋务教育。

# 背景

洋务运动需要翻译、工程、矿务、铁路、海军、外交和机器制造人才。传统科举以经义文章为中心，难以培养近代技术和外语人才。同文馆、船政学堂等新式机构虽已出现，但规模有限。[^biggerstaff][^hsu]

容闳早年留学美国，深知西式教育对技术和制度知识的重要性。他主张由国家选派少年赴美长期学习，再回国服务洋务事业。

# 直接原因

直接原因是洋务事业的人才短缺。仅靠聘请外籍技师和短期翻译，无法建立中国自己的技术队伍。派遣幼童留学，是为了从少年阶段培养能够掌握外语、科学和工程知识的人才。[^yung]

曾国藩、李鸿章等洋务官员支持该计划，也与他们办理军工、船政和外交事务时感到人才不足有关。

# 根本原因

根本原因是晚清教育体系与近代国家需求脱节。清朝需要工程师、外交官、翻译、海军军官和铁路矿务人才，但科举制度仍以传统经典和八股文为主要通道。

留美幼童计划体现了洋务派的一种突破：在不全面改革科举的前提下，另开一条小规模、精英化、国家资助的留学路径。这也决定了它的政治风险很高，容易遭遇保守力量质疑。

# 经过

1872 年起，清政府分批派遣幼童赴美学习，由容闳等人参与组织管理，学生在美国寄宿家庭和学校中接受教育。计划原本希望学生完成较长时间学习后进入更高层次专业训练。[^rhoads]

在学习过程中，学生迅速适应英语和美国学校生活，也逐渐接触西式服饰、体育、社交和宗教环境。这些变化引起清廷和部分官员担忧，认为学生可能偏离传统礼制和政治忠诚。

美国方面对中国学生进入军事院校也有限制，加上清廷内部反对声音增强，计划在 1881 年被提前撤回。许多学生尚未完成完整学业。

# 结果

留美幼童计划提前撤回，未能按原设想完成长期教育。但回国学生中仍有多人进入铁路、矿务、外交、海关、海军和教育领域，成为晚清近代人才的重要来源。詹天佑、唐绍仪、梁诚等人常被视为这一群体的代表。[^rhoads]

计划失败的直接表象是撤回，深层结果则是暴露清廷既需要西学人才、又害怕西学改变政治和文化秩序的矛盾。

# 影响

对国家而言，留美幼童计划是中国近代国家派遣留学生的重要起点。它说明晚清已经认识到人才培养不能只依赖外籍顾问。

对学生和社会而言，这一计划创造了新的身份类型：既受传统国家资助，又接受西式教育的近代知识和技术人才。他们回国后常在旧官僚体制和新技术事务之间穿行。

对教育制度而言，留美幼童计划证明小规模留学可以培养人才，但也说明没有国内制度接纳和政治信任，海外教育成果很难充分释放。

# 历史评价

留美幼童计划的积极意义很突出：它突破传统科举视野，把现代科学、工程和外语教育直接连接到国家建设。

它的局限也很典型：规模小、政治信任不足、管理目标摇摆，且没有与国内教育和任用制度形成稳定衔接。提前撤回不是偶然失误，而是洋务运动制度边界的体现。

# 与前后事件的关系

留美幼童计划上承[同文馆](/历史/中国近代史/02自强运动与边疆危机/09同文馆)和洋务教育，下接晚清更大规模的留学日本、欧美以及清末新政教育改革。

它与江南制造总局、福州船政局、轮船招商局共同说明：洋务运动不仅需要机器和企业，更需要能够理解和操作这些制度、技术的人。
