# 摘要

台湾建省，是晚清在 1874 年日本侵台和 1884-1885 年中法战争后强化东南海疆治理的重要举措。清廷于 1885 年议准台湾建省，行政上逐步从福建省分出，至 1887 年前后完成较明确的省制安排，并以刘铭传为台湾巡抚。它标志清政府不再只把台湾视为福建海外府属和移垦边地，而是把台湾提升为海防、财政、交通和近代行政建设的前沿。[^davidson][^chu-liu]

台湾建省的意义，既在于海疆地位上升，也在于晚清试图以铁路、电报、矿务、邮政、军防和行政区划调整推动地方现代化。其局限同样明显：经费不足、地方社会复杂、中央支持不稳，使刘铭传改革难以长期持续。[^fairbank][^spence]

# 背景

清朝对台湾的治理长期带有边疆性质。台湾原属福建行政体系，地方社会由汉人移民、原住民社群、地方豪强、商贸网络和山地边界共同构成。清廷既担心地方失控，又长期投入有限。[^davidson]

1874 年日本以琉球漂民事件为由出兵台湾，清政府通过交涉解决危机，却看见日本已能把台湾问题国际化。此后沈葆桢赴台办理善后，推动设防、开山抚番和行政强化。台湾不再只是地方治安问题，而成为海疆主权问题。

中法战争进一步放大台湾的重要性。法军攻击基隆、淡水并占领澎湖，说明台湾位于东南海防要冲，一旦失守，福建、广东、东海和南海交通都会受影响。台湾建省正是在这种海防压力下被提上日程。

# 直接原因

第一，日本侵台和法国攻台接连发生，证明台湾在列强和周边国家眼中具有战略价值。清廷若继续以福建遥领方式治理台湾，很难快速应对海上危机。

第二，中法战争后，台湾防务、港口、煤矿、电报和军队调度的重要性上升，需要更高层级行政机构统筹。

第三，刘铭传等官员推动以建省方式强化台湾治理。建省不仅是名义升格，也意味着巡抚、布政、财政和地方建设可以更直接地围绕台湾展开。[^chu-liu]

# 根本原因

根本原因在于晚清海疆观念发生变化。鸦片战争以后，沿海口岸和海军问题已经成为国家安全核心；到中法战争后，台湾这样的岛屿边疆更被视为主权和海防前哨。传统“海外府属”的治理方式，难以应对近代舰队、殖民扩张和国际法竞争。

另一个根本原因是国家整合边疆的方式改变。清朝在新疆建省、台湾建省中都表现出同一趋势：把原本较边缘、军事化或府属化的空间，纳入更明确的省制行政，以便加强财政、军政和交通控制。

# 经过

1874 年日本侵台后，沈葆桢赴台办理防务和善后，推动炮台、道路、开山、行政调整和海防建设。虽然这些措施有限，却为后来建省提供了问题意识和初步经验。[^davidson]

1884-1885 年中法战争期间，台湾成为重要战场。法军进攻基隆，在淡水受挫，并占领澎湖。台湾军民和清军防守使法军未能轻易控制全岛，但清廷也清楚看到台湾防务若无更高行政支撑，难以长期维持。

1885 年，清廷议准台湾建省。此后台湾从福建行政体系中逐步分出，刘铭传出任台湾巡抚，推动铁路、电报、邮政、矿务、军防、财政和行政区划调整。Davidson 对晚清台湾史的叙述中，把刘铭传时期视为台湾近代化建设的重要阶段。[^davidson]

1887 年前后，台湾省制安排更趋明确。建省并不意味着台湾马上拥有充足财政和稳定制度，许多建设仍依赖刘铭传个人推动、中央拨款和地方税收。

# 结果

最直接的结果，是台湾从福建遥领格局转向省级行政。巡抚、布政和地方行政体系围绕台湾重组，台湾在清朝边疆治理中的地位明显上升。

第二个结果，是刘铭传时期出现一批近代化建设。铁路、电报、煤矿、邮政、军防和行政区划调整，使台湾成为晚清地方新政较集中的试验场之一。[^chu-liu]

第三个结果，是清廷对海疆的认识更具体。台湾建省与北洋海军建设、沿海炮台和船政调整共同说明，晚清已经把海防视为国家安全重点。

# 影响

对国家而言，台湾建省强化了东南海疆治理，显示清政府试图把边疆岛屿纳入更紧密的行政体系。它是晚清海防意识上升的制度化表现。

对人民而言，建省和刘铭传改革带来道路、通信、税制、军防和行政变化，也带来征发、税负、土地与族群关系调整。近代化建设并非只有便利，也会改变地方社会权力结构。

对经济社会而言，铁路、电报和矿务有助于台湾市场与行政整合，但规模和持续性受财政限制。刘铭传离任后，不少建设难以保持同等推进速度。

# 历史评价

台湾建省的积极意义，在于清政府终于把台湾放到国家海防和行政整合的核心位置。面对日本和法国压力，建省是维护主权和提升治理能力的必要回应。

它的局限，在于建省来得较晚，且缺少稳定财政和制度支持。清朝能在危机后提升台湾地位，却未能在甲午战争前建立足以保障台湾长期安全的海军、陆防和财政体系。1895 年台湾割让，反过来显示建省的方向正确但支撑不足。

# 与前后事件的关系

台湾建省上承日本侵台、中法战争和海防与塞防之争。它是海防压力在行政制度上的回应。

它下接北洋海军成军和甲午战争前夜。台湾建省说明清朝已认识到海疆重要性；但甲午战争后的台湾割让说明，仅靠行政升格而没有完整国防和外交能力，仍不足以保住海疆成果。
