# 摘要

左宗棠收复新疆，是清政府在 19 世纪 70 年代重新整合西北边疆的关键事件。新疆在同治年间长期动荡，阿古柏势力控制天山南路，俄国又于 1871 年占据伊犁。清廷在海防与塞防之争后支持左宗棠督办新疆军务，清军于 1876 年以后分路推进，至 1878 年基本恢复新疆大部控制；随后又通过外交交涉，于 1881 年《中俄伊犁条约》后收回伊犁大部，并在 1884 年建立新疆省。[^hsu-ili][^millward]

这一事件的意义，不只在军事胜利。它说明晚清虽然整体衰弱，仍能在特定条件下通过地方军、筹饷、近代军械、后勤转运和外交交涉维护国家统一；但它也暴露出边疆治理必须从军府驻防走向更明确的省制行政、财政和社会整合。[^kim][^spence]

# 背景

乾隆以后，新疆被纳入清朝版图，治理依靠伊犁将军、驻防、伯克制度、卡伦、驿道和地方族群关系共同维系。到 19 世纪中叶，清朝内地战乱、财政枯竭、回民起事和中亚局势变化叠加，新疆旧有治理结构迅速失衡。[^millward][^kim]

阿古柏原与浩罕势力有关，后来在新疆南部建立割据政权，并试图通过中亚、英国和俄国之间的关系获得外部承认。与此同时，俄国以边境安全和贸易为由占据伊犁，使新疆问题从内部平乱变成中俄外交和中亚大国竞争的一部分。[^hsu-ili][^millward]

左宗棠在陕甘战事后具备较强西北军务经验。他主张新疆不可放弃，并把恢复新疆视为保卫蒙古、甘肃和京师西北屏障的关键。清廷最终支持其方案，说明塞防路线在国家统一和边疆安全层面获得认可。

# 直接原因

第一，阿古柏势力在新疆长期存在，已经威胁清朝对西北边疆的实际控制。若清政府继续迟疑，割据状态可能被外部力量承认为事实。

第二，俄国占据伊犁，使清廷意识到新疆问题若不处理，西北边界会继续被压缩。军事收复新疆与外交解决伊犁问题相互关联，前者为后者提供筹码。[^hsu-ili]

第三，海防与塞防之争后，清廷决定不放弃新疆，并任命左宗棠督办军务。中央授权、地方筹饷和西北军队准备，构成西征的直接政治条件。

# 根本原因

根本原因在于清朝必须把新疆从传统边疆驻防空间，重新纳入近代国家主权和行政控制框架。19 世纪中叶以后，边疆已不是模糊缓冲地带：俄国的边界、领事、贸易和军事推进，阿古柏的割据外交，都迫使清朝以更明确的军事和行政方式回应。

国家能力也是根本原因。新疆距离内地财赋中心遥远，战事需要粮饷、驼马、道路、军械、地方协作和长期治理安排。左宗棠收复新疆之所以重要，正因为它不仅是前线作战，也是晚清国家在极端困难条件下重新组织后勤与边疆行政的尝试。[^kim][^spence]

# 经过

左宗棠首先在西北进行较长时间准备，包括整顿军队、筹措粮饷、购置枪炮、修路设台和安排转运。与鸦片战争中临时防守不同，西征需要跨越辽阔内陆，后勤比单场战斗更决定成败。

1876 年以后，清军由甘肃、新疆东部逐步推进。刘锦棠等将领率军进入新疆，先恢复天山北路和吐鲁番、乌鲁木齐等要地，再向南疆推进。阿古柏势力在军事压力和内部不稳中瓦解，阿古柏本人于 1877 年死亡，清军随后继续收复喀什噶尔、叶尔羌等地。[^millward][^kim]

至 1878 年，清政府基本恢复新疆大部控制。军事胜利并未立即解决全部问题：伊犁仍由俄国占据，地方社会也需要重建秩序。此后清廷通过中俄谈判处理伊犁问题，1881 年《中俄伊犁条约》后收回伊犁大部，但也付出赔款和部分边境、贸易让步。[^hsu-ili]

1884 年，新疆正式建省。建省意味着清廷不再只把新疆视为军府和驻防边地，而是试图以省制、巡抚、州县、财政和移民垦殖等方式纳入全国行政体系。[^millward]

# 结果

最直接的结果，是清政府恢复新疆大部控制，阿古柏割据政权瓦解。清朝避免了新疆长期脱离中央控制，也为后来处理伊犁交涉争取了更有利的位置。

第二个结果，是伊犁问题通过外交谈判解决。清朝收回伊犁大部，但付出赔款和若干权益让步，说明军事胜利并不等于外交完全主动；近代边疆问题必须同时在战场和谈判桌上处理。[^hsu-ili]

第三个结果，是新疆建省。省制化使新疆从传统军府边疆转向更常规的行政区划，强化了国家对西北的制度性整合，也为后来的边疆治理提供基础。[^millward]

# 影响

对国家而言，收复新疆维护了西北边疆完整，遏止了俄国和中亚势力进一步扩大影响。它证明晚清仍具有一定军事与行政恢复能力。

对人民而言，战争结束了长期割据和战乱的一部分，但也带来军费、征发、迁徙、重建和新行政体系的压力。新疆地方社会的秩序重建，并不是军事胜利后自动完成的。

对边疆治理而言，收复新疆推动清政府从“驻防守边”转向“建省治边”。这改变了新疆在中国国家结构中的位置，也使边疆行政、交通、财政和族群关系成为更长期的治理议题。

# 历史评价

左宗棠收复新疆的积极意义非常明确：它维护了国家统一和西北边疆安全，在晚清多重危机中表现出少见的战略坚持和组织能力。

但也应看到，它不是一场单纯依靠个人英雄主义完成的胜利。其背后有陕甘战后军队基础、各省筹饷、洋务军械、后勤转运和清廷授权。它的局限也在于，清朝虽能完成局部军事整合，却仍未建立足以长期支撑全国边防的现代财政和军政制度。

# 与前后事件的关系

它上承海防与塞防之争。正是因为清廷没有放弃塞防，左宗棠西征才获得政治和资源支持。

它下启新疆建省和晚清边疆行政重组。新疆收复后，清政府必须回答如何长期治理、如何面对俄国、如何整合地方社会的问题。与台湾建省、北洋海军建设并看，收复新疆说明晚清自强运动的主线不仅是机器和舰船，也是主权边疆的制度化维护。
