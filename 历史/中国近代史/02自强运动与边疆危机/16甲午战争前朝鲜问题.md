# 摘要

甲午战争前朝鲜问题，是指 1870 年代至 1894 年间，朝鲜王朝在清朝传统宗藩关系、日本明治扩张、朝鲜内部改革与保守冲突、俄英等列强关注和民众危机之间，逐渐成为东亚战争焦点的过程。1876 年《江华条约》打开日本进入朝鲜的通道，1882 年壬午兵变和 1884 年甲申政变使清日竞争加深，1885 年《天津会议专条》规定两国向朝鲜派兵需互相通知，却也把清日干预朝鲜的可能性制度化。[^paine][^conroy]

这一问题的关键，不是朝鲜被动地“引发”甲午战争，而是朝鲜自身危机与清日两国东亚秩序竞争交织。清朝仍试图以宗藩和驻朝影响维护东北门户，日本则把朝鲜视为明治国家安全和扩张的核心方向。到东学党起义时，朝鲜问题已经成为清日开战的最易燃引线。[^schmid][^seth]

# 背景

朝鲜长期处于以清朝为中心的东亚宗藩秩序中，同时保持自身王朝国家结构。19 世纪后半期，西方列强、日本和俄国进入东北亚，传统宗藩秩序开始受到近代条约体系冲击。[^schmid]

日本明治维新后，迅速把朝鲜视为战略方向。1876 年，日本以武力压力迫使朝鲜签订《江华条约》，朝鲜由此向日本开放口岸并进入近代条约关系。对清朝而言，这意味着朝鲜不再只是传统藩属，而成为清日竞争和列强外交的前沿。[^conroy][^seth]

朝鲜内部也有深刻危机。财政困难、官僚腐败、军制矛盾、开化派与守旧派冲突、农民负担和外来压力交织，使朝鲜政治不断震荡。清日之争并不是外部力量凭空制造的，它利用并加剧了朝鲜内部矛盾。

# 直接原因

第一，1876 年后日本在朝鲜获得条约权利，挑战清朝传统宗藩影响。清政府不得不更直接地处理朝鲜外交与内政危机。

第二，1882 年壬午兵变后，清军进入朝鲜并加强影响，袁世凯等人在朝鲜事务中扮演重要角色。日本也因使馆和侨民受损要求赔偿与驻兵，清日竞争进一步制度化。[^paine]

第三，1884 年甲申政变中，朝鲜开化派在日本支持下试图夺权，清军介入后政变失败。清日为避免立即开战，于 1885 年达成《天津会议专条》，约定双方撤兵，并在将来向朝鲜派兵时互相通知。这个安排表面上降低危机，实际使双方都保留了再度介入朝鲜的权利。[^paine][^conroy]

# 根本原因

根本原因在于东亚区域秩序正在转换。清朝仍把朝鲜视为藩属和东北屏障，日本则以近代国家战略和国际法语言要求朝鲜“独立”于清朝影响，同时扩大自身控制。所谓“朝鲜独立”在日本政策中常与排除清朝、建立日本优势相连。[^schmid]

朝鲜内部国家能力不足也是根本原因。王朝财政、军队、地方治理和社会整合无法有效缓解农民负担和政治冲突，使外部力量有机会借助派系和危机介入。

清朝的制度迟滞同样关键。清廷试图用宗藩关系和驻朝代表维持影响，却缺乏一套适应近代国际法、条约外交和军事动员的朝鲜政策。日本则以更统一的国家战略推进，双方差距逐渐扩大。[^paine]

# 经过

1876 年《江华条约》后，日本在朝鲜取得通商和外交入口。朝鲜开港使日本商人、外交官和军事压力进入半岛，也促使清朝更关注朝鲜事务。

1882 年壬午兵变爆发，朝鲜旧式军人和民众不满薪饷、军制和外来影响，攻击日本使馆并冲击朝鲜政局。清朝派兵入朝，帮助朝鲜王室恢复秩序，并把大院君带往中国。此后清朝在朝鲜影响上升，袁世凯等人长期参与朝鲜事务。[^seth][^paine]

1884 年甲申政变中，金玉均等开化派在日本支持下发动政变，试图建立亲日改革政府。清军介入后政变失败，日本在朝鲜的直接政治推进受挫，但清日矛盾更加尖锐。[^conroy]

1885 年，李鸿章与伊藤博文在天津达成协议，双方撤出驻朝军队，并约定未来如向朝鲜派兵，须互相行文通知。这个协议避免了当时战争，却为 1894 年双方以“按约通知”为名出兵留下制度路径。[^paine]

1885-1894 年间，朝鲜仍在清日影响、内部派系和社会危机中震荡。袁世凯代表清朝在汉城维持影响，日本则继续等待机会扩大优势。东学党起义爆发后，朝鲜政府请求清朝援助，日本随即以天津约定为依据派兵，局势迅速滑向战争。

# 结果

最直接的结果，是朝鲜从传统宗藩秩序中的藩属，转变为清日共同竞争和列强关注的战略焦点。

第二个结果，是清日双方都保留了介入朝鲜的机制。1885 年天津约定暂时降温，却让未来派兵通知成为可能，危机并未消除。

第三个结果，是朝鲜内部改革问题被外部竞争扭曲。开化派、保守派、王室和农民运动都不得不在清日压力下行动，国家自主改革空间不断缩小。

# 影响

对国家而言，朝鲜问题关系清朝东北门户和东亚秩序。清政府若失去朝鲜影响，辽东和直隶海防压力会明显上升。

对朝鲜人民而言，外部竞争加重内部危机。农民负担、腐败、军制不公和外来经济压力最终汇入东学党起义。

对东亚秩序而言，朝鲜问题使传统宗藩关系、近代条约外交和日本帝国扩张正面碰撞。甲午战争的导火线在 1894 年点燃，但火药早已在此前十多年积累。

# 历史评价

甲午战争前朝鲜问题说明，晚清的边疆危机已从新疆、台湾、越南延伸到东北亚藩属秩序。清朝并非没有维护朝鲜的意愿，却仍以宗藩和地方化外交方式处理近代国家竞争。

日本对朝政策的扩张性也十分明显。它以朝鲜独立和改革为名，实质上不断排除清朝影响，最终把朝鲜纳入自身战略空间。

同时，朝鲜不是被动背景。朝鲜王朝的内部矛盾、改革失败和农民起义，都是导致危机升级的重要因素。把甲午战争前朝鲜问题只写成“中日争夺”，会遮蔽朝鲜社会自身的历史能动性。

# 与前后事件的关系

它上承明治日本扩张、清朝自强运动和东亚宗藩秩序动摇。日本在琉球、台湾、朝鲜方向的行动，逐步压缩清朝周边空间。

它下启东学党起义和甲午战争。东学党起义使朝鲜内部危机转化为清日出兵，天津约定则为双方派兵提供外交说辞。朝鲜问题由此成为第二阶段通向甲午战争的关键桥梁。
