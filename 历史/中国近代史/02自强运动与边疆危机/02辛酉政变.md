# 摘要

辛酉政变发生于 1861 年，是咸丰帝去世后两宫太后与恭亲王奕訢联合清除顾命八大臣、重组晚清中枢权力的宫廷政变。政变后，慈安太后、慈禧太后垂帘听政，恭亲王奕訢进入权力核心，同治朝政治格局由此形成。[^wright][^rowe]

**关键词**：辛酉政变、咸丰帝、慈禧太后、慈安太后、恭亲王奕訢、肃顺、同治中兴、垂帘听政、洋务运动。

# 背景

第二次鸦片战争重创清廷威望。英法联军攻入北京，咸丰帝避往热河，清政府在外战、内乱和财政压力中陷入中枢失序。1861 年咸丰帝去世，幼帝继位，政权交接立即成为各派争夺核心。[^spence][^hsu]

咸丰帝临终安排肃顺、载垣、端华等顾命大臣辅政，但两宫太后掌握皇帝名义和宫廷印信，恭亲王奕訢又在北京处理战后交涉并拥有现实政治资源。顾命大臣与两宫、奕訢之间的权力冲突迅速激化。

# 直接原因

直接原因是幼帝继位后的辅政权归属。顾命大臣试图控制朝政，两宫太后和奕訢则不愿被排除在核心决策之外。围绕诏书、印信、护送梓宫回京和人事安排的冲突，最终演变为政变。[^wright]

另一直接原因是战后危机需要新的中枢组合。清廷必须同时处理太平天国、捻军、赔款、外国公使驻京和地方督抚坐大的问题，单靠热河顾命集团难以获得足够政治支持。

# 根本原因

辛酉政变的根本原因，是晚清皇权继承机制与现实政治危机之间的矛盾。幼帝继位使宫廷权力出现真空，而外战失败和内乱又要求中枢迅速重建决策能力。

从制度上看，清朝没有稳定的摄政和内阁责任机制。皇帝年幼时，太后、宗室、军机大臣、顾命大臣和地方督抚之间只能通过宫廷联盟和权力斗争重新分配权力。辛酉政变正是这种制度缺口的集中表现。

# 经过

咸丰帝在热河去世后，顾命大臣奉遗诏辅政，年幼的载淳继位，原拟年号“祺祥”。两宫太后与恭亲王奕訢在回京和发布谕旨过程中形成联盟。

政变关键发生在灵柩回京前后。两宫太后和奕訢借皇帝名义下令逮捕肃顺等人，载垣、端华被赐死，肃顺被处决，顾命集团瓦解。随后年号改为“同治”，两宫太后垂帘听政，恭亲王奕訢被授予重要权力。[^rowe][^wright]

政变没有改变清朝皇权体制本身，却改变了晚清中枢的实际运行方式：太后、宗室亲王、军机处、总理衙门和地方督抚共同构成新的政治格局。

# 结果

辛酉政变确立了两宫太后垂帘听政和恭亲王奕訢参与中枢的格局。顾命八大臣被清除，年号由“祺祥”改为“同治”，同治朝政治由此展开。[^wright]

短期看，政变结束了咸丰死后的中枢内斗，使清廷能够集中处理内战、外交和战后重建。长期看，它也确立了慈禧太后持续干预最高政治的基础。

# 影响

对国家而言，辛酉政变为“同治中兴”和洋务运动提供了政治空间。奕訢、文祥、曾国藩、李鸿章、左宗棠等人能够在镇压内乱、办理外交和兴办军工方面获得一定支持。[^wright][^fairbank]

对人民而言，政变本身是宫廷权力斗争，但其后续政策影响了战后重建、地方秩序、军费筹措和洋务企业。普通民众更多是这些政策成本和秩序恢复的承受者。

对制度而言，政变没有产生现代政治责任机制，而是通过宫廷联盟解决继承危机。它使晚清获得一段有限稳定，却也让最高权力长期依赖非制度化的太后垂帘和亲王辅政。

# 历史评价

辛酉政变不能只理解为慈禧个人夺权。它首先是清廷在外战失败、内乱未平、幼帝继位条件下的一次中枢重组。

它的积极意义在于提供了战后稳定和洋务政策的政治条件；局限在于它仍是宫廷政变，没有触动皇权专制、财政分散、军政地方化和传统官僚制度的根本问题。

# 与前后事件的关系

辛酉政变上承第二次鸦片战争和咸丰帝去世造成的权力真空，下启同治朝的自强运动。它与[总理衙门设立](/历史/中国近代史/02自强运动与边疆危机/01总理衙门设立)共同构成 1861 年前后晚清政治重组的两个关键节点。

没有辛酉政变后的中枢稳定，洋务运动难以获得持续的政治许可；但正因为这种稳定主要来自宫廷权力再分配，洋务运动也始终受制于旧制度边界。
