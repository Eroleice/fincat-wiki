# 摘要

府院之争是 1916 年袁世凯死后，北京政府内部总统府与国务院之间围绕权力、国会、约法和对德参战等问题展开的冲突。通常所说的高潮，指 1917 年总统黎元洪与国务总理段祺瑞之间的公开对立。[^chi][^nathan]

它不是单纯的个人争吵，而是北洋政治失去最高强人后，宪制文本、军阀派系和外交财政利益相互碰撞的结果。府院之争最终引出张勋入京和短暂复辟，也使北京政府的中央权威进一步破碎。[^mccord][^cambridge12]

# 背景

袁世凯死后，黎元洪继任总统，段祺瑞任国务总理。表面上，北京政府恢复了共和名义下的总统、总理、国会和约法框架；实际上，北洋集团内部已经没有能压服各派的共同领袖。[^cambridge12]

第一次世界大战后期，中国是否对德绝交并参战，成为府院之争的重要议题。段祺瑞希望借参战扩大政府资源和国际地位，黎元洪及部分国会议员则担心内阁和军人派系绕过法定程序，并借外交问题增强自身权力。[^nathan]

# 直接原因

直接原因是黎元洪与段祺瑞围绕参战、内阁权限和国会程序发生冲突。总统府强调总统和国会在重大事项中的地位，国务院和段系力量则强调内阁行政效率和军政实际控制。[^chi]

1917 年，黎元洪免去段祺瑞总理职务，段系督军和北洋派系随即施压。张勋以调停名义率兵入京，使本已尖锐的府院冲突转向更严重的政权危机。[^mccord]

# 根本原因

根本原因是民初宪制框架缺少稳定执行基础。总统、总理和国会的权力边界在文本中可以讨论，但真正决定政治走向的，仍是各派军队、督军联盟、财政来源和外交借款。[^nathan][^mccord]

另一层原因是北洋集团内部派系化。袁世凯在世时还能以个人权威协调北洋系统；他去世后，段祺瑞、冯国璋及地方督军各有利益。府院之争因此也是北洋军阀政治正式展开的信号。

# 经过

袁世凯死后，北京政府试图恢复约法和国会，以重建共和合法性。黎元洪作为总统，名义上处于国家元首位置；段祺瑞作为总理，实际掌握较强的军政资源和北洋派系支持。[^cambridge12]

围绕对德绝交、参战和内阁权限，两人矛盾不断扩大。段祺瑞推动参战政策，认为可以借此改善中国国际处境并取得财政资源；反对者则担心这会被段系用来扩大军队和控制国会。[^nathan]

1917 年 5 月，黎元洪免去段祺瑞总理职务。北洋督军对总统施压，张勋率部入京调停。张勋进入北京后，局势并未回到宪政轨道，反而在 7 月演变为拥清帝复辟。[^chi][^mccord]

# 结果

府院之争没有通过宪制程序解决，反而导致张勋入京和清室短暂复辟。段祺瑞随后以讨逆名义重新掌权，北京政府虽然恢复共和名义，但国会和约法的权威继续受损。[^chi][^mccord]

1917 年 8 月，中国最终对德国、奥匈帝国宣战，但参战政策已深深卷入派系政治。北京政府获得国际身份和部分资源，却没有因此解决内部合法性和军阀割据问题。[^nathan]

# 影响

府院之争使民初中央政治进一步军事化。总统、总理和国会之间的争议，本应通过制度程序解决，却被督军通电、军队调动和派系压力主导。

它也使南方反对派获得新的政治理由。孙中山等人认为北京政府破坏约法和国会，随后以护法为号召在广州组织南方政权。府院之争因此是护法运动的重要前置事件。

# 历史评价

府院之争说明，民初共和国的问题不是“有没有制度名词”，而是制度背后有没有可执行的权力边界。总统、总理、国会和内阁都存在，但军队和财政并不稳定服从这些机构。

它还说明外交议题会被国内派系吸收。对德参战本来关系中国在一战后国际秩序中的位置，却在北京政局中变成段系、总统府、国会和督军之间争夺资源的工具。

# 与前后事件的关系

府院之争上承护国运动后的权力重组。袁世凯倒台后，共和名义恢复，但北洋政治缺少共同权威，府院冲突由此爆发。

它下启张勋复辟和护法运动。张勋借调停入京发动复辟，段祺瑞讨逆后进一步扩大权力；南方则以北京破坏约法为由组织护法，南北分裂更加制度化。
