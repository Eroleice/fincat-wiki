# 摘要

第一次国共合作，是 1920 年代中国国民党、中国共产党和苏联/共产国际因素共同形成的革命统一战线。它通常以 1924 年国民党一大和国民党改组为制度化标志，以反帝反军阀、推动国民革命为共同目标。[^wilbur][^saich]

合作使国民党获得更强组织动员能力，也使中国共产党进入更广阔的全国政治舞台。黄埔军校、工农运动、五卅运动、省港大罢工和北伐战争都与这一合作格局密切相关；1927 年四一二反革命政变和七一五分共则标志合作破裂。[^wilbur-how][^fitzgerald]

# 背景

孙中山领导的国民党在护法和地方军政斗争中屡受挫折，需要组织、经费、军事训练和群众动员资源。中国共产党成立不久，人数少、力量弱，也需要通过更广阔的政治平台接触工人、农民和青年群众。[^wilbur][^dirlik]

苏联和共产国际则希望在中国推动反帝革命，并认为国民党可作为更广泛民族革命的载体。三方目标并不完全相同，但在反帝反军阀和组织革命力量上形成交集。[^saich]

# 直接原因

直接原因是国民党改组为合作提供了组织形式。共产党员以个人身份加入国民党，可以参与国民党党务、军校、宣传和群众运动，同时保留共产党自身组织。[^wilbur-how]

另一直接原因是反军阀统一战线需要整合有限资源。广州革命政权若要北伐，既需要军队和财政，也需要工人、学生、农民和城市舆论支持。国共合作让这些资源在一段时间内被集中起来。

# 根本原因

根本原因是北洋军阀割据和列强特权使单一政治力量难以完成国家统一。反帝反军阀成为不同革命力量暂时合作的共同语言。

更深层看，1920 年代中国革命进入政党、军队和群众运动结合的新阶段。国民党有历史声望和政权平台，共产党有工农组织和阶级动员方向，苏联提供顾问和组织经验，这些因素共同塑造了合作格局。[^fitzgerald]

# 经过

1923 年前后，孙中山、苏联代表和共产国际代表围绕国民党改组和合作方式进行磋商。中共方面在共产国际影响下接受党员以个人身份加入国民党的策略。[^saich]

1924 年国民党一大召开后，合作制度化。共产党人进入国民党党部、黄埔军校和群众组织，国民党则在苏联顾问帮助下强化党务、宣传和军队建设。

1925 年孙中山逝世后，合作仍在五卅运动、省港大罢工和广州革命政府中继续发展。1926 年北伐开始，工农运动和军队推进相互配合，但国民党内部对共产党、工农运动和革命领导权的分歧迅速加深。[^wilbur]

# 结果

第一次国共合作直接推动了国民革命兴起。黄埔军校建立、群众运动扩大、广东革命根据地巩固和北伐战争发动，都与合作带来的组织整合有关。[^wilbur-how]

但合作也在发展中积累矛盾。共产党推动工农运动，国民党右派和部分军事力量担心社会革命冲击既有秩序；苏联顾问、国民党各派和中共之间也围绕战略和权力产生分歧。1927 年合作最终破裂。

# 影响

对国家政治而言，第一次国共合作把反军阀和反帝运动推向全国规模。它证明现代政党、革命军队、工农学生运动和宣传组织可以结合起来改变军阀格局。

对社会而言，合作时期工人、农民和青年学生的政治参与显著扩大。五卅运动、省港大罢工和北伐时期的工农运动，显示群众不再只是政治旁观者，而成为革命力量的一部分。[^fitzgerald]

# 历史评价

第一次国共合作是一次有效但脆弱的革命联盟。它有效，是因为各方资源互补，确实推动了国民革命和北伐；它脆弱，是因为合作双方对革命性质、阶级动员、军队控制和政权归属存在根本分歧。

因此，不能只把它看作“团结成功”或“必然破裂”。它更像民国初年国家碎片化中的一次高强度整合尝试，既释放了巨大动员力量，也把内部矛盾推向爆发。

# 与前后事件的关系

它上承国民党改组和中国共产党成立。改组提供组织外壳，建党提供新的阶级动员力量，苏联和共产国际则提供统一战线策略。

它下启黄埔军校、五卅运动、省港大罢工和北伐战争，也通向四一二反革命政变和七一五分共。合作既是北伐成功的重要条件，也是 1927 年革命阵营分裂的直接背景。
