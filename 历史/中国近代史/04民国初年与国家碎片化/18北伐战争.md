# 摘要

北伐战争是国民革命军在 1926 年从广东出师北上，以打倒军阀、统一中国为号召的军事政治行动。广义北伐延续到 1928 年东北易帜前后；本页按第四阶段主题，重点说明 1926 年至 1927 年国共合作背景下的北伐推进、群众动员和革命阵营分裂。[^wilbur][^van-de-ven]

北伐迅速冲击吴佩孚、孙传芳等北洋军阀势力，推动革命中心从广州移向武汉、南京、上海等地。但军事胜利也加剧了国民党内部、国共之间以及工农运动与地方秩序之间的矛盾，最终通向四一二反革命政变和七一五分共。[^fitzgerald][^eastman]

# 背景

袁世凯死后，北洋军阀派系割据，中央政府名义存在但实际权力分散。直系、奉系、皖系残余和南方地方军政力量围绕地盘、财政、铁路和外交承认反复争夺，国家统一成为 1920 年代最强烈的政治诉求之一。[^cambridge12]

广州革命政权在国民党改组、国共合作、黄埔军校和群众运动支持下，逐步形成较强组织和军事力量。五卅运动、省港大罢工等反帝运动也为北伐提供了舆论和群众基础。[^wilbur]

# 直接原因

直接原因是广州革命政府已经具备出师条件。黄埔系干部、国民革命军整编、苏联顾问和国共合作组织网络，使北伐从政治口号转化为军事计划。

另一个直接原因是南方革命力量需要打破军阀包围。若长期困守广东，革命政权会受财政、地方军事和外部压力限制；北进可以争取湖南、湖北和长江流域的战略空间。

# 根本原因

根本原因是民国初年国家碎片化已经难以通过议会和约法解决。军阀掌握军队和地方财政，革命力量只能通过军事行动重组国家权力。

更深层看，北伐体现现代革命动员方式的变化。政党、军校、宣传、工农运动和军事行动同时展开，使战争不只是军队作战，也是政治宣传和社会重组。[^fitzgerald]

# 经过

1926 年 7 月，国民革命军从广东出师北伐。北伐初期重点进攻湖南、湖北方向，迅速击败吴佩孚势力，并控制武汉地区。群众运动、工会和农会在北伐推进区迅速发展。[^wilbur]

随后，北伐军继续向江西、福建、浙江、江苏等方向推进，打击孙传芳势力。军事胜利推动国民政府内部权力中心发生变化，武汉和南京逐渐形成不同政治重心。

1927 年春，北伐进入长江下游和上海、南京区域。城市工人运动、地方商界、外国租界、国民党军队和共产党组织之间矛盾急剧上升。蒋介石在上海发动四一二反革命政变后，北伐的统一战线基础遭到决定性破坏。[^eastman]

# 结果

北伐在 1926-1927 年迅速摧毁或削弱多个北洋军阀势力，推动国民革命军控制华中、华东大片区域。北洋军阀体系受到严重冲击，国家统一的现实进程明显加快。[^van-de-ven]

但北伐也导致国民革命阵营内部矛盾爆发。工农运动扩大、城市工人武装和军队控制权问题，使国民党右派、左派和共产党之间冲突升级。1927 年国共合作破裂，北伐的政治基础被重组。

# 影响

对国家政治而言，北伐结束了民国初年许多地方军阀各自为政的旧格局，推动南京国民政府后来实现形式统一。但这种统一主要依靠军事和党国体制，并没有立即解决地方实力派、财政和社会整合问题。

对社会而言，北伐期间工人、农民、学生和商民动员达到新高点。农会、工会和宣传组织在军队推进中扩张，也使阶级和社会革命问题成为国民党内部无法回避的矛盾。[^fitzgerald]

# 历史评价

北伐战争具有明显的反军阀统一意义。它打破北洋军阀长期分裂局面，使“统一国家”从口号进入军事政治实践。

但北伐不是单纯的民族统一战争。它同时是国民党、共产党、苏联顾问、地方军阀、城市工人、农民运动和列强租界力量共同卷入的复杂革命过程。其胜利伴随暴力、分裂和新的权力集中。

# 与前后事件的关系

它上承国民党改组、国共合作、黄埔军校和省港大罢工。没有这些组织、军事和群众基础，广州政权难以发动大规模北伐。

它下启四一二反革命政变和七一五分共。北伐扩大了革命力量，也把内部矛盾推到城市和政权中心，最终使第一次国共合作走向破裂。
