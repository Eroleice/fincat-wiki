# 摘要

徐州会战是 1938 年围绕徐州及津浦、陇海铁路交通线展开的大规模会战。日军试图打通华北与华中占领区之间的联系，夺取徐州这一铁路枢纽；中国第五战区则在李宗仁等指挥下组织防御、机动和反击。会战中最著名的局部胜利是台儿庄战役。[^hsu-chang][^mitter]

徐州会战的特点，是交通线争夺、机动作战和局部胜利并存。中国军队未能长期保住徐州，但在台儿庄等战场取得重要胜利，并在日军合围压力下实施撤退，保存部分有生力量。[^battle-china][^vandeven]

# 背景

南京失守后，日本希望进一步打通华北与华中战场。徐州位于津浦铁路和陇海铁路交汇处，是连接山东、江苏、河南、安徽的重要交通枢纽。控制徐州，意味着日军可以改善南北占领区联系，并威胁中国中原和武汉方向。[^hsu-chang][^drea]

中国方面，徐州会战由第五战区负责组织，李宗仁等将领在复杂地形和多路日军压力下调度部队。中国军队装备和火力仍弱于日军，但可以利用铁路交叉区、河湖地形和多方向机动进行防御与反击。[^mitter][^battle-china]

# 直接原因

直接原因，是日军从南北两个方向压向徐州，试图通过津浦线和山东南部作战形成合围。中国若放弃徐州，日军将获得重要交通枢纽；若守徐州，则需要承受多路进攻和被包围风险。[^hsu-chang]

另一个直接原因，是中国需要在南京失守后重建正面战场士气。徐州会战提供了组织较大规模反击和迟滞日军的机会，台儿庄战役正是在这一会战框架中形成。[^mitter]

# 根本原因

根本原因在于抗战初期双方围绕交通线和战略枢纽争夺主动权。日本依靠铁路、公路和机动作战扩大占领，中国则试图用防御、反击和战略撤退打破日军速胜设想。[^battle-china]

从中国战略看，徐州会战仍属于持久抗战中的空间换时间。守住徐州当然有价值，但更重要的是在消耗日军、鼓舞士气和保存主力之间取得平衡。[^vandeven]

# 经过

会战前期，日军从山东南下和津浦线方向推进，临沂、滕县等地发生激烈战斗。中国军队通过不同部队的牵制和反击，试图阻断日军协同，延缓其向徐州集中。[^hsu-chang]

3 月至 4 月，台儿庄战役成为会战高潮。中国军队在李宗仁统一指挥下，利用台儿庄城区、运河和周边阵地，集中孙连仲、汤恩伯等部队夹击日军，取得抗战初期正面战场重要胜利。[^mitter][^battle-china]

台儿庄胜利后，日军继续调整兵力并加强合围。5 月，徐州面临被包围风险，中国军队选择撤出徐州，避免主力被困。会战随后转入徐州外围和豫东、皖北方向的后续作战。[^hsu-chang][^vandeven]

# 结果

徐州会战的结果具有双重性。中国军队在台儿庄取得重要胜利，打击了日军气焰，鼓舞全国抗战士气；但徐州最终失守，中国军队被迫撤退。[^mitter][^hsu-chang]

从战略上看，中国撤出徐州避免了主力被日军合围歼灭，保存了继续抗战的力量。日军夺取徐州后仍未能迫使中国投降，战争继续向武汉会战和长期相持方向发展。[^vandeven]

# 影响

对国家而言，徐州会战证明南京失守后中国正面战场仍有组织反击能力。台儿庄胜利尤其重要，它在连续失利后提供了可见的胜利经验。[^battle-china]

对人民而言，会战区域跨越多省交界，铁路、城镇和乡村都被卷入战火。战役造成难民、破坏和征发，也促使地方社会进一步参与抗战支援。[^mitter]

对军事而言，徐州会战显示中国军队可以在局部战场通过地形、兵力集中和多方向协同取得胜利；但也显示在日军持续增援和合围压力下，战略撤退仍是保存力量的重要手段。[^hsu-chang]

# 历史评价

徐州会战不是单纯胜利或失败。若只看徐州城得失，中国最终撤退；若看抗战总体，它包含台儿庄这样的重大胜利、对日军的迟滞消耗，以及避免主力被围的战略取舍。[^vandeven][^battle-china]

它的历史意义，在于说明抗战初期中国正面战场并非一路溃败。中国军队在装备劣势下仍能通过指挥、地形和士气取得局部主动，但这些胜利也必须放在长期持久战和总体资源劣势中理解。[^mitter]

# 与前后事件的关系

徐州会战上承南京失守后的正面战场重组。南京和上海的失利没有结束抗战，徐州会战成为中国重新组织大型防御与反击的重要节点。

它下启台儿庄战役的胜利记忆和武汉会战前的战略调整。徐州撤退后，日军继续向中原和武汉方向施压，中国抗战进入更大范围的持久消耗。
