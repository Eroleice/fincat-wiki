# 摘要

重庆大轰炸通常指抗战时期日军对重庆及周边地区持续实施的战略轰炸，1938 年后逐步加剧，1939 至 1941 年尤为猛烈。重庆作为战时首都和西南后方核心，承受了长期空袭、火灾、避难、停工、疏散和民众伤亡。[^lary][^mitter]

这场轰炸的目的，不只是摧毁军事设施，也包括打击战时政府运转、破坏城市生活、制造恐慌并削弱抵抗意志。它没有迫使中国政府投降，却把后方社会卷入直接战争暴力，成为抗战记忆中最集中体现平民苦难的事件之一。[^van-de-ven]

**关键词**：重庆大轰炸、战时首都、战略轰炸、后方社会、防空洞、六五隧道惨案、平民苦难。

# 背景

武汉、广州失守后，重庆成为国民政府战时中心之一。中央机关、外交机构、军事指挥、学校、工厂、报刊和大量难民汇聚西南，使重庆具有政治和象征意义。[^lary][^mitter]

日本难以通过占领武汉等城市迫使中国投降，便继续以轰炸、封锁和扶植伪政权等方式削弱中国抵抗。空袭重庆，是这种相持阶段战争方式的重要组成。[^van-de-ven]

# 直接原因

直接原因是重庆成为战时政治和军事中心。日军希望通过空袭破坏政府机关、交通通信、军工生产和城市秩序，使重庆无法稳定承担战时首都功能。[^mitter]

同时，轰炸也带有心理战目的。日军把平民生活区纳入空袭威胁，试图制造恐惧、流亡和社会失序，迫使中国在长期战争中丧失抵抗意志。[^lary]

# 根本原因

根本原因在于日本“速胜”受挫后转向长期压迫策略。既然夺取城市无法结束战争，日方就试图用轰炸、封锁和占领区统治削弱中国国家运转与社会承受力。[^van-de-ven]

中国方面空军和防空体系相对薄弱，西南后方地形虽提供一定纵深，却不能完全阻止远程空袭。城市人口密集、建筑材料易燃、防空设施不足，使轰炸造成严重平民灾难。[^lary]

重庆大轰炸不是一次空袭，而是长期、反复、带有战略和心理战目的的空中打击。它迫使城市建立警报、灯火管制、防空洞、疏散和救护制度，也让普通居民长期生活在“后方并不安全”的现实中。[^lary]

# 结果

第一，重庆遭受长期破坏，城市建筑、交通、生产和居民生活受到严重影响。平民伤亡和社会创伤成为轰炸最沉重的后果。[^lary]

第二，轰炸没有达到迫使中国政府投降的目标。重庆政府继续维持战时行政和外交功能，中国抗战在西南后方继续展开。[^mitter][^van-de-ven]

第三，轰炸推动防空、疏散、救护和城市管理制度在极端条件下发展，也把战时后方社会纳入直接军事暴力之中。[^lary]

# 影响

对国家而言，重庆大轰炸显示后方中心同样处在战争前线。它强化了重庆作为战时首都的象征，也使中国抗战在国际社会中呈现为平民承受侵略暴力的长期斗争。

对人民而言，轰炸改变了日常生活。警报、避难、停课、停工、物价、迁居、伤亡和心理创伤，构成普通人理解抗战的具体经验。[^lary]

对战争伦理而言，重庆大轰炸提醒人们，现代战争的暴力不再局限于前线军队。城市居民、学校、医院、工厂和市场都可能成为战争打击的对象。[^van-de-ven]

# 历史评价

重庆大轰炸应被放在日本侵华战争和战略轰炸史中评价。它是对中国战时后方和普通民众的长期暴力，不应被简化为“军事压力”或“城市附带损害”。

同时，重庆在轰炸下仍维持政府、外交、教育、工业和社会组织运转，也体现中国后方社会的韧性。韧性不意味着苦难可以被浪漫化；它首先说明普通人被迫在极端危险中维持生活和抗战。[^lary][^mitter]

# 与前后事件的关系

它上承广州、武汉失守和抗战相持阶段。正是因为战时中心西移，重庆才成为日本重点轰炸目标。

它下接后方建设、国际援助和长期抗战。重庆大轰炸没有结束中国抵抗，反而使西南后方的防空、工业、教育、宣传和外交意义更加突出。[^van-de-ven]
