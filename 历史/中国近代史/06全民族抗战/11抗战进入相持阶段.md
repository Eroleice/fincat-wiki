# 摘要

1938 年广州、武汉相继失守后，全面抗战进入相持阶段。这里的“相持”不是双方力量相等，而是日本已经夺取大量城市和交通线，却无法迫使中国政府投降；中国则失去东部、华中和华南多处中心城市，却依托西南后方、敌后战场和长期动员继续抵抗。[^mitter][^van-de-ven]

相持阶段使战争形态发生变化：大规模正面会战仍会发生，但不再是唯一主轴；日军占领、封锁、轰炸和扶植伪政权并行，中国则在重庆后方、敌后根据地、国际援助和政治整合之间维持抗战。毛泽东在 1938 年《论持久战》中提出抗日战争将经历战略防御、战略相持和战略反攻的分析，成为理解这一阶段的重要思想文本之一。[^mao-protracted][^cpc-history]

**关键词**：战略相持、持久战、重庆后方、敌后战场、正面战场、伪政权、长期消耗。

# 背景

抗战初期，日本以夺取北平、天津、上海、南京、徐州、武汉、广州等城市和交通枢纽为重点，试图通过连续军事压力迫使中国屈服。但中国政府迁至重庆，军队主力和社会资源并未完全崩溃，敌后游击战争也在华北、华中扩展。[^mitter][^battle-china]

1938 年后，日本占领区扩大，兵力和行政资源被拉长。占领城市和铁路不等于控制广大乡村、山区和交通线外的社会空间。中国方面虽然损失严重，却获得更清晰的持久战路径。[^van-de-ven]

# 直接原因

直接原因是广州、武汉失守后，双方都难以继续按 1937-1938 年那种高速、大城市连续会战的方式推进战争。日本取得城市战果，却没有达到迫降中国的目的；中国失去重要城市，却保留重庆政府、后方空间和敌后抗战力量。[^mitter]

太长的战线、有限的兵力、占领区治安压力和国际局势变化，使日本无法把军事胜利立即转化为政治胜利。中国方面也无力迅速收复大城市，只能在长期防御、敌后袭扰、后方建设和外交争取中维持抗战。[^van-de-ven][^battle-china]

# 根本原因

根本原因在于中日战争的结构性不对称。日本拥有更强工业、海空军和机动作战能力，但需要在辽阔中国维持占领；中国军事装备落后、财政困难，却有广阔战略纵深、庞大人口和持续抵抗的政治意志。[^mitter][^van-de-ven]

持久战不是自然发生的结果，而是战争空间、社会动员和组织能力共同作用的产物。中国必须把战争从城市正面作战扩展为后方生产、敌后根据地、国际援助、宣传教育和政治整合，才能抵消军事劣势。[^mao-protracted][^cpc-history]

# 经过

| 阶段表现 | 主要内容 | 历史含义 |
|:--|:--|:--|
| 战时中心西移 | 重庆和西南后方承担中央政府、外交、军政和文化教育功能。 | 国家组织在城市沦陷后继续存在。 |
| 日军占领与封锁 | 日军控制重要城市、铁路和港口，并通过轰炸、扫荡、封锁和伪政权维持占领。 | 占领成本上升，战争从进攻转为治理和反游击压力。 |
| 正面战场继续作战 | 长沙、桂南、枣宜等战役仍不断发生。 | 相持不是无战事，而是大战略目标难以迅速改变。 |
| 敌后战场扩展 | 八路军、新四军和根据地在华北、华中开展游击战、破袭和基层组织。 | 沦陷区内部出现长期抵抗空间。 |
| 国共摩擦加深 | 统一战线在合作中伴随军队编制、地盘、补给和政治动员冲突。 | 民族战争没有消除中国内部政治竞争。 |
{.dense}

相持阶段的战争并不平静。日本继续发动局部攻势、轰炸重庆、扶植汪精卫政权，并在华北华中加强“扫荡”。中国方面既有正面战场会战，也有敌后根据地扩展、百团大战和后方大生产等实践。[^battle-china][^cpc-history]

# 结果

相持阶段的形成，使日本无法在 1938 年后结束战争。中国虽然损失巨大，却把抗战转化为更长期、更复杂的国家和社会动员。[^mitter]

同时，相持也使中国内部矛盾继续积累。国民政府的财政和军政压力加重，中国共产党在敌后根据地扩展组织力量，国共之间的互信不断下降。[^van-de-ven][^cpc-history]

国际层面上，相持为后来的太平洋战争和同盟国援华创造了时间。中国战场长期牵制日本力量，也使中国在世界反法西斯战争中的位置逐步上升。[^mitter]

# 影响

对军事格局而言，相持阶段把抗战从“守城市”推向“守国家存在”。正面战场、敌后战场、后方生产和国际外交都成为战争的一部分。

对社会而言，长期战争带来更深的苦难：轰炸、难民、物价上涨、征兵、征粮、疾病和家庭离散持续扩大。抗战的坚持不是抽象口号，而是普通人在日常生活中长期承受的组织和生存压力。[^lary]

对政治格局而言，相持阶段改变了国共力量对比。国民政府保有国际承认和中央政府地位，但消耗严重；中国共产党则通过敌后根据地和群众组织积累基层力量。[^cpc-history][^van-de-ven]

# 历史评价

“相持阶段”是一种战略判断，不应理解为战场上的停顿。日本仍有局部进攻能力，中国仍有严重危机，普通民众仍承受持续战争暴力。相持真正说明的是：日本无法用占领大城市解决中国问题，中国也无法短期内把日本逐出中国。

从中国近代史看，这一阶段凸显了国家韧性和组织能力的重要性。谁能维持财政、军队、基层、生产、宣传和外交，谁就能在长期战争中积累政治资本。[^van-de-ven]

# 与前后事件的关系

它上承广州、武汉失守。两城失守使抗战初期战略防御阶段告一段落，也迫使中国将中心西移并接受长期战争现实。

它下启重庆大轰炸、百团大战、皖南事变、敌后根据地建设和大生产运动。后续这些事件分别体现相持阶段的不同面向：后方承受轰炸、敌后主动出击、统一战线裂痕、根据地治理和自力更生。[^cpc-history]
