# 概述

本页用于整理“历史 / 中国近代史”目录下的事件写作清单。暂以 1839/1840 年至 1949 年为近代史写作范围，将主线放在国家危机、人民动员、制度探索、民族救亡与新国家形成之间的连续关系。

每个事件页建议围绕四个核心问题展开：直接原因、根本原因、直接影响、长期影响。最终目标不是堆叠年表，而是说明近代中国如何在连续危机、牺牲、组织、抗争和重建中锻造民族精神。
