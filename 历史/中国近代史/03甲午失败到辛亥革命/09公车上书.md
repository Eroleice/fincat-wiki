# 摘要

公车上书，通常指 1895 年《马关条约》消息传到北京后，赴京参加会试的举人和维新派士人围绕拒和、迁都、练兵、变法等主张展开的集体政治表达。传统叙述多强调康有为、梁启超组织千余举人联名上书；近年研究对签名人数、递呈程序和是否进入正式奏折渠道有不同考订，因此本页把它作为甲午战后士人请愿和维新舆论动员的标志性事件来理解。[^mao][^kwong]

**关键词**：公车上书、康有为、梁启超、马关条约、拒和、变法、会试举人、士人政治、维新运动。

公车上书的意义，不只在一次上书是否正式送达，更在于它显示传统科举士人开始以集体请愿、舆论传播和政治组织方式回应国家危机。它连接了《马关条约》的震动和戊戌变法的兴起。[^hsu][^chang]

# 背景

甲午战争失败后，清廷议和消息震动北京。割地、赔款、承认朝鲜独立等条款，使赴京会试的举人群体感到国家危急。士人原本通过科举进入仕途，此时也开始把国家危机与政治改革联系起来。[^hsu]

康有为此前已多次上书，主张变法图强。梁启超等新式士人也逐渐围绕康有为形成维新网络。甲午战败给维新派提供了极强的现实论据：如果制度不改，国家将继续败于列强和日本。[^kwong][^chang]

“公车”原为汉代征召士人赴京的典故，后来被用来指赴京应试举人。公车上书因此带有传统士人身份和近代政治请愿相结合的意味。

# 直接原因

第一，《马关条约》割地赔款的消息激起士人强烈反应。拒绝批准条约、反对割地和要求整顿军政成为直接诉求。

第二，赴京会试使各省举人集中在北京，形成临时政治网络。士人之间可以讨论、传抄、签名和共同表达意见。

第三，康有为等维新派已经形成较明确的变法主张，能够把战败愤怒组织成上书文本和改革纲领。[^mao]

# 根本原因

公车上书的根本原因，是传统士人政治在甲午危机后开始转向近代公共政治。

科举制度原本把士人的政治参与主要导向考试、入仕和奏议。甲午战败后，许多士人意识到单纯进入旧官僚体系已不足以救国，必须以集体舆论和制度改革回应危机。

维新派也在寻找新的政治动员方式。他们既没有军队，也没有正式政党，只能借上书、报刊、学会、讲学和士人网络扩大影响。公车上书正是这种转型的早期表现。

# 经过

## 会试举人聚集

1895 年春，各省举人赴京参加会试。甲午战败和议和消息传来后，举人之间出现大量议论。割让台湾、辽东、赔款等条款尤其刺激士人情绪。

## 康有为草拟上书

传统叙述中，康有为起草长篇上书，提出拒和、迁都、练兵、变法等主张，并组织举人签名。梁启超等人参与联络和传播。[^kwong]

## 递呈细节争议

关于这次上书是否正式递入、是否被都察院接收、签名人数究竟多少，学界有考订差异。茅海建等研究提醒，不能把后来广泛流传的纪念性叙述直接等同于全部制度事实。[^mao]

因此，更稳妥的理解是：公车上书作为一次士人集体请愿和政治动员确实产生了重要影响；但在具体人数、文本流转和官方受理程序上，应保留史料差异。

## 维新舆论扩散

无论递呈程序如何，公车上书之后，康有为、梁启超等维新派声望上升，强学会、报刊和学堂活动继续发展，变法主张进入更广阔的士人和城市舆论空间。

# 结果

公车上书没有阻止《马关条约》生效，也没有立即改变清廷决策。但它使维新派从少数士人议论走向全国性政治象征，康有为、梁启超等人的影响迅速扩大。

它还推动士人政治表达方式变化。上书、联名、传抄、报刊、学会和公开议论逐渐成为晚清公共政治的重要形式。

# 影响

## 对国家的影响

公车上书没有直接改变国家政策，却显示清廷旧有决策渠道面临新压力。士人不再只是等待考试和任官，也开始以集体方式要求国家改变方向。

## 对人民的影响

事件本身主要发生在士人阶层，但它推动的报刊、学会和维新舆论，后来影响学生、商人和城市公众，使国家危机逐渐从朝廷议题变成公共议题。

## 对思想政治的影响

公车上书把“拒和救亡”和“变法图强”连接起来。它使维新派获得政治声望，也为 1898 年戊戌变法提供思想和组织前奏。

# 历史评价

公车上书的价值，不应完全系于它是否按传统奏折程序正式成功递达。它的历史意义在于，甲午战败后士人开始尝试用集体请愿和公共舆论影响国家政策。

同时也要避免把它神话为成熟的群众政治。参与主体主要是举人和维新士人，组织松散，政治诉求仍依赖皇帝采纳和朝廷改革。它是近代公共政治的开端性尝试，而不是现代政党政治或全民运动。

# 与前后事件的关系

公车上书上承甲午战败和《马关条约》。如果没有战败割地赔款带来的强烈震动，举人群体不会在北京形成如此集中的政治表达。

它下启强学会、维新报刊和戊戌变法。维新派在公车上书中获得名声和网络，随后继续推动学会、办报、上书和变法，最终进入 1898 年光绪帝支持的改革高潮。
