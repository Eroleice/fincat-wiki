# 摘要

黄花岗起义，又称 1911 年广州三月二十九日之役，是中国同盟会在辛亥革命前发动的一次重要武装起义。起义由黄兴、赵声等人筹划，目标是在广州发动精干力量攻击清朝两广总督署，进而推动华南和全国革命。起义最终失败，但牺牲者被后世以“黄花岗七十二烈士”纪念，成为辛亥革命前最具象征性的牺牲事件之一。[^xinhai-history][^bergere]

**关键词**：黄花岗起义、广州起义、黄兴、赵声、孙中山、同盟会、槟榔屿会议、七十二烈士、辛亥革命。

从历史链条看，黄花岗起义发生在[同盟会成立](/历史/中国近代史/03甲午失败到辛亥革命/19同盟会成立)之后、[武昌起义](/历史/中国近代史/03甲午失败到辛亥革命/21武昌起义)之前。它没有直接推翻清朝，却以巨大的牺牲强化了革命党人的精神动员，也暴露了秘密起义在情报、协同和军事资源上的局限。[^hsu][^schiffrin]

# 背景

同盟会成立后，革命党人多次试图通过边境、会党、新军和城市突袭发动起义。1906 年以后的萍浏醴、镇南关、河口等起义相继失败，说明革命派虽然有宣传和筹款能力，却缺少稳定的军事基地。[^xinhai-history]

广州在革命党人眼中具有特殊地位。它接近香港、澳门和南洋华侨网络，便于筹款、采购军械和人员往来；广东又是兴中会早期活动和多次反清行动的重要区域。黄兴等人希望在广州集中精干力量，以牺牲性突击打开局面。

1910 年广州新军起义失败后，革命派一度陷入低潮。孙中山、黄兴等人在南洋筹款和会商，决定组织一次更大规模、更具决战性质的广州起义。华侨捐款、留学生和青年革命者的参与，使这次起义从一开始就带有强烈的精神动员色彩。[^bergere][^schiffrin]

# 直接原因

第一，同盟会需要用一次有力行动打破起义连续失败后的低潮。革命党人担心长期只宣传不行动，会削弱组织凝聚力和海外筹款信心。

第二，华南交通和海外联络条件便利。香港、广州和南洋之间的人员、军械和资金流动，为革命党人组织突击行动提供了可能。

第三，革命派判断清廷在新政、立宪和地方矛盾中已经出现政治松动，希望通过广州起义引发连锁响应。

第四，起义计划在筹备中多次受阻，军械运输、人员协同和保密出现问题，导致原定多路配合方案不断收缩，最终形成以黄兴率敢死队突击为中心的行动。[^xinhai-history]

# 根本原因

黄花岗起义的根本原因，是革命派在王朝危机和组织困境之间寻找突破口。

从政治上看，清廷的新政和预备立宪未能恢复信任，革命派认为必须以武装起义打断王朝统治。黄花岗起义是“以牺牲唤起革命”的典型行动。

从组织上看，同盟会虽然有纲领和海外网络，却缺少可长期控制的军队、城市政权和财政基地。秘密起义因而成为革命派常用方式，但这种方式高度依赖保密、内应和同步配合，一旦暴露或配合失灵，失败风险极高。

从社会心理上看，青年革命者的牺牲精神已经成为晚清政治文化中的重要力量。黄花岗起义之所以被反复纪念，不只是因为它在军事上接近成功，而是因为它把革命、青年、牺牲和共和理想绑定在一起。

# 经过

1910 年底至 1911 年初，孙中山、黄兴、赵声等人围绕广州起义筹款和部署。起义计划原本希望争取新军、巡防营、会党和城市革命者配合，以多路进攻方式夺取广州。

实际筹备中，军械运输、人员调集和保密均出现困难。部分内应和配合力量未能按计划行动，清方警觉也使起义时机不断变化。黄兴到广州后，起义计划被迫压缩为较小规模的突击行动。

1911 年 4 月 27 日，黄兴率革命党人进攻两广总督署。起义队伍一度突入目标区域，但张鸣岐已经逃离，清军随即组织反击。革命党人在广州城内展开巷战，因人数、火力、协同和后援不足，最终失败。[^xinhai-history][^schiffrin]

起义失败后，大量革命党人牺牲或被捕。广州地方人士和革命者后来收殓烈士遗骸，形成“黄花岗七十二烈士”的纪念传统。需要注意的是，后世纪念中的“七十二烈士”是最具象征性的纪念名目，并不等于此次起义全部死难者的完整统计。[^xinhai-history]

# 结果

黄花岗起义在军事上失败。革命党未能夺取广州，也没有立即引发华南各地响应。许多骨干牺牲，革命组织承受重大损失。

但起义在政治和精神上产生强烈影响。烈士遗骸收葬和“七十二烈士”纪念，使失败的军事行动转化为革命传播资源。革命党人可以借此说明清廷不可改革、革命必须继续，也可以借牺牲故事争取海外华侨和青年学生支持。

起义还强化了黄兴在革命派中的军事声望。虽然行动失败，黄兴亲临前线和率队突击，使其成为同盟会中最具行动力的领袖之一。

# 影响

对革命组织而言，黄花岗起义既是鼓舞也是警示。它显示革命党人有献身精神和组织动员能力，但也显示秘密突击很难替代稳定军队、广泛地方响应和成熟政治准备。

对社会舆论而言，黄花岗烈士把辛亥革命前的抽象共和理想具象化。林觉民等人的遗书和烈士纪念，后来不断被用来说明个人牺牲与国家重建之间的关系。

对辛亥革命进程而言，黄花岗起义没有直接引发全国革命，却在武昌起义前进一步扩大了反清革命的声望。数月后武昌起义爆发时，革命党人的牺牲叙事已经在舆论中积累了很强的道义力量。[^state-rev][^hsu]

# 历史评价

黄花岗起义是一场军事失败、政治影响深远的革命行动。若只看夺取广州的目标，它没有成功；若看革命动员和历史记忆，它是辛亥革命前最重要的精神资源之一。

它的积极意义在于，革命党人以行动证明反清共和不是空谈，并把青年、华侨、知识分子和秘密组织连接起来。它的局限在于，起义计划过度依赖少数精英突击和不稳定内应，缺少足够军事后援和群众政治组织。

因此，黄花岗起义既应被理解为革命精神的高峰，也应被理解为秘密革命路线局限的暴露。辛亥革命后来能够成功，不是因为重复黄花岗模式，而是因为武昌起义与新军、地方政治和各省响应结合起来。

# 与前后事件的关系

黄花岗起义上承[同盟会成立](/历史/中国近代史/03甲午失败到辛亥革命/19同盟会成立)。同盟会提供了纲领、筹款、海外网络和革命干部，广州起义则是这一组织能力的一次集中使用。

它下启[武昌起义](/历史/中国近代史/03甲午失败到辛亥革命/21武昌起义)。黄花岗失败后，革命派更加认识到必须争取新军和地方响应；武昌起义恰恰是在湖北新军内部革命组织和地方政治危机共同作用下爆发。

从阶段主线看，黄花岗起义与[保路运动](/历史/中国近代史/03甲午失败到辛亥革命/18保路运动)共同说明：辛亥革命不是单一事件，而是革命党秘密起义、地方权益运动、立宪派失望和新军变化叠加的结果。
