# 摘要

袁世凯就任临时大总统，是指清帝退位后，孙中山辞去临时大总统职务，临时参议院选举袁世凯为中华民国临时大总统，并由袁于 1912 年 3 月在北京就职的政权交接事件。它标志辛亥革命的南北妥协完成，也标志北洋军事实力进入共和国最高权力中心。[^young][^state-rev]

**关键词**：袁世凯、临时大总统、孙中山辞职、南北议和、北洋军、北京就职、中华民国临时约法、民国初年。

这一事件的历史意义具有两面性：一方面，它以妥协方式促成清帝退位和名义统一，避免南北战争继续扩大；另一方面，它使共和国从开端就受到强人政治、北洋军权和中央地方矛盾制约。[^chen-yuan][^roc-history]

# 背景

清帝退位后，中华民国在名义上取得全国政权基础，但国家统一仍很脆弱。南方南京临时政府缺少足够财政和军力控制北方，北方袁世凯则掌握北洋军和北京政治资源。[^young][^roc-history]

孙中山在南京临时政府成立时已经表示，若袁世凯能促成清帝退位，可以让位以完成统一。这一承诺不是个人谦让那么简单，而是南方革命阵营在军事实力不足、财政困难和外交压力下作出的现实选择。[^bergere]

袁世凯的优势来自北洋军。北洋军是晚清最有战斗力的新式军队之一，袁世凯长期经营其人事和指挥网络。辛亥革命后，谁能控制北洋军，谁就能在南北谈判和共和国初期政治中占据关键地位。[^chen-yuan][^shan-yuan]

# 直接原因

第一，清帝退位需要政治兑现。南方革命阵营承认袁世凯促成退位的作用，孙中山辞职，为袁接任临时大总统铺路。[^state-rev]

第二，南方缺少立即北伐统一全国的实力。继续战争可能造成长期分裂和财政崩溃，因此让袁接任被视为换取统一的代价。

第三，袁世凯坚持在北京掌握实际权力。围绕是否南下南京就职、临时政府所在地和北方军政控制权，南北之间存在持续博弈。[^young]

第四，临时参议院希望通过《中华民国临时约法》等制度约束总统权力。让袁接任并不意味着南方完全信任袁，而是试图在妥协中保留宪政限制。[^roc-archives]

# 根本原因

袁世凯就任临时大总统的根本原因，是辛亥革命完成了政治合法性转换，却没有同步完成军事和财政权力的革命。

革命党和南京临时政府拥有共和国名义，但缺少全国性军队、稳定税源和行政系统。袁世凯拥有北洋军和北京官僚资源，却缺少共和国革命合法性。南北妥协正是双方资源互补和相互制约的结果。

清末新军现代化未能实现军队国家化。北洋军在组织和训练上较现代，却在政治上与袁世凯个人网络深度绑定。共和国建立后，军队没有立即服从宪政国家，反而成为强人政治的基础。

此外，列强和国内商绅普遍希望中国局势尽快稳定。袁世凯在许多人眼中比革命党更能维持秩序，这也增加了其接任的现实可能。[^young][^shan-yuan]

# 经过

1912 年 2 月 12 日清帝退位后，孙中山按照南北议和安排提出辞职。临时参议院随后选举袁世凯为中华民国临时大总统，同时黎元洪被置于重要副职位置，以平衡革命起源和北洋实力。[^roc-archives][^young]

南方原希望袁世凯到南京就职，以体现中央政府从南京临时政府延续而来。但袁世凯以北方秩序和军政稳定为由，坚持留在北京。北京兵变等事件进一步强化了“袁不能离京”的政治现实，南京方面最终接受其在北京就职。

1912 年 3 月，袁世凯在北京就任临时大总统。南京临时政府权力交接完成，中华民国政治中心实际上转向北京。孙中山卸任后，革命派转而寄望于临时约法、政党组织和议会政治来限制总统权力。[^young][^bergere]

袁世凯就职前后，《中华民国临时约法》公布。临时约法试图以责任内阁、参议院和法律程序限制总统权力，但实际能否执行，取决于军队、财政和政治力量格局。[^roc-archives]

# 结果

中华民国完成从南京临时政府到北京临时大总统政府的权力转移。袁世凯取得共和国最高职位，北洋集团成为民国政治核心力量。

南北妥协暂时实现名义统一。清帝退位、孙中山辞职和袁世凯就任连在一起，使国家避免立即陷入长期南北战争。

但共和国制度从开端就面临军权压倒法权的风险。临时约法试图限制总统权力，现实中袁世凯掌握军队、财政和北京官僚系统，革命派和议会力量难以真正制衡。[^young]

# 影响

对国家政治而言，袁世凯就任把民国政治中心从南京转向北京，也把北洋军事实力制度化地带入共和国。此后北京政府成为民国初年政治主轴。

对宪政而言，这一事件使临时约法从一开始就面对强总统和强军人的挑战。制度文本虽然设计了限制权力的框架，但缺少可靠的军队国家化和财政支撑。

对革命派而言，让袁接任是一场必要妥协，也是一场风险很高的让渡。革命派保住了共和名义，却失去了最高行政和军事控制权。后来的宋教仁案、二次革命和袁世凯称帝，都与这一权力结构有关。[^young][^chen-yuan]

# 历史评价

袁世凯就任临时大总统不能只用“窃取革命果实”或“和平统一功臣”中的任何一个标签概括。

从短期看，袁世凯确实促成清帝退位和南北统一，减少了继续战争的成本。没有北洋军和袁的压力，清廷未必会以相对和平方式退位。

从长期看，袁世凯掌握共和国最高职位，使军事实力压过宪政制度的趋势从民国开端就十分明显。革命派以让位换统一，付出的代价是共和国很快进入强人政治和军政冲突。

因此，这一事件是辛亥革命的收束，也是民国初年困局的开端。帝制被推翻了，但国家权力仍主要掌握在能够控制军队的人手中。

# 与前后事件的关系

袁世凯就任临时大总统上承[清帝退位](/历史/中国近代史/03甲午失败到辛亥革命/24清帝退位)。退位是袁获得共和国最高职位的政治前提，也是南北妥协的核心交换。

它也回接[中华民国成立](/历史/中国近代史/03甲午失败到辛亥革命/23中华民国成立)。南京临时政府建立共和国名义，袁世凯就任则把这个名义转入北洋集团主导的北京政治。

向后看，它开启[民国初年与国家碎片化](/历史/中国近代史/04民国初年与国家碎片化/00民国初年与国家碎片化)的主线。临时约法、政党政治、总统权力、北洋军、地方都督和革命派之间的矛盾，将成为民国初年政治危机的核心。
