# 摘要

中国同盟会成立，是 1905 年孙中山、黄兴、宋教仁等人在日本东京整合兴中会、华兴会、光复会等反清革命力量的重要事件。它使晚清革命运动从分散的会党、留学生和地方团体，逐渐走向带有纲领、组织和舆论平台的全国性革命网络。[^schiffrin][^bergere]

**关键词**：中国同盟会、孙中山、黄兴、宋教仁、兴中会、华兴会、光复会、民报、三民主义、反清革命、共和。

同盟会的政治纲领通常概括为“驱除鞑虏，恢复中华，创立民国，平均地权”。这一纲领把民族革命、共和国建构和社会经济设想结合起来，成为辛亥革命前革命派最重要的组织和思想旗帜之一。[^sun-complete][^xinhai-history]

# 背景

甲午战争以后，维新、立宪和革命三种救亡路径同时发展。戊戌变法失败说明依靠皇权自上而下推行改革十分脆弱；庚子危机和《辛丑条约》又使清廷威信严重下降。许多青年士人、留学生和海外华侨开始相信，仅靠王朝内部改革难以完成国家转型。[^hsu][^schiffrin]

日本成为晚清政治流亡者和留学生的重要聚集地。明治维新的成功、东京的报刊出版空间、留学生社团和革命人物流亡网络，使日本成为反清组织整合的关键地点。孙中山的兴中会、黄兴和宋教仁参与的华兴会，以及江浙革命者联系较深的光复会，原本各有地域、组织和行动传统；成立同盟会，就是为了把这些力量聚合起来。[^rankin][^bergere]

同时，清廷宣布预备立宪前后，立宪派和革命派都在争夺“救中国”的解释权。革命派需要一个更清晰的组织和舆论平台，说明推翻清朝、建立共和国并不是零散暴动，而是一套政治方案。

# 直接原因

第一，分散革命团体多次起义受挫，显示单一地区、单一会党或单一暗杀行动难以推翻清朝。兴中会、华兴会、光复会等组织需要更高层级的协调。[^schiffrin]

第二，留日学生和海外华侨政治化加速。留学生社群接触宪政、民族主义、革命党和近代报刊，海外华侨则为革命宣传、筹款和联络提供重要基础。

第三，孙中山的海外网络与黄兴等国内、留日革命者的实际组织能力互补。孙中山提供较系统的革命纲领和国际筹款经验，黄兴、宋教仁等人则在华中、华南和学生群体中具有组织基础。[^bergere][^xinhai-history]

第四，革命派需要与保皇派、立宪派展开思想竞争。《民报》后来成为同盟会的重要舆论阵地，与梁启超等人的立宪改良主张形成论战。

# 根本原因

同盟会成立的根本原因，是晚清国家危机使一部分政治力量从“改革清朝”转向“推翻清朝、建立共和国”。

甲午失败、庚子危机和清末新政的反复，使王朝体制在许多青年知识分子眼中失去自我更新能力。清廷可以引进学堂、军制和官制改革，却很难真正限制皇权、平等处理满汉关系、建立负责任政府并恢复主权。

革命派的民族主义和共和主义在这一背景下结合。早期同盟会纲领带有强烈反满色彩，也强调“创立民国”。这既反映了当时对清朝统治合法性的否定，也反映了近代民族国家和共和制度观念进入中国政治中心的过程。[^sun-complete][^rhoads]

组织上，现代革命需要报刊、章程、经费、海外支部、秘密联络、军事策动和政治宣传。同盟会成立，正是革命运动从人物型、会党型行动向近代政党雏形转变的重要一步。

# 经过

1905 年夏，孙中山抵达日本后，与黄兴、宋教仁等革命者接触。各团体经过会商，决定建立统一组织。东京成立大会上，孙中山被推为总理，黄兴等人承担实际组织事务，同盟会由此形成总部、支部和会员宣誓等组织安排。[^schiffrin][^bergere]

同盟会建立后，开始用章程、盟书和革命方略统一政治表达。其纲领把反清、恢复中华、建立共和国和平均地权联系起来，后来孙中山又通过《民报》发刊词和演说，把民族、民权、民生三民主义加以系统阐发。[^sun-complete]

《民报》创刊后，同盟会获得较稳定的舆论平台。革命派借此批评清廷和保皇立宪路线，传播共和国、国民、民族革命和社会改革等观念。报刊论战虽然不能直接造成清朝灭亡，却改变了青年学生和城市知识分子的政治想象。

同盟会成立后继续组织起义。萍浏醴起义、镇南关起义、河口起义、广州新军起义和黄花岗起义等行动多数失败，但它们扩大了革命网络，也积累了军事策动、筹款和宣传经验。组织内部也存在地域、资源、领袖权威和路线分歧，这说明同盟会并不是纪律严密的现代政党，而是一个带有联盟性质的革命网络。[^rankin][^xinhai-history]

# 结果

同盟会成立后，反清革命获得相对统一的组织名义和纲领。革命派可以用同盟会联络海外华侨、留学生、国内会党、新军和地方知识分子，组织筹款、宣传和起义。

同盟会也推动共和国观念普及。与单纯反清复仇或地方暴动不同，同盟会明确提出“创立民国”，把革命目标指向国家制度重建。

不过，同盟会并没有完全克服组织松散、地域分歧、经费不足和军事力量有限的问题。辛亥革命最终成功，既有同盟会长期活动的作用，也有清末新政、保路运动、新军变化和地方立宪派转向等多重因素共同推动。[^xinhai-history][^roc-history]

# 影响

对国家政治语言而言，同盟会把“民族”“民权”“民生”“民国”“国民革命”等概念推向公共舆论。它使救亡不再只是朝廷改革问题，而成为国民共同建立新国家的政治想象。

对革命组织而言，同盟会提供了跨地域网络。华南、华中、江浙、南洋、日本和美洲华侨之间的联系，使革命资源能够在不同地点流动。黄花岗起义和武昌起义前后的组织、筹款、宣传，都与这种网络有关。

对后来的民国政治而言，同盟会既是革命组织，也是政党政治的前身。1912 年后同盟会参与改组国民党，说明革命团体需要从秘密行动组织转向公开政党，但这一转型并不顺利。

# 历史评价

同盟会的积极意义在于，它为辛亥革命提供了较明确的组织框架、政治纲领和舆论平台。没有同盟会，反清力量仍可能存在，但更难形成跨地区的革命名义和共和国方案。

它的局限也很明显。早期纲领中的反满语言带有强烈族群动员色彩，后来需要通过“五族共和”等口号重新处理民族国家内部的族群关系。同盟会组织也较松散，许多地方行动并不完全受总部指挥。

从近代史主线看，同盟会成立标志中国政治从王朝改革争论进一步走向革命建国议程。它没有单独完成辛亥革命，却把革命派从边缘秘密团体推进为晚清政治竞争中的关键力量。

# 与前后事件的关系

同盟会成立上承戊戌变法失败、庚子危机和[清末新政](/历史/中国近代史/03甲午失败到辛亥革命/15清末新政)。这些事件不断削弱“清廷可以自我改革”的信心，为革命派扩大影响提供了土壤。

它下启[黄花岗起义](/历史/中国近代史/03甲午失败到辛亥革命/20黄花岗起义)和[武昌起义](/历史/中国近代史/03甲午失败到辛亥革命/21武昌起义)。同盟会组织的多次起义虽多失败，却培养了革命干部、建立了海外筹款渠道，也把共和国观念传播到新军和城市社会。

向后看，同盟会与[中华民国成立](/历史/中国近代史/03甲午失败到辛亥革命/23中华民国成立)相连。南京临时政府不是同盟会一党政府，但同盟会提供了最重要的革命合法性资源。
