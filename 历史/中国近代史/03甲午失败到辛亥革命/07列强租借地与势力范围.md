# 摘要

列强租借地与势力范围，是指甲午战争后俄、德、英、法、日等列强在中国争夺港湾、租借地、铁路、矿权、贷款和区域优先权的现象。1897-1898 年前后，德国租借胶州湾，俄国租借旅顺、大连，英国租借威海卫和展拓香港新界，法国租借广州湾；同时，各国在山东、东北、长江流域、华南和福建等地争夺势力范围。[^macmurray][^bickers]

**关键词**：租借地、势力范围、胶州湾、旅顺大连、威海卫、新界、广州湾、门户开放、铁路矿权、帝国主义瓜分危机。

这一事件说明，甲午战败后中国危机不再限于日本。列强相互竞争，却都把中国主权、港湾、铁路、矿产和市场当作可谈判的利益对象。所谓“租借”和“势力范围”在形式上不同于直接割地，但同样压缩中国的领土、财政、司法、军事和经济自主。[^fairbank][^hay]

# 背景

甲午战败显示清朝军事和财政能力不足，也暴露中国沿海和内地权益的可争夺性。列强看到日本通过战争取得领土、赔款和通商权益，随即加快在中国攫取港湾、铁路和矿权。[^bickers]

三国干涉还辽表明列强可以共同限制日本，但这并不意味着它们尊重中国主权。俄国阻止日本占有辽东后，很快转向自己在东北取得旅顺、大连；德国则借山东教案进入胶州湾；英法也为维持自身利益取得租借地或扩大既有据点。[^macmurray]

美国没有取得传统意义上的租借地，但担心列强瓜分中国市场，因而提出“门户开放”政策，要求各国在各自势力范围内维持商业机会和中国关税行政的形式完整。[^hay]

# 直接原因

第一，甲午战败使清朝国际地位急剧下降，列强判断中国难以有效抵抗港湾和权益要求。

第二，列强彼此竞争需要据点。港湾可以停泊舰队，铁路和矿权可以控制内地资源，贷款和顾问权可以影响财政和行政。

第三，个别事件成为借口。德国以巨野教案为契机强占胶州湾；俄国以远东战略需要取得旅顺、大连；英国和法国也以均势或既有利益为名扩大在华权益。[^bickers][^macmurray]

# 根本原因

根本原因是帝国主义列强在全球扩张中把中国纳入势力分割体系，而清朝缺少维护主权和资源开发权的国家能力。

租借地和势力范围不是孤立港口问题。它们背后是海军基地、铁路走向、矿产开采、贷款控制、关税收入和外交保护等一整套权力安排。列强不一定直接吞并大片中国领土，却通过“租借”“优先权”“不得让与他国”等方式限制清政府自主。

清朝在甲午后财政困难、军力不足、政治保守和外交被动，难以拒绝列强要求。列强之间的相互牵制有时避免了中国被某一国独占，却没有真正保护中国主权。

# 经过

## 德国进入胶州湾

1897 年巨野教案后，德国派兵占据胶州湾，并在 1898 年取得胶州湾租借权及山东铁路、矿权相关利益。山东由此成为德国势力范围的重要区域。[^macmurray][^bickers]

## 俄国租借旅顺大连

俄国在三国干涉还辽后继续推进东北利益，1898 年取得旅顺口和大连湾租借权益，并推动中东铁路、南满方向权益。辽东从“还给中国”转为俄国势力深入东北的前沿。[^macmurray]

## 英法扩大据点

英国在 1898 年租借威海卫，并展拓香港新界；法国取得广州湾租借地。英法举动既服务本国海军、贸易和殖民利益，也与俄、德、日等国在华扩张形成相互牵制。[^macmurray]

## 门户开放

1899-1900 年，美国国务卿海约翰提出门户开放照会，主张各国在中国保持贸易机会、尊重既有关税安排和中国领土行政的形式完整。美国国务院历史办公室将其概括为美国在列强势力范围竞争中维护商业机会的政策。[^hay]

# 结果

中国沿海和内地权益被进一步切割。租借地在形式上仍可被说成有期限租借，但实际由列强长期控制，成为海军、贸易、行政和殖民影响的据点。

势力范围使铁路、矿权、贷款和投资带有强烈排他性。清政府在名义上仍统治全国，实际经济和战略空间不断受限。

门户开放政策没有消除列强在华特权。它主要反对排他性瓜分市场，并不等于反对不平等条约体系本身。[^hay]

# 影响

## 对国家的影响

租借地和势力范围严重压缩中国主权。港湾、铁路和矿权被列强控制，使清朝在军事防御、资源开发、交通规划和财政安排上受制于人。

## 对人民的影响

地方民众面对土地征用、铁路修筑、矿权开发、教会扩张、治外法权和外军驻扎，社会冲突更容易激化。山东、华北等地民间反洋情绪上升，与后来义和团运动有密切背景联系。[^bickers]

## 对政治思想的影响

列强瓜分危机强化救亡意识。维新派、立宪派、革命派都把甲午后租借地和势力范围视为国家濒危的证据，改革和革命话语因此更具紧迫性。

# 历史评价

列强租借地与势力范围不是正常商业投资，而是不平等国际秩序下的权益攫取。它们以条约、租借、贷款和铁路矿权形式出现，却实质改变中国主权和地方治理。

同时，这一事件也说明列强并非铁板一块。俄、德、英、法、日、美之间既竞争又妥协，中国有时能利用矛盾暂缓某些压力，但在自身国家能力不足时，列强矛盾并不能转化为真正安全。

# 与前后事件的关系

它上承甲午战败、三国干涉还辽和《马关条约》。日本从中国取得巨大利益，列强随即以均势和补偿逻辑进入中国权益竞争。

它下启义和团运动和八国联军侵华。租借地、铁路、教案、教会和外军存在加剧地方社会紧张，最终与民间反洋运动、清廷决策失衡和列强军事干涉连在一起。
