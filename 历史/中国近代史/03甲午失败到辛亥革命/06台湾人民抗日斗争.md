# 摘要

台湾人民抗日斗争，主要指 1895 年《马关条约》割让台湾、澎湖后，台湾士绅、清军残部、地方团练和民众抵抗日本接收与殖民统治的斗争。日本军队自北向南推进，台湾抵抗力量经历台北、新竹、苗栗、彰化、嘉义、台南等阶段，最终在 1895 年秋后被日本压制。[^macmurray][^davidson]

**关键词**：台湾割让、乙未战争、台湾民主国、唐景崧、刘永福、丘逢甲、徐骧、吴汤兴、姜绍祖、日本接收台湾。

这一事件的核心意义，在于割地不只是条约纸面上的领土转移，而会立即落到人民的身份、家园和政治归属上。台湾人民抗日斗争把《马关条约》的屈辱转化为直接的反侵略行动，也成为近代中国反割地、反殖民记忆的重要组成部分。[^lamley][^hsu]

# 背景

《马关条约》将台湾全岛及附属岛屿、澎湖列岛割让给日本。对清廷而言，这是战败议和中的领土让步；对台湾居民而言，则意味着未经当地人民同意，家园和政治归属被条约改变。[^macmurray]

台湾在晚清已设省不久，地方社会由移民社群、原住民群体、士绅、团练、商人、清军和地方官署交织构成。社会整合并不充分，但面对割台和日本接收，许多地方力量形成临时抵抗。[^lamley]

日本在甲午战争中已经占领澎湖，并在条约后准备接收台湾。其目标不是单纯完成军事占领，而是建立长期殖民统治。

# 直接原因

第一，《马关条约》割让台湾、澎湖，直接引发台湾社会对割地的拒绝和抵抗。

第二，清廷在条约后要求台湾交接，日本则派军登陆接收。台湾本地力量无法接受在没有参与谈判的情况下被转交给日本。[^davidson]

第三，部分清军、黑旗军、地方团练和士绅希望通过军事抵抗、政治宣示或等待外援来阻止日本占领。

# 根本原因

根本原因在于甲午战败导致清朝无法保护台湾，而日本把台湾视为殖民扩张的重要目标。

台湾人民抗日斗争不是独立于中国近代危机之外的地方事件。它的直接背景是清朝战败和割地，深层背景则是东亚帝国主义扩张、近代国家能力差距和台湾社会自身的地方动员结构。

同时，台湾地方社会的抵抗力量成分复杂：有维护清朝归属的士绅和官员，有地方团练和义军，有黑旗军残部，也有普通民众出于保家、避乱和反外来统治而参与。其目标并不完全一致，但共同面对日本接收。

# 经过

## 割台与政治宣示

《马关条约》签订后，台湾士绅和部分官员反对割台。唐景崧等人在台北成立“台湾民主国”形式的政权，试图以政治宣示争取抵抗空间和外部注意。该政权持续时间很短，但反映了台湾社会对割让的强烈反应。[^davidson][^lamley]

## 日本登陆与北部失守

1895 年 5 月下旬，日本军队在台湾北部登陆，随后攻占基隆、台北等地。唐景崧离台后，北部抵抗迅速转入地方武装和义军层面。

## 中南部抵抗

日军继续南下，在新竹、苗栗、彰化、嘉义、台南等地遭遇地方义军、团练、清军残部和黑旗军抵抗。徐骧、吴汤兴、姜绍祖等地方抗日人物在中部抵抗中具有代表性，刘永福则在台南一带坚持抵抗。[^davidson]

## 抵抗被压制

由于武器、训练、补给、统一指挥和外援不足，台湾抗日力量难以长期抵挡日本正规军。1895 年秋后，台南失守，主要有组织抵抗结束，日本殖民统治逐步建立。

# 结果

台湾主要有组织抗日抵抗在 1895 年被日本压制，日本开始在台湾建立殖民统治。台湾和澎湖从此脱离清朝统治，直到 20 世纪中期才结束日本殖民时期。

抗日失败并不意味着抵抗意义消失。它使台湾割让不再只是外交文本，而成为人民反对殖民接收的历史行动，也为后来台湾社会的抗日记忆提供重要源头。

# 影响

## 对国家的影响

台湾割让和抗日失败说明清朝已经无力保护边疆海岛和人民。国家主权损失不只发生在朝廷和条约之间，也表现为地方社会被迫面对外来统治。

## 对人民的影响

台湾人民直接承受战争、占领和殖民治理。许多抵抗者牺牲，普通居民则面对政权更替、治安压力、征发、迁徙和生活秩序重组。

## 对民族记忆的影响

台湾人民抗日斗争强化了近代中国反割地、反殖民的历史记忆。它提醒后人，领土主权不是抽象地图，背后是具体人民的身份、家园和生活。

# 历史评价

台湾人民抗日斗争具有明确的反侵略和反殖民意义。虽然抵抗力量组织松散、目标复杂、军事条件不足，但其基本动因是反对战败条约强行改变台湾归属。

也要看到它的局限。台湾地方社会缺少统一指挥和稳定外援，清廷已决定按条约交割，日本则拥有正规军和殖民国家机器。抵抗失败是力量对比和国家保护能力崩溃的结果，不应被简单解释为地方抵抗意志不足。

# 与前后事件的关系

它上承《马关条约》。割让台湾和澎湖是斗争的直接原因，没有条约割地，就不会出现 1895 年日本接收与台湾反接收的冲突。

它下启日本在台湾的殖民统治，也与列强租借地和势力范围共同说明：甲午战败后，中国主权危机从条约口岸扩大到领土、殖民、铁路、矿权和地方社会各层面。
