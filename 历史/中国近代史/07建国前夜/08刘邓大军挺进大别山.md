# 摘要

刘邓大军挺进大别山，是 1947 年晋冀鲁豫野战军主力在刘伯承、邓小平指挥下强渡黄河、南下大别山的战略行动。它标志人民解放军由战略防御逐步转入战略进攻，把战争推向国民党统治区腹地，对南京、武汉之间的中原战略地带形成压力。[^pla-history][^westad]

这一行动的意义不在于大别山根据地立即稳定，而在于它迫使国民党军调整部署，打乱其重点进攻节奏，并与陕北、山东等方向作战形成战略配合。它也是解放战争从“守住根据地”转向“把战场推向对方腹地”的关键节点。[^westad]

**关键词**：刘邓大军、刘伯承、邓小平、晋冀鲁豫野战军、大别山、战略进攻、解放战争。

# 背景

1947 年上半年，国民党军在全面进攻受挫后，转向对陕北和山东等解放区的重点进攻。中共中央和解放军需要寻找办法，减轻被重点进攻地区压力，并把战争主动权从根据地防御转向外线进攻。[^westad]

晋冀鲁豫野战军位于华北和中原之间，具备南下中原的战略条件。大别山地处鄂豫皖交界，靠近国民党统治区腹地，既可威胁长江中游和南京、武汉之间的联系，也能为中原战场打开新局面。[^pla-history]

# 直接原因

第一，国民党对陕北和山东的重点进攻需要被牵制。刘邓大军南下，可以迫使国民党从其他方向抽调兵力回援中原。

第二，解放军需要从战略防御转向战略进攻。长期在根据地内防守，容易被敌方掌握战场选择权；向大别山挺进，则把战场推到国民党统治区深处。[^westad]

第三，大别山地区具有山地条件和革命活动基础，适合建立新的战略支点，但同时也面临远离后方、补给困难和敌军围攻的风险。

# 根本原因

刘邓大军挺进大别山的根本原因，是解放战争力量对比开始发生变化后，中共需要通过外线作战夺取战略主动。

战争初期，国民党军依靠城市、交通线和正规军优势发动进攻；经过一年多作战后，国民党军兵力被拉长，财政和士气压力上升，解放军则在运动战、根据地动员和土地改革支持下保存并发展力量。此时单纯防御已经不能充分利用形势变化，主动进入中原腹地成为改变全国战局的选择。[^westad][^lary]

# 经过

## 强渡黄河

1947 年夏，刘伯承、邓小平率晋冀鲁豫野战军主力南下，强渡黄河，进入鲁西南地区作战。强渡黄河本身具有战略宣示意义：解放军不再只在北方根据地内应战，而是开始向国民党统治区腹地推进。[^pla-history]

## 鲁西南作战

南下部队在鲁西南地区与国民党军作战，争取打开南进通道。通过机动作战，部队突破阻拦，继续向大别山方向推进。

## 进入大别山

部队进入大别山后，面临远离后方、补给困难、地方环境复杂和国民党军围攻等问题。挺进大别山不是轻松开辟根据地，而是在艰苦条件下建立战略支点。[^pla-history]

## 战略配合展开

刘邓大军南下后，陈粟、陈谢等部也在相关方向展开行动，形成多路外线出击格局。国民党军不得不调整兵力部署，原有重点进攻节奏受到影响。[^westad]

# 结果

刘邓大军成功把主力推进到大别山地区，完成从内线防御向外线进攻的战略突破。虽然部队在大别山面临补给和生存困难，建立稳定根据地并不容易，但其战略牵制作用已经显现。[^pla-history]

全国战局上，国民党军重点进攻的节奏被打乱，中原地区重新成为主要战场之一。解放军由此逐步形成多路战略进攻态势，为后来三大战役前的力量变化创造条件。[^westad]

# 影响

短期看，挺进大别山减轻了陕北、山东等方向压力，迫使国民党军分兵应对。它也提高了解放军主动选择战场的能力。

长期看，这一行动象征解放战争战略阶段的变化。解放军不再只是保存根据地和抵御进攻，而开始主动进入国民党统治区腹地，推动战争从局部防御转向全国范围的战略进攻。

对大别山地区民众而言，战争进入本地带来政治动员、支前任务和军事压力。战略意义背后，也有普通人承担的粮食、运输、安全和生活成本。

# 历史评价

刘邓大军挺进大别山是一次高风险战略行动。它牺牲了靠近后方的补给便利，换取对国民党腹地的战略压力。评价它时，不能只看大别山根据地建设的艰苦，也要看其对全国战局和国民党部署的牵制效果。

从战略史角度看，它标志解放军开始主动改变战场位置。战争的主线由“国民党进攻解放区”逐渐转为“解放军把战争推向国民党统治区”，这对后来的战略决战具有前导意义。

# 与前后事件的关系

刘邓大军挺进大别山上承全面内战爆发后的战略防御和土地改革形成的动员基础。没有前期根据地支撑和部队保存，南下进攻难以实现。

它下启解放军战略进攻和三大战役前的力量转变。大别山行动与其他外线出击共同迫使国民党军分散兵力，为后续全国战局逆转创造条件。
