# 摘要

南京国民政府形式统一，通常指 1927 年南京国民政府成立后，经清党、宁汉合流、继续北伐、占领北京和各地政治承认，到 1928 年前后成为名义上的全国中央政权。其“形式”二字很关键：南京政府在外交承认、首都、国旗和中央名义上取得优势，但地方实力派、财政分散和军队私属问题并未真正解决。[^cambridge][^taylor]

这一事件既结束了北洋政府作为中央政权的历史，也开启了所谓“南京十年”的国家建设尝试。它为关税、金融、交通、教育和行政建设提供了中央框架，却也把国民党内部派系、地方军政集团和中共武装斗争纳入同一个不稳定国家结构中。[^eastman][^jordan]

**关键词**：南京国民政府、北伐、宁汉合流、北洋政府、形式统一、南京十年、党国体制、地方实力派。

# 背景

北伐战争打破了北洋军阀分裂格局。国民革命军从广东北上，先后击败吴佩孚、孙传芳等势力，并向华北推进。北伐的政治目标是“打倒军阀、统一中国”，但它同时依赖各路地方军事力量和国民党内部复杂派系。[^jordan][^cambridge]

1927 年，国共合作破裂，国民党内部也出现南京、武汉等中心的分裂。南京国民政府在蒋介石等推动下成立，并以清党、军事整合和金融工商支持为基础建立东南政权。随后宁汉合流，国民党政权逐步重新整合。[^taylor][^eastman]

北京仍由北洋体系控制，东北由奉系张作霖势力掌握。南京政府要成为全国中央政权，必须在军事上结束北洋政府，在政治上争取地方实力派承认，并在外交上取得列强承认。[^cambridge]

# 直接原因

第一，北伐后期国民革命军取得华北战场优势，北洋政府失去继续维持中央名义的军事和政治基础。1928 年张作霖退出北京后，北洋政府体系实际瓦解。[^jordan][^taylor]

第二，国民党各派在宁汉分裂后重新合流，使南京政权具备以国民党中央和国民政府名义整合全国的组织条件。[^eastman]

第三，地方实力派在北伐胜负已定后需要选择承认新的中央政权，以保留本地军政利益并参与全国政治分配。南京政府的统一因此带有妥协和承认性质，而不只是军事征服。[^cambridge]

# 根本原因

南京国民政府形式统一的根本原因，是北洋军阀体系失去全国合法性，而国民党通过北伐和党国组织提供了新的中央政权框架。

从国家结构看，辛亥革命后中国长期存在中央虚弱、地方军队割据和财政分散。北洋政府虽拥有中央名义，但无法稳定整合地方实力派。北伐的成功，说明旧中央已经无法继续维持全国秩序。[^cambridge]

从政党政治看，国民党比旧军阀集团更重视党务、宣传、军校、行政和群众动员，能够以“革命政党建国”的方式重塑中央权威。南京国民政府的统一，是党国体制取代北洋议会和军阀平衡的过程。[^eastman]

从社会和国际环境看，商人、知识界和部分地方势力都希望结束长期内战和军阀混战。列强也需要一个可交涉的中央政府处理关税、债务和外交问题，这为南京政府取得承认提供了外部条件。[^taylor]

# 经过

## 南京政权建立

1927 年，南京国民政府成立。它以东南财政、国民革命军嫡系和国民党右派政治力量为基础，同时通过清党与中共分裂，确立自身反共和党国统治方向。[^taylor][^eastman]

## 宁汉分裂与合流

武汉国民政府一度与南京对立，但国共合作破裂后，武汉方面也转向分共。国民党内部经过重组，宁汉合流使国民政府重新具备全国党政名义。[^cambridge]

## 继续北伐

1928 年，国民革命军继续北伐。各路军队向华北推进，张作霖退出北京后在皇姑屯被炸身亡，北京随后由国民党方面控制并改称北平。北洋政府作为中央政权的历史至此结束。[^jordan][^taylor]

## 取得中央名义

南京国民政府以国都、国旗、中央机构和外交承认确立新的中央政权名义。各地实力派大多在保留自身军政利益的条件下承认南京，东北最终通过东北易帜纳入形式统一框架。[^cambridge]

# 结果

南京国民政府成为名义上的全国中央政府。北洋政府结束，北京改称北平，南京作为国都的政治地位确立。[^jordan][^taylor]

国家建设获得新的制度平台。南京政府推动关税自主、币制金融、交通建设、教育行政和城市治理等政策，形成后来所说的“南京十年”面貌。[^eastman]

但统一主要是形式上的。地方实力派仍掌握军队、地盘和财政，中央对西南、西北、华北和东北的控制程度不一。中原大战很快证明，地方军政集团仍能发动全国性战争。[^cambridge][^taylor]

# 影响

南京国民政府形式统一结束了北洋时期多中心中央名义竞争，为中国重建统一外交、关税谈判和中央行政提供条件。对外关系中，中国至少拥有一个较稳定的交涉主体。[^eastman]

它也带来党国体制的强化。国民党把政党、政府和军队结合在一起，以训政名义组织国家。这个体制比北洋政府更有动员和行政能力，但也压缩了政党竞争、地方自治和社会运动空间。[^cambridge]

对中共而言，南京政府的统一意味着新的强敌形成。南昌起义、秋收起义和根据地建设都发生在国民党新中央清剿和围压的背景下。形式统一越推进，国共之间的军事竞争越制度化。

# 历史评价

南京国民政府形式统一有积极意义：它结束了北洋政府中央名义和长期军阀混战的一个阶段，为现代国家建设提供了框架。关税、金融、交通和教育等领域的建设，不能简单被内战叙事抹去。[^eastman]

但它的局限同样明显。统一并没有彻底解决军队国家化、财政集中、地方治理和政治包容问题。国民党内部派系和地方实力派仍然以军队为政治资本，中央权威很大程度建立在妥协、收编和军事压力之上。[^taylor]

因此，“形式统一”是准确表述：南京政府获得了国家外壳和中央名义，但统一国家的实际能力仍在形成中。这个矛盾贯穿中原大战、对中共围剿以及九一八事变后的对日政策。

# 与前后事件的关系

南京国民政府形式统一上承北伐战争和国共合作破裂。北伐打倒北洋中央，清党则决定新政权的反共方向。

它直接下启东北易帜。没有东北承认南京，形式统一仍缺少东北这一关键区域；东北易帜使全国名义统一更完整。[^cambridge]

它也下启中原大战和九一八事变。前者暴露国内整合不彻底，后者则考验形式统一国家在外部侵略面前的实际动员和防卫能力。
