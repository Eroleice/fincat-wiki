# 摘要

三湾改编是 1927 年秋收起义余部在江西永新三湾村进行的部队整顿。改编的核心，是在失败和减员后重建部队组织、加强党对军队的领导、把党支部建立到基层连队，并通过士兵委员会等方式改善军队内部关系。[^ccp-history][^short-history]

它不是一次规模很大的战役，而是早期红军组织史上的关键节点。三湾改编使一支受挫、成分复杂、纪律不稳的起义部队转向更有政治组织能力的革命军队，为井冈山根据地和后来的古田会议提供了直接经验。[^averill][^cambridge]

**关键词**：三湾改编、毛泽东、秋收起义、支部建在连上、士兵委员会、党对军队领导、红军组织建设。

# 背景

秋收起义原计划进攻长沙，但起义部队很快受挫。部队减员、士气波动、成分复杂、指挥不稳等问题集中暴露。如果不及时整顿，起义余部很可能在转移途中瓦解。[^short-history]

当时中共尚缺乏成熟的独立建军经验。南昌起义和秋收起义都显示，单纯把旧军队或地方武装拉入革命阵营，并不能自动形成纪律严明、政治目标清楚的革命军队。军队内部的党组织、士兵关系、干部制度和纪律问题必须重新设计。[^ccp-history][^cambridge]

三湾村位于秋收起义余部向井冈山转移的途中。部队在这里停留整顿，既是军事形势所迫，也是组织建设的主动选择。[^averill]

# 直接原因

第一，秋收起义受挫后，部队需要缩编和重组。原有建制与实际兵力不匹配，继续维持虚弱编制会影响指挥和补给。[^short-history]

第二，部队成分复杂，旧军队习气、军官与士兵关系、逃亡和纪律问题影响战斗力。要在农村山区长期生存，必须建立新的组织纪律。[^ccp-history]

第三，毛泽东等领导人已经认识到，革命军队必须由党直接掌握，而不能只依靠军事长官个人影响或临时政治动员。[^averill]

# 根本原因

三湾改编的根本原因，是中共早期武装斗争需要解决“谁领导军队、军队怎样组织、士兵为什么作战”的问题。

从政治上看，国共合作破裂后，中共不能再依赖国民革命军体系中的合法地位。独立武装必须有自己的政治核心和组织系统。[^cambridge]

从军事上看，弱小部队若无严密组织和纪律，很难在敌强我弱、补给困难和频繁转移中生存。党组织下沉到连队，有助于把政治动员、纪律执行和军事行动结合起来。[^short-history]

从社会上看，红军要在农村获取群众支持，就必须改变旧军队扰民、军官压迫士兵和军纪松弛的形象。军队内部民主和群众纪律，成为根据地政治合法性的一部分。[^averill]

# 经过

## 缩编部队

三湾改编首先对起义余部进行整编。由于兵力损失和组织混乱，部队由原有较大编制缩编为更适合实际指挥和行动的建制，减少空架子，提高机动性。[^short-history]

## 建立基层党组织

改编的重要内容，是把党组织建到连队基层。党支部进入连队，使政治领导不再停留在上层机关，而能直接影响士兵教育、干部监督、纪律执行和战斗动员。[^ccp-history]

## 改善官兵关系

三湾改编还建立士兵委员会等制度，强调官兵平等和士兵参与。其目的不是把军队变成松散团体，而是在旧军队等级压迫之外建立新的内部凝聚力。[^short-history]

## 向井冈山转移

改编后，部队继续向井冈山地区转移。三湾改编没有立即解决所有问题，但使起义余部具备更强的组织稳定性，为进入井冈山和建立根据地创造条件。[^averill]

# 结果

三湾改编使秋收起义余部在严重挫折后保存下来。缩编、建党支部、建立士兵委员会和加强纪律，使部队组织稳定性明显提高。[^short-history]

改编为井冈山根据地建设提供了组织基础。部队进入井冈山后，需要处理地方武装、农民动员、土地政策和敌军围剿等问题，基层党组织和纪律建设成为红军立足的重要条件。[^averill]

从制度结果看，三湾改编被后世视为中共党对军队绝对领导原则的早期实践之一。它还没有形成完整军事制度，但已经提出红军区别于旧军队的关键组织方向。[^ccp-history]

# 影响

三湾改编的直接影响，是防止起义余部瓦解。对于一支刚刚失败、兵力减少、前途不明的部队而言，组织整顿本身就是保存革命力量的前提。[^short-history]

它还改变了军队政治结构。党组织下沉到连队，使政治工作能够覆盖基层士兵，而不是只依赖上级命令。这个原则后来在古田会议中得到更系统阐发。[^ccp-history]

长期看，三湾改编是红军建军传统的重要组成部分。它把“军队服从党的政治目标”“士兵是政治主体”“军纪关系群众支持”等问题放到一起，影响中共军队建设和根据地治理。[^cambridge]

# 历史评价

三湾改编的积极意义，在于它以组织建设回应军事失败。它没有把失败只归结为兵力不足，而是看到起义部队必须改造成有政治方向、基层组织和群众纪律的军队。[^averill]

它的局限在于，当时仍是应急状态下的初步改编，很多制度尚未稳定，军事训练、补给、干部培养和战略路线仍需在井冈山和赣南闽西实践中继续完善。

从近代史角度看，三湾改编说明中共早期武装斗争的关键不只是“有枪”，还包括如何把军队从旧式私人化、雇佣化、军阀化逻辑中改造出来。这正是土地革命阶段政党、军队和基层社会关系重组的核心问题之一。

# 与前后事件的关系

三湾改编上承秋收起义。秋收起义失败暴露了攻城路线和临时部队组织的弱点，三湾改编则直接回应这些问题。

它下启井冈山根据地。改编后的部队进入井冈山，并在根据地建设中检验党组织、士兵委员会和纪律建设的实际作用。[^averill]

它还与古田会议形成前后关系。三湾改编提出基层组织原则，古田会议则在红四军更复杂的实践中系统总结党军关系、政治工作和思想建党问题。[^short-history]
