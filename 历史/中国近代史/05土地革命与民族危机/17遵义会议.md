# 摘要

遵义会议是 1935 年 1 月中共中央在贵州遵义召开的政治局扩大会议。会议发生在第五次反围剿失败和长征初期湘江惨败之后，重点讨论军事指挥和中央领导问题，批评博古、李德等人在军事路线上的错误，并使毛泽东重新进入中央核心领导层。[^ccp-history][^kampen]

它通常被视为中共历史中的重大转折点。需要注意的是，遵义会议并非一天之内完成全部权力结构重组；毛泽东影响力的上升、军事指挥方式的改变和领导格局的稳定，是会议及其后续行军决策共同形成的结果。[^sun][^kampen]

# 背景

第五次反围剿失败后，中央红军被迫离开中央苏区。长征初期，红军携带大量机关和物资，行动迟缓，在突破封锁线和湘江战役中遭受重大损失。[^ccp-history][^sun]

这种危机使中共中央内部对军事路线和领导责任的不满集中爆发。此前，博古作为主要负责人，李德作为共产国际派驻军事顾问，对红军军事决策有重要影响；毛泽东等早期苏区领导人的运动战经验没有成为主导。[^kampen]

# 直接原因

第一，第五次反围剿失败和湘江惨败使红军面临生死存亡。若不调整指挥方式，继续被国民政府军围追堵截，中央红军可能被彻底消灭。[^sun]

第二，红军内部对阵地战、消耗战和机械执行外来军事方案的不满上升。许多领导人认识到，必须重新发挥机动作战和灵活指挥优势。[^ccp-history]

第三，长征途中远离共产国际直接指挥，客观上为中共中央独立讨论军事路线和领导问题提供了空间。[^kampen]

# 根本原因

遵义会议的根本原因，是中共在中央苏区失败后必须重建能够适应中国革命战争条件的领导和军事指挥。

从军事层面看，红军面对的是敌强我弱、围追堵截和地形复杂的局面，机械照搬正规战和阵地防御难以生存。[^sun]

从组织层面看，中共中央需要在危机中明确责任、调整领导关系，并恢复指挥系统的有效性。没有这种调整，长征很难从被动撤退转为主动机动。[^kampen]

从政治层面看，遵义会议意味着中共在重大决策上逐步减少对外部指令和教条化路线的依赖，开始更强调结合中国战争实际。[^ccp-history]

# 经过

1935 年 1 月，中央红军攻占遵义并获得短暂停留时间。中共中央政治局召开扩大会议，参加者包括博古、周恩来、毛泽东、张闻天、王稼祥、朱德等中央和红军领导人。[^ccp-history]

会议集中讨论第五次反围剿和长征初期军事指挥问题，批评博古、李德在军事指导上的错误。毛泽东、张闻天、王稼祥等提出对既有路线的批评，周恩来在军事领导责任问题上也作出检讨。[^kampen][^sun]

会议后，毛泽东被增补进入中央政治局常委，张闻天、毛泽东、王稼祥等人的影响上升。随后红军在四渡赤水、巧渡金沙江等行动中更强调机动和灵活指挥，逐步摆脱被动局面。[^ccp-history][^salisbury]

# 结果

遵义会议结束了博古、李德在军事指挥上的主导地位，使毛泽东重新进入中央核心领导层，并推动红军军事指挥由机械防御转向更灵活的机动作战。[^ccp-history][^kampen]

会议后，红军通过四渡赤水等行动摆脱被动，长征逐渐从仓促突围转向主动选择路线。遵义会议因此成为长征能否继续的重要转折点。[^salisbury][^sun]

从组织史看，遵义会议标志中共领导集体在危机中进行了自我调整。但后来的稳定领导格局还需经过扎西会议、苟坝会议、会理会议及长征后续过程继续形成。[^kampen]

# 影响

对中共而言，遵义会议确立了更重视中国革命战争实际的路线方向，成为后来党史叙事中“独立自主解决中国革命问题”的象征。[^ccp-history]

对长征而言，会议后的领导调整和战术变化直接影响红军能否摆脱围追堵截。四渡赤水等行动之所以被反复强调，正是因为它们展示了灵活机动作战的效果。[^salisbury]

对中国近代史而言，遵义会议使中共在长征中保存并重组了领导核心。这个领导核心后来在陕北、抗日民族统一战线和国共关系重组中发挥重要作用。[^kampen]

# 历史评价

遵义会议的积极意义，在于它在危急关头纠正了第五次反围剿以来的军事路线问题，提升了适合中国革命战争条件的领导经验。

评价时也要避免把后来的结果简单投射回会议现场。遵义会议确实是重大转折，但毛泽东领导地位的形成是一个过程，会议本身主要围绕军事路线和组织调整展开。

因此，遵义会议既是中共党史中的关键节点，也是理解长征从失败突围转向战略生存的核心事件。

# 与前后事件的关系

它上承第五次反围剿失败和长征初期损失。没有中央苏区失败和湘江惨败，领导路线问题不会以如此紧迫的方式爆发。[^sun]

它下启长征后半程的机动转移。遵义会议后的四渡赤水、巧渡金沙江等行动，使红军逐步脱离被动，并最终转向陕北。[^salisbury]
