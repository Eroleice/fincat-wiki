# 摘要

伪满洲国成立，是指日本在九一八事变后占领中国东北，并于 1932 年 3 月扶植以溥仪为名义执政者的傀儡政权。该政权被日本用来包装其对东北的军事占领和殖民统治，但中国政府和国联李顿报告均不承认其合法性。[^lytton][^state-mukden]

伪满洲国的成立，使东北沦陷从军事占领转为制度化统治。日本通过傀儡政权、关东军、南满铁路和移民、资源开发、警察宪兵体系，把东北纳入其帝国扩张结构。对中国而言，它是主权和领土完整遭受严重破坏的标志。[^coble][^mitters-war]

**关键词**：伪满洲国、满洲国、溥仪、关东军、九一八事变、东北沦陷、李顿报告、日本侵略。

# 背景

九一八事变后，日本关东军迅速占领东北。单纯军事占领容易暴露侵略性质，也难以长期处理行政、财政、治安和国际舆论问题。扶植一个名义上的“独立国家”，成为日本包装占领和管理东北的方式。[^coble]

溥仪作为清朝末代皇帝，具有满洲旧王朝象征。日本利用其身份，试图把东北从中国主权体系中切割出来，制造所谓“民族自决”和“复兴满洲”的政治叙事。[^mitters-war]

国际上，中国向国联申诉。国联调查团在东北实地调查后，承认日本在东北有利益，但不承认用武力制造的伪满洲国具有合法性。[^lytton]

# 直接原因

第一，九一八事变后日本已实际控制东北，需要把军事占领转化为可持续行政统治。伪满洲国提供了地方政府外壳。[^coble]

第二，日本希望削弱国际社会对侵略的指控。通过制造“独立国家”，日方试图把中日争端改写为东北内部政治变化。[^lytton]

第三，溥仪愿意接受日本安排，成为傀儡政权名义领袖。其身份为日本宣传提供象征资源，但实际权力受关东军和日本顾问体系控制。[^mitters-war]

# 根本原因

伪满洲国成立的根本原因，是日本要把对东北的军事占领制度化、合法化和殖民化。

从战略上看，东北为日本提供资源、工业基地、铁路网络、移民空间和对苏防御前沿。直接吞并成本高、国际压力大，傀儡政权成为更便于操作的形式。[^coble]

从政治上看，日本需要否定中国对东北的主权。伪满洲国以“独立”名义存在，实质上是把中国领土从中国国家框架中剥离。[^lytton]

从中国国内看，南京国民政府形式统一不足，东北地方军政与中央之间关系松散，九一八事变后缺少有效抵抗和收复能力，为日本扶植傀儡政权提供了现实条件。[^state-mukden][^taylor]

# 经过

## 东北占领后筹建

日军占领东北后，关东军和日本相关机构开始组织地方行政重建，吸收部分旧官僚、地方势力和亲日人员，筹备以“自治”“独立”为名的新政权。[^coble]

## 溥仪出任名义领袖

溥仪被日本带入东北政治安排中，1932 年伪满洲国成立后出任“执政”。1934 年，伪满洲国进一步改为帝制形式，溥仪称帝。[^mitters-war]

## 建立统治体系

伪满洲国表面上拥有政府、法律和行政机构，实际关键权力掌握在关东军、日本顾问和日方控制的经济军事机构手中。警察、宪兵、情报和资源开发体系服务于日本统治。[^coble]

## 国际反应

国联李顿报告不承认日本以武力造成的东北现状和伪满洲国合法性。国联大会采纳相关立场后，日本走向退出国联，国际集体安全机制的无力进一步暴露。[^state-mukden][^lytton]

# 结果

日本对东北的占领被制度化。伪满洲国建立行政、警察、财政和经济管理体系，使军事占领转化为长期殖民统治结构。[^coble]

中国东北主权被严重破坏。伪满洲国把东北从中国国家框架中强行切割出去，成为日本侵略中国和扩张大陆政策的基地。[^mitters-war]

国际社会虽不普遍承认伪满洲国，但未能有效制止日本。国联机制的失败削弱了中国对国际调停的期待，也助长日本继续冒险。[^state-mukden]

# 影响

伪满洲国成立加深了中国民族危机。九一八事变是军事侵略，伪满洲国则把侵略结果制度化、行政化，使东北人民长期处于殖民统治、资源掠夺和政治控制之下。[^coble]

它推动中国抗日救亡舆论扩大。东北沦陷和伪满洲国成立使“亡国灭种”危机更具体，学生、知识界、媒体和社会团体要求抵抗日本的声音增强。[^mitters-war]

它也影响国际秩序。国联无法制止日本建立傀儡政权，显示一战后集体安全体系面对侵略国家时缺乏强制力。这一失败与 1930 年代全球危机相互呼应。[^state-mukden]

# 历史评价

伪满洲国不是正常国家独立的结果，而是日本关东军在武力占领基础上扶植的傀儡政权。它的存在以否定中国东北主权为前提，政治合法性不能脱离九一八事变和日本军事控制来理解。[^lytton]

从中国近代史看，伪满洲国是民族危机制度化的标志。它不仅夺走土地，还试图通过行政、教育、警察和经济体系改造东北社会，使侵略从战场推进到日常统治。

从国际关系看，伪满洲国事件说明国际承认与实际控制之间存在距离。即使国际报告否认其合法性，只要缺乏有效制裁和军事压力，侵略者仍可能维持既成事实。

# 与前后事件的关系

伪满洲国成立直接上承九一八事变。没有关东军制造事变和迅速占领东北，就没有伪满洲国的政治外壳。[^state-mukden]

它下启更深的华北危机和抗日救亡运动。日本在东北建立傀儡政权后，继续向热河、长城和华北施压，中国社会对停止内战、一致抗日的呼声不断增强。[^coble]

在第五阶段主线中，伪满洲国成立标志民族危机从军事事件变成长期政治现实。它迫使中国各政治力量重新面对一个问题：在国家主权被直接破坏时，内部政权竞争还能否继续压过抗日救亡。
