# 摘要

翟婉明是铁路工程动力学专家、中国科学院院士，长期从事车辆-轨道耦合动力学和高速铁路安全运行相关研究。把他放入“中国脊梁”，是因为高速铁路不只是土建和列车制造问题，更是轮轨相互作用、振动、平顺性、可靠性和长期运维共同构成的系统科学问题。[^zhai-casad]

# 时代难题

列车速度提高后，铁路问题不再只是“轨道够不够坚固”。轮轨作用、车辆振动、轨道不平顺、桥隧结构和运行环境会耦合放大，影响安全、舒适和维护成本。中国高铁网络快速扩大，使这类动力学问题从学术研究变成国家交通系统的基础问题。

# 突破过程

翟婉明的贡献，在于把车辆和轨道作为耦合系统研究，而不是孤立分析车辆或线路。高速铁路需要通过模型、试验、仿真和现场数据相互校验，才能回答“能否安全运行”“能否长期稳定运行”“如何维护最经济”这些问题。其研究为高速铁路设计、评估和运维提供了理论工具。

# 与世界先进水平的比较

中国高铁从追赶到大规模成网，必须补齐动力学、检测、维护和标准体系。白皮书记录了中国高速铁路网络规模和交通基础设施发展成果。[^transport-white-paper] 翟婉明的意义，是在高速铁路从工程建设转向长期运营阶段，提供与世界先进轨道交通相匹配的理论支撑。

# 关键成果与影响

车辆-轨道耦合动力学的影响并不总是直接体现在某座桥或某列车上，但它决定高速铁路运行品质和安全边界。翟婉明的研究支撑了高速铁路工程从“建成通车”向“长期安全、高速、平稳运行”转变。

# 方法、品格与组织能力

翟婉明的研究方法强调系统耦合：车辆、轨道、结构和运行条件不是互不相关的部件，而是动态互动的整体。对中国高铁而言，这种方法能把工程经验上升为可计算、可验证、可复用的科学模型。

# 历史评价

翟婉明代表的是中国高速铁路背后的基础科学能力。没有动力学、安全评估和长期运维理论，高速铁路就难以稳定成网。其“中国脊梁”意义，在于为国家重大交通系统提供了不显眼却关键的理论底座。

# 相关人物与事件

相关人物包括何华武、孙永福、王梦恕。相关事件包括中国高速铁路网络形成、车辆-轨道耦合动力学研究和高速铁路长期运维体系建设。
