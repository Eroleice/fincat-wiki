# 摘要

李振声是中国科学院院士，小麦遗传育种专家。他的代表性贡献，是把小麦与其近缘野生植物的远缘杂交研究推进到可用于生产的育种体系，形成“小偃”系列小麦品种。中国科学院院士资料列明，他长期从事小麦遗传育种研究，曾获2006年度国家最高科学技术奖；中国政府在2024年授予他“共和国勋章”。[^li-cas][^li-order]

# 时代难题

新中国粮食生产长期面对高产、抗病、抗逆和稳产的综合约束。小麦作为主粮作物，常规育种能逐步改良产量，但在抗病、耐逆等性状上容易遇到遗传资源瓶颈。远缘野生植物保存着重要基因资源，难点在于能否跨过生殖隔离，把有利性状稳定转入普通小麦。

# 突破过程

李振声选择偃麦草等近缘植物作为小麦改良材料，通过远缘杂交、染色体工程和连续选择，把野生亲缘植物的抗病、抗逆等性状导入小麦。这个过程周期长、失败率高，需要从细胞遗传学到田间选择连续推进。小偃系列品种的形成，说明远缘杂交不只是理论实验，也可以进入生产育种。

# 与世界先进水平的比较

国际作物育种早已重视野生亲缘资源，但把远缘杂交稳定转化为主粮品种，需要长期材料积累和区域适应性试验。李振声的贡献在于，在中国黄淮、关中等小麦产区需求下，把细胞遗传学方法与大田育种目标结合，使中国小麦育种在野生资源利用方面形成自主体系。这里应避免说他“独自解决粮食问题”，更准确的是，他扩展了中国小麦育种可利用的遗传资源边界；中国科学院资料支持的是其小麦遗传育种和远缘杂交贡献，而非“世界首创”式表述。[^li-cas]

# 关键成果与影响

小偃系列品种及相关材料为提高小麦产量和抗逆能力提供了重要支撑。李振声的工作还推动了中国作物育种从经验选择向遗传资源发掘、材料创制和品种应用相结合的方向发展。对粮食安全而言，这类成果的意义在于增强主粮作物面对病害、气候和产量压力时的技术储备。

# 方法、品格与组织能力

李振声的方法特征是“慢变量”研究：不追求短期可见的单点突破，而是长期建设材料、鉴定性状、回交改良和生产验证。他的组织能力也体现在把基础遗传研究、育种单位和产区试验连接起来，让实验室材料最终经得起田间检验。

# 历史评价

李振声的历史位置，是中国小麦远缘杂交育种从探索走向应用的代表人物。其贡献不是一个品种的命名，而是把野生亲缘资源引入主粮育种体系，形成能够持续服务国家粮食安全的技术路线。
