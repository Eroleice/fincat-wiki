# 摘要

王梦恕是隧道及地下工程专家、中国工程院院士，长期从事铁路隧道、城市地下工程和复杂地质条件下施工技术研究。将其纳入“中国脊梁”，重点在于记录中国基础设施从平原路基、普通桥隧，走向山区、高原、城市地下空间和高速铁路复杂工程的过程。[^wangms-ysg]

# 时代难题

中国交通基础设施扩展到山区、高原和大城市后，隧道与地下工程成为绕不开的能力瓶颈。线路要穿山越岭，城市轨道要穿越密集建成区，高速铁路又对沉降、变形和安全余量提出更高要求。王梦恕面对的不是单个洞口，而是一整套地下工程风险控制问题。

# 突破过程

王梦恕的工作强调施工方法、地质判断和工程安全的结合。隧道工程的困难在于“不可见”：围岩、水文、断层、沉降和既有建筑影响常常在施工中不断暴露。其贡献在于推动适合中国复杂条件的地下工程技术和工程经验积累，使隧道建设从经验施工走向更系统的设计、监测和风险控制。

# 与世界先进水平的比较

与欧洲、日本等较早发展现代隧道和城市轨道工程的地区相比，中国起步较晚，但建设规模和复杂场景增长极快。白皮书显示，中国交通基础设施在铁路、公路、城市交通等领域快速扩展。[^transport-white-paper] 王梦恕一代地下工程专家的意义，是在这种高强度建设需求中形成自主适应复杂地质和城市条件的工程能力。

# 关键成果与影响

隧道和地下工程的影响常常不如桥梁、列车醒目，却是现代交通网络能否穿越山河和城市的基础。王梦恕的贡献体现在铁路隧道、城市地下空间和工程安全技术积累中，为高铁、城市轨道和地下基础设施扩张提供技术支撑。

# 方法、品格与组织能力

地下工程需要对风险保持敬畏。王梦恕的工程方法可以概括为：重视地质、重视现场、重视监测和施工反馈。评价这类工程专家，不能只看理论论文，也要看其经验是否能转化为设计规程、施工组织和安全控制。

# 历史评价

王梦恕是中国隧道与地下工程能力提升中的代表人物。他的价值，在于把中国交通基础设施的“穿越能力”推向更复杂场景：山岭、城市、高速铁路和大规模地下空间。其贡献属于集体工程体系，但关键专家的判断会直接影响工程安全和技术路线。
