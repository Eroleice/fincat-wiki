# 摘要

潘家铮，水工结构工程和水利水电工程专家，中国科学院院士、中国工程院院士。中国工程院院士馆记载其 1927 年 11 月出生于浙江绍兴，2012 年 7 月 13 日逝世；1980 年当选中国科学院院士，1994 年当选中国工程院院士。[^pan-ysg]

他的贡献适合放在“水电工程技术奠基人”框架下理解：长期从事水工结构和水电工程技术工作，在设计、咨询、论证和工程技术路线选择中推动中国形成自主判断能力。[^pan-ysg][^pan-calendar]

# 时代难题

水电工程面对的是高坝、大流量、地质、移民、生态、发电和防洪等多重约束。对新中国来说，难题不仅是建成几座工程，更是建立能独立判断工程风险、方案优劣和长期运行安全的技术体系。

# 突破过程

潘家铮的履历显示，他从浙江钱塘江水电勘测处、北京水电总局到上海勘测设计院，长期处在水电工程设计和技术管理一线。院士馆列明其专业为水工结构工程（水利水电工程）专家，并列有国家科学技术进步奖、光华工程科技奖等工程科技奖励。[^pan-ysg]

中国科协之声相关栏目以“什么事为什么非得外国人先做，然后我们再做？”概括潘家铮的工程意识。这句话适合用作本页的保守评价：他的价值在于推动自主技术判断，而不是把任何单项大型水电工程都归功于个人。[^pan-calendar]

# 与世界先进水平的比较

与世界先进水平比较时，本页不使用未经核验的单项排名。更稳妥的说法是：潘家铮一代工程师面对的是从学习国外经验走向自主论证、设计和咨询的转变；这种转变让中国大型水电工程不再只是“等别人先做”的跟随工程。[^pan-calendar]

# 关键成果与影响

潘家铮的影响主要体现为水工结构理论、工程设计经验和重大水电工程咨询能力的积累。2005 年国家科学技术进步奖二等奖、2012 年光华工程科技奖成就奖，说明其长期工程科技贡献获得国家和工程界认可。[^pan-ysg]

# 方法、品格与组织能力

水电工程是高度集体性的事业。潘家铮的组织价值，更多体现在把专业判断放入工程总体目标中：安全、经济、施工可行、长期运行和公共利益需要共同权衡。这个特征也使他区别于只做单一技术环节的专家。

# 历史评价

潘家铮的历史位置，是中国大型水电工程技术体系中的重要奠基者和判断者。评价他需要保守：他不是一个人建成水电工程，却在水工结构和工程论证中提供了长期稳定的技术骨架。

# 相关人物与事件

相关事件包括浙江钱塘江水电勘测处、上海勘测设计院、大型水电工程技术咨询、国家科学技术进步奖和光华工程科技奖。
