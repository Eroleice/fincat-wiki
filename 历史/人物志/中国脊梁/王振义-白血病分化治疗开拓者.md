# 摘要

王振义是中国工程院院士、血液学专家。他在急性早幼粒细胞白血病（APL）治疗史上的关键贡献，是推动全反式维甲酸诱导分化治疗，使一种高度凶险的白血病进入可治愈疾病的轨道。中国工程院院士馆列明其研究方向包括早幼粒细胞白血病、诱导分化疗法和全反式维甲酸；中国政府在2024年授予他“共和国勋章”。[^wang-cae][^wang-order]

# 时代难题

APL曾是死亡风险很高的白血病亚型，早期患者常因出血和凝血异常迅速恶化。传统思路主要是杀伤白血病细胞，但毒性和疗效边界明显。王振义面对的难题，是能否让异常白血病细胞重新分化，而不是只靠更强烈的杀伤。

# 突破过程

王振义团队把维甲酸诱导细胞分化的基础线索推进到临床。1988年发表于《Blood》的研究报告显示，全反式维甲酸可诱导APL缓解。[^wang-atra] 这一突破背后有严格的临床观察、风险控制和团队协作。后来，维甲酸与三氧化二砷等治疗策略结合，使APL治疗进一步改善。王振义、陈竺等人的综述把APL概括为从高度致死走向高度可治的疾病模型。[^wang-blood-review]

# 与世界先进水平的比较

分化治疗的意义在于改变癌症治疗思路：不是只追求把癌细胞“杀光”，而是尝试纠正其分化阻滞。国际上对APL分子机制和靶向治疗的认识不断推进，王振义的工作则提供了从临床实践反向推动治疗范式变化的中国经验。与世界先进水平相比，这项成果不是跟随式应用，而是在特定白血病类型上形成了具有国际影响的原创临床策略。

# 关键成果与影响

全反式维甲酸治疗APL的成功，使白血病治疗从传统化疗扩展到诱导分化和分子靶向思路。它也为后续维甲酸、砷剂和风险分层治疗体系奠定基础。对中国医学史而言，王振义的贡献表明，临床医生在严密观察和机制理解之间往返，可以创造世界级治疗方案。

# 方法、品格与组织能力

王振义的工作方式强调病人需要、临床证据和基础机制的结合。他没有把临床经验停留在个案层面，而是通过规范观察、发表研究和培养团队，让治疗路径进入可被世界同行检验的医学文献。

# 历史评价

王振义是白血病分化治疗的开拓者。评价他的贡献，应同时看到瑞金医院、上海血液学研究团队以及国际基础研究的协作背景。个人的关键判断很重要，但真正改变疾病结局的是一个持续迭代的治疗体系。
