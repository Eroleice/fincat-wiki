# 摘要

宋文骢是中国工程院院士、飞机设计专家，中国工程院院士馆资料记载其长期从事飞机设计研究，并在歼-10 等型号研制中作出重要贡献。[^song-ysg] 歼-10 是中国自主研制第三代战斗机的重要节点。称宋文骢为“歼-10总设计师”，不是说一架飞机由一人完成，而是说明他在总体方案、技术取舍和跨专业组织中承担核心责任。

# 人物坐标

- 生卒：1930-2016。
- 领域：飞机总体设计。
- 主要身份：中国工程院院士，飞机设计专家，歼-10 总设计师。[^song-ysg]
- 主要成果取得年份：20 世纪 60 年代起参与战斗机设计；20 世纪 80 年代后主持歼-10 关键设计攻关；1998 年歼-10 首飞；2003 年相关型号完成设计定型；2003 年当选中国工程院院士。[^song-ysg]

# 时代难题

第三代战斗机不是简单提升速度，而是气动布局、飞控、航电、武器、发动机和制造能力的综合升级。中国在较长时期内面临装备代差和关键系统基础薄弱的问题。歼-10 的难题，是在有限条件下形成一型真正按中国需求设计的现代战斗机。

# 突破过程

宋文骢主持总体设计，必须在气动布局、结构重量、操纵品质、动力匹配和系统集成之间反复平衡。院士馆资料和相关报道都把他的工作与歼-10 研制相联系。[^song-ysg][^song-report] 这种突破不是一次性“选型”，而是长期方案论证、试验验证、风险控制和试飞改进。

# 与世界先进水平的比较

歼-10 研制时，世界主要航空强国已经形成第三代战斗机体系，电传飞控、先进气动布局和综合航电成为竞争焦点。中国需要跨越的不只是某个零件，而是现代战斗机总体设计方法。宋文骢团队的意义，是使中国在第三代战斗机自主研制上取得关键突破；保守说是补上体系短板，而不是把所有指标写成世界第一。[^song-report]

# 关键成果与影响

歼-10 的影响在于改变中国战斗机研制格局。它锻炼了总体设计、气动试验、控制律、试飞验证和制造协同队伍，也为后续型号提供经验。宋文骢的贡献，是在高度复杂的系统工程里保持方案主线，使不同专业能围绕同一型飞机协同收敛。[^song-ysg]

# 方法、品格与组织能力

宋文骢的工程方法强调总体权衡。他既要懂技术细节，也要决定哪些指标必须坚持、哪些风险可以逐步化解。飞机设计的难处在于每个子系统都可能影响全局，总设计师的价值正在于把局部最优拉回整机最优。

# 历史评价

宋文骢的历史地位，来自歼-10 对中国航空工业的节点意义。它标志着中国现代战斗机自主设计能力的一次重要跃升。对他的评价应放在团队、试验体系和国家航空工业积累中理解，既承认总设计师的关键判断，也避免把大型型号工程简化为个人传奇。
