# 摘要

徐滨士是装备维修工程、表面工程和再制造工程专家，中国工程院院士。其“中国脊梁”意义，在于把装备维修从“坏了再修”的经验活动，推进为延寿、节材、节能和循环利用相结合的工程体系。[^xu-ysg]

# 时代难题

工业化不仅要会制造新装备，也要会维护、修复和延长装备寿命。大型机械、车辆、军工装备和工业设备如果只能报废换新，会带来高成本和资源浪费。徐滨士面对的核心问题，是如何把维修变成有理论、有工艺、有质量控制的工程学科。

# 突破过程

徐滨士的突破路径，是从表面工程和维修技术进入再制造工程。表面磨损、腐蚀、疲劳和损伤是装备失效的重要原因；如果能通过检测、修复、强化和再制造恢复甚至提升性能，装备寿命和资源效率都会改变。这一过程把传统修理升级为设计、材料、工艺、检测和评价共同参与的系统工程。

# 与世界先进水平的比较

再制造工程在国际上与循环经济、绿色制造和装备全寿命管理相连。中国需要在大规模装备保有量背景下形成自己的再制造体系。徐滨士的意义，在于推动中国从维修经验积累走向再制造工程学科和产业化方向，缩小与先进制造国家在装备全寿命管理上的差距。

# 关键成果与影响

再制造的影响并不总是体现在一个标志性工程上，而体现在大量装备寿命、成本和资源利用效率中。徐滨士的工作为装备维修工程、表面工程和再制造工程提供了学科框架，也让工业体系更重视“用好已有装备”的能力。

# 方法、品格与组织能力

徐滨士的工程方法强调全寿命周期：装备不是交付后就结束，而是在服役、维修、升级和再利用中持续产生价值。这种思路把材料、制造、检测和管理连接起来，特别适合资源约束和装备规模巨大的国家。

# 历史评价

徐滨士适合放在“中国脊梁”的工业基础能力序列中。他的贡献不如桥梁、高铁那样可见，却支撑了装备体系的耐久性、经济性和资源效率。对制造业大国而言，再制造能力是从“会造”走向“会用、会养、会循环”的关键一步。
