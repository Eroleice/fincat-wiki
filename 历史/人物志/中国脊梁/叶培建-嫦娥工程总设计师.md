# 摘要

叶培建，空间飞行器总体、信息处理专家，中国科学院院士。中国科学院院士信息页记载，他主要从事卫星总体设计和信息处理研究。[^ypj-casad] 航天科技集团资料记载，嫦娥一号发射时，孙家栋任我国探月工程总设计师，叶培建任嫦娥一号卫星总指挥兼总设计师；因此本页标题沿用“嫦娥工程总设计师”的通俗概括，正文按具体任务职责表述。[^ce1-spacechina]

# 时代难题

嫦娥一号以前，中国航天器主要围绕地球运行。探月意味着更远距离、更长链路、更复杂轨道控制和更高自主性。航天科技集团资料称，直到本世纪初，我国所有飞行器都围绕地球转；探月工程让中国航天迈向深空。[^ce1-spacechina]

# 突破过程

2007年10月24日，嫦娥一号由长征三号甲运载火箭发射。航天科技集团资料记载，叶培建作为嫦娥一号卫星总指挥兼总设计师，在发射、太阳翼展开、天线展开和绕月制动等关键节点中承担卫星系统总体责任。[^ce1-spacechina]

嫦娥一号在轨工作17个月，完成多项中国航天器首次，包括进入月球轨道、远程测控通信和传回中国第一张月面图片。[^moon10-spacechina] 这使中国探月从规划论证走向工程现实。

# 与世界先进水平的比较

叶培建参与的探月任务不是从零复制美苏旧路线。嫦娥一号解决的是中国第一次绕月探测的工程闭合；嫦娥三号则把任务推进到软着陆和巡视勘察。航天科技集团资料称，嫦娥三号成功后，中国成为世界上第三个独立自主实施月球软着陆的国家。[^moon10-spacechina]

# 关键成果与影响

叶培建的关键贡献在于空间飞行器总体设计能力的迁移：从卫星总体设计走向月球探测器总体设计。嫦娥一号建立了中国深空探测的第一套工程经验，嫦娥三号进一步验证软着陆、巡视器释放和月面互拍等能力。[^ce1-spacechina][^moon10-spacechina]

# 方法、品格与组织能力

深空探测没有足够现场补救空间，设计阶段就必须把风险前移。叶培建的组织能力体现为把轨道、测控、热控、电源、载荷和地面系统纳入同一任务节奏，并在关键节点保持可判读、可处置的状态。

# 历史评价

叶培建的历史定位，应放在嫦娥工程集体成就之中。他不是整个探月工程的唯一总师；但作为嫦娥一号卫星系统总指挥兼总设计师，并长期参与深空探测任务，他代表了中国空间飞行器总体设计能力从地球轨道走向月球和更远深空的关键一代。

# 相关人物与事件

相关人物包括孙家栋、欧阳自远、龙乐豪等；相关事件包括嫦娥一号发射、嫦娥一号绕月成功、嫦娥三号软着陆、探月工程“绕、落、回”三步走和“人民科学家”国家荣誉称号授予。[^ce1-spacechina][^moon10-spacechina][^national-honor]
