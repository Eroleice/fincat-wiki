# 摘要

陈竺是中国科学院院士、血液学和分子生物学专家。中国科学院院士资料显示，他长期从事血液学、分子生物学和白血病研究。[^chen-cas] 与王振义的临床突破相衔接，陈竺等人推动了急性早幼粒细胞白血病（APL）机制研究和联合治疗体系，使中国在这一疾病的分子分型、药物组合和长期疗效研究中形成国际影响。

# 时代难题

APL临床疗效改善后，新的难题随之出现：为什么维甲酸和砷剂有效，哪些患者最受益，如何降低复发和治疗毒性，如何把个别医院经验转成可推广方案。陈竺所处的位置，是把临床成功继续推进到机制解释、方案优化和国际共同体认可。

# 突破过程

陈竺与上海血液学研究团队围绕PML-RARα等分子异常、维甲酸诱导分化和三氧化二砷作用机制展开研究。相关工作把APL从形态学诊断推进到分子机制和靶向治疗层面。后续国际临床研究证明，维甲酸联合三氧化二砷可在特定APL患者中取得良好疗效，显示这一治疗体系已经进入国际标准化评价。[^chen-nejm]

# 与世界先进水平的比较

APL治疗的国际先进方向，是把疾病理解为由特定分子异常驱动，并用药物直接干预异常蛋白和分化阻滞。陈竺的贡献在于，把中国临床发现与分子机制研究相连接，使治疗不只停留在“经验有效”，而能解释、优化和推广。与世界先进水平相比，这一体系不是单点追赶，而是在APL这一病种上参与塑造国际治疗范式。

# 关键成果与影响

陈竺推动的研究增强了中国血液学在国际上的可见度，也帮助APL成为精准治疗和转化医学的典型案例。对患者而言，意义在于从高危急症走向可分层、可监测、可长期管理的治疗流程；对医学体系而言，意义在于建立临床医生、基础研究者和多中心试验之间的协同路径。

# 方法、品格与组织能力

陈竺的特点是跨越基础医学、临床医学和医学组织管理。他的工作说明，重大疾病突破需要从病房走向分子机制，再回到治疗方案和制度化推广。这样的组织能力让个别突破转化为稳定体系。

# 历史评价

陈竺不应被简单写成某一药物的“发明者”。他更重要的历史角色，是白血病治疗体系推动者：把王振义等人的临床开拓继续推向机制化、规范化和国际化，使APL成为中国医学参与世界治疗范式建设的代表病种。
