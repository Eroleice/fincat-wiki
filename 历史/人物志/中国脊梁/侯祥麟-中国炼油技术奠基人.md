# 摘要

侯祥麟是石油化工专家，中国科学院院士、中国工程院院士。中国工程院院士馆资料将其列为化工、冶金与材料工程学部院士；中国科学院已故院士资料也列明其石油化工领域身份和重要经历。[^hou-cae][^hou-cas] 他的历史贡献，是在中国石油炼制基础薄弱、外部技术封锁和工业化需求强烈的年代，推动炼油技术从引进依赖走向自主建设。

# 时代难题

现代工业需要汽油、柴油、润滑油和化工原料。新中国早期炼油工业基础薄弱，设备、工艺、催化剂和工程经验都不足。即便找到石油，没有炼制能力，也难以转化为交通、国防和工业体系可用的能源产品。侯祥麟面对的是一条完整产业链的瓶颈。

# 突破过程

侯祥麟长期在石油炼制和石油化工领域工作，参与炼油科研、工程技术和行业组织。中国工程院院士馆资料概括其在石油加工、石油化工技术和工业发展中的贡献。[^hou-cae] 他推动的不是单一装置，而是包括工艺路线、科研队伍、工程放大和行业标准意识在内的技术体系。炼油技术需要在实验、设计、运行和安全之间闭环，任何一端短板都会影响工业化。

# 与世界先进水平的比较

20世纪世界炼油工业已进入催化裂化、加氢、重油加工和高品质油品竞争阶段。中国当时的差距不仅是设备差距，更是工艺、催化剂、运行经验和工程人才差距。侯祥麟等人的贡献，是在长期追赶中建立中国自己的炼油科研和工程能力，使炼油工业逐步接近现代石油化工体系要求。这里应保守表述为“缩小差距、建立自主能力”，不宜写成一次性超越；工程院和中科院资料支持的是其石油化工领域基础性贡献和学术身份。[^hou-cae][^hou-cas]

# 关键成果与影响

侯祥麟参与奠定的炼油技术体系，服务了中国能源供应、交通燃料、润滑油和石油化工原料保障。其影响不只在科研论文，也在炼厂建设、工程队伍培养和行业决策中体现。对国家工业化而言，炼油技术的自主化意味着资源能被转化为可用产品，能源安全有了工程支点。

# 方法、品格与组织能力

侯祥麟的工作特征是工程系统思维：既懂化学和工艺，也重视装置运行、规模放大和产业组织。他的品格体现为长期服务国家能源需求，在复杂工业体系中做基础性、支撑性的工作。

# 历史评价

称侯祥麟为“中国炼油技术奠基人”，重点不是把整个行业归功于一人，而是指出他在炼油科研、工程技术和行业组织中的基础性角色。他所代表的一代工程科学家，把“有没有石油”之后的关键问题推进为“能不能炼好、用好、持续改进”。
