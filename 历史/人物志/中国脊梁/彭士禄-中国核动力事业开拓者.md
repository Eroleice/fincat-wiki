# 摘要

彭士禄是中国工程院院士、核动力与核电站专家，被中国工程院称为中国核动力领域的开拓者之一。他长期参与核潜艇动力、秦山二期核电站和大亚湾核电站前期技术工作，把高度保密、基础薄弱的核动力工程推进到可设计、可建造、可运行的阶段。[^peng-cae] 评价他，重点不在塑造单人神话，而在理解国家在工业基础不足、外部技术封锁和安全需求迫切时，怎样依靠团队组织、工程试验和体系建设完成关键能力补课。

# 人物坐标

- 生卒：1925-2021。
- 领域：核动力、核电站工程。
- 主要身份：中国工程院院士，中国核潜艇第一任总设计师之一，核动力事业重要开拓者。[^peng-cae][^peng-xinhua]
- 主要成果取得年份：1958 年参与核潜艇工程；1970 年中国第一艘核潜艇下水；20 世纪 80 年代后参与秦山二期、大亚湾等核电工程；2017 年获何梁何利基金科学与技术成就奖。[^peng-cae][^peng-xinhua]

# 时代难题

新中国发展核动力，面对的是双重难题：一是海上战略装备需要可靠、紧凑、长期运行的动力系统；二是和平利用核能需要把反应堆、设备制造、工程设计和运行管理接成完整链条。外部可借鉴经验有限，关键技术又不可能直接购买，核潜艇和核电站都必须在试验、制造和安全边界中摸索。[^peng-xinhua]

# 突破过程

彭士禄的突破不是孤立发明，而是把核反应堆理论、设备配套、工程管理和现场问题合在一起推进。他在核潜艇动力研制中承担总体和组织协调工作，强调用计算、试验和工程判断反复校验。转向核电后，他参与秦山二期、大亚湾等项目论证，推动中国从单项设备攻关走向成套核电工程能力。[^peng-cae]

# 与世界先进水平的比较

核潜艇和商用核电在 20 世纪中后期已是少数工业强国掌握的复杂系统。中国的差距不只是反应堆理论，更在材料、控制、制造、质量保证和运行规程。彭士禄参与的路线，使中国在没有完整外部输入的条件下形成自主核动力工程能力；但页面需要保守表述为“关键追赶与自主化突破”，而不是笼统称为全面世界领先。[^peng-xinhua]

# 关键成果与影响

他的影响主要体现在三点：核潜艇动力使中国具备更完整的海上战略装备技术基础；秦山二期等工程推动商用核电自主设计和建造；核动力队伍在这些工程中积累了质量管理、安全文化和跨专业协同经验。[^peng-cae] 这些成果属于大型团队与国家工程体系，彭士禄的价值在于关键技术路线、总体判断和持续组织推进。

# 方法、品格与组织能力

彭士禄常被记住的是“愿做核动力事业拓荒牛”的姿态。更可分析的是他的工程方法：敢担总体责任，但把判断落在试验和数据上；重视年轻队伍和跨部门协作；在保密、压力和资源不足条件下，用清晰目标把专业团队聚成工程共同体。[^peng-xinhua]

# 历史评价

彭士禄的历史位置，在于他连接了国防核动力与民用核电两条路线。核潜艇解决国家安全底座，核电工程提升能源与工业能力。若说他是“中国核动力事业开拓者”，应理解为他在关键节点把科学、工程和组织动员贯通起来，而不是替代整个核工业集体。
