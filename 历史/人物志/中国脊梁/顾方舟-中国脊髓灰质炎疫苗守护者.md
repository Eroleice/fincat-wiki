# 摘要

顾方舟是病毒学家、免疫学家，曾任中国医学科学院院长、北京协和医科大学校长。公众常以“糖丸爷爷”记住他，但更重要的是，他把脊髓灰质炎疫苗从实验室制品推进到可大规模免疫的公共卫生工具。中国政府在2019年授予他“人民科学家”国家荣誉称号。[^gu-order]

# 时代难题

脊髓灰质炎曾给儿童健康造成严重威胁，幸存者可能留下肢体残疾。新中国公共卫生体系起步时，既要面对疫苗技术不足，也要面对幅员辽阔、冷链薄弱和基层接种能力有限等问题。顾方舟承担的任务，不只是“做出疫苗”，还包括让疫苗适合中国儿童、适合农村和边远地区、适合长期计划免疫。

# 突破过程

顾方舟在1950年代后期参与脊灰疫苗攻关，曾赴苏联考察活疫苗生产工艺。回国后，他组织研究协作，推动毒种、生产、检定、临床观察和推广应用的连续工作。1960年，研究组形成首批液体活疫苗；随后又把液体疫苗制成糖丸，使保存和服用更便利。[^gu-qiushi] 糖丸的意义在于把专业制品转化为基层可执行的免疫工具。

# 与世界先进水平的比较

当时国际上已有索尔克灭活疫苗和沙宾口服活疫苗路线，中国的突破不是抢先发明口服疫苗，而是在短时间内完成吸收、验证、本土生产和大规模推广。顾方舟团队面对的是“追赶世界先进疫苗技术”与“建立中国自己的免疫实施体系”两项任务。保守地说，他的贡献是把世界已有疫苗方向转化为中国可持续使用的公共卫生能力，而不是孤立的实验室成果。[^gu-qiushi]

# 关键成果与影响

糖丸疫苗降低了运输和接种门槛，支持了中国儿童脊灰免疫覆盖。2000年，中国确认实现无脊髓灰质炎目标，顾方舟作为代表参加相关确认报告签字仪式。[^gu-qiushi] 这一成就来自疫苗研发、生产供应、计划免疫和基层卫生网络共同作用，顾方舟是其中贯通科研和应用的关键人物。

# 方法、品格与组织能力

顾方舟的能力体现在三个层面：能判断国际技术路线，能组织国内实验和临床验证，能把疫苗设计成适合真实社会条件的剂型。糖丸看似简单，背后是对温度、运输、儿童服用习惯和基层接种流程的系统理解。

# 历史评价

把顾方舟称为“守护者”比单纯称为“发明者”更准确。中国消除脊灰不是一个人的胜利，而是国家公共卫生体系的长期工程；顾方舟的历史贡献，是在关键技术和关键组织环节上，使这项工程真正可执行、可推广、可持续。
