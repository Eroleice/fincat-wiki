# 摘要

屠呦呦是中国药学家、中国中医科学院研究员。她最重要的历史位置，不是把传统知识简单搬进现代医学，而是在疟疾高发、既有药物耐药性加重的背景下，把古代医药线索、化学提取、药效筛选和临床验证接成一条现代研发链。诺贝尔奖委员会将2015年生理学或医学奖的一半授予她，以表彰其发现青蒿素用于治疗疟疾的贡献；中国政府在2019年授予她“共和国勋章”。[^tu-nobel-facts][^tu-order]

# 时代难题

20世纪中后期，疟疾仍是全球重要传染病。热带地区战事、人口流动和药物耐药叠加，使寻找新型抗疟药成为公共卫生和国家任务。屠呦呦团队面对的不是单一实验问题，而是从候选药物筛选、有效成分提取、毒性观察到临床应用的系统难题。青蒿作为传统药物线索已有记载，但能否转化为稳定、可验证、可规模化的现代抗疟药，需要重新证明。

# 突破过程

屠呦呦参与“523”抗疟研究后，组织团队查阅传统医籍和民间经验，并对多种中草药进行实验筛选。关键变化在于，她注意到古籍中对青蒿处理方式的提示，改用低温乙醚提取，避免高温破坏有效成分，从而获得对疟原虫有效的提取物。随后，团队继续分离纯化并推动药效与安全性观察，最终形成以青蒿素为核心的抗疟药物方向。这个过程依赖团队分工、临床协作和多轮验证，不能理解为单人灵感瞬间完成。

# 与世界先进水平的比较

青蒿素的价值在于，它不是对既有喹啉类药物的小修补，而是在耐药压力下打开了新的抗疟治疗路径。WHO在疟疾事实表中仍把以青蒿素为基础的联合疗法列为恶性疟最有效治疗方式之一，并同时提醒局部青蒿素耐药需要持续监测。[^tu-who-malaria] 因此，青蒿素既是中国科研进入世界医学体系的标志，也是全球抗疟体系必须继续维护的公共产品。

# 关键成果与影响

屠呦呦的成果使传统医药线索进入现代药物发现流程，推动了青蒿素及其衍生物在全球抗疟治疗中的应用。2015年诺贝尔奖的授予，表明这一成果已被国际医学共同体评价为影响广泛的原创性发现。[^tu-nobel-release] 对中国科研史而言，它也说明在资源紧张、任务复杂的年代，面向重大疾病的组织化研究可以形成世界级成果。

# 方法、品格与组织能力

屠呦呦的工作方法有三个要点：第一，尊重传统经验但不把经验当结论；第二，抓住工艺条件对有效成分的影响，用实验把线索转成证据；第三，把个人研究置于集体攻关和公共卫生目标中。她的贡献体现的是低调、耐心和可重复验证的科学品格。

# 历史评价

对屠呦呦的评价应避免两种极端：既不能把青蒿素说成脱离现代科学的“古方奇迹”，也不能抹去古代医药知识提供的启发。更准确的说法是，屠呦呦团队在国家需求、传统知识和现代药学之间建立了可验证的桥梁，并以此改变了全球疟疾治疗格局。
