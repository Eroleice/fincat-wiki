# 摘要

吴明珠是中国工程院院士，园艺作物育种专家。中国工程院院士馆资料称，她长期从事甜瓜和西瓜育种，是中国甜瓜育种学科的开创者之一，并组织新疆甜瓜资源调查、整理和利用。[^wu-cae] 她的贡献不是某一个“名瓜”的传奇，而是把资源调查、亲本创制、杂交育种和产区推广连成了甜瓜育种体系。

# 时代难题

新疆瓜类资源丰富，但传统地方品种存在成熟期、产量、抗病性、商品一致性和外运适应性等多重问题。对一个农业大国来说，瓜类育种不是单纯提高口感，也关系到边疆农业、农民收入和特色产业。吴明珠面对的难题，是如何在丰富地方资源中筛选可遗传、可组合、可推广的性状。

# 突破过程

吴明珠长期扎根新疆，深入产区收集和整理甜瓜资源。她将地方品种资源与现代育种方法结合，围绕早熟、优质、抗病、耐贮运等目标选育亲本和组合。中国工程院资料显示，她在甜瓜和西瓜新品种选育、资源利用和人才培养方面贡献突出。[^wu-cae] 这种突破更像一套“种质资源工程”：先把资源摸清，再把资源转化为可持续育种材料。

# 与世界先进水平的比较

世界瓜类育种早已进入杂交优势利用、商品化种子和区域化品种配置阶段。吴明珠的工作价值在于，使中国新疆瓜类资源不再只是地方特产，而成为现代育种可利用的遗传材料。保守地说，她推动中国甜瓜育种从经验选留迈向系统资源调查和目标性状改良；中国工程院资料支持的是“中国甜瓜育种学科的开创者之一”和资源调查贡献，本页不把她写成“世界首创”。[^wu-cae]

# 关键成果与影响

吴明珠团队选育和推广的瓜类品种，服务了新疆及其他地区甜瓜、西瓜生产，也增强了中国瓜类种业的自主材料基础。她的长期工作把“地方优质资源”转化为“可复制的育种能力”，并通过产区示范和人才培养延续影响。

# 方法、品格与组织能力

吴明珠的方法不是坐在实验室等待好材料，而是到产地、到田间、到农户中寻找问题。她的组织能力体现在资源调查、亲本保存、组合鉴定、区域试验和推广应用之间的连续性。农业育种常以十年计，她的贡献也正来自这种长期主义。

# 历史评价

吴明珠代表了中国农业科学中一种容易被低估的力量：把分散在地方经验和自然资源中的潜力，整理成国家种业能力。评价她时，应避免把成果归结为“个人发现某个品种”，而应看到她对瓜类种质资源、育种学科和边疆农业产业的系统性贡献。
