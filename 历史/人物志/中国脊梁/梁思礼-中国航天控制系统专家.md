# 摘要

梁思礼，导弹控制专家，中国科学院院士。中国科学院院士信息页记载，他研制成功具有中国特色的捷联惯导系统，开辟战略导弹“惯导化”道路，并在地地战略导弹和长征二号运载火箭中任型号副总设计师，还曾任航天计算机自动测量与控制系统总设计师。[^lsl-casad]

# 时代难题

导弹和火箭的控制系统是“看不见的骨架”。新中国早期导弹研制既缺资料，也缺仪器和导弹实物；中国科学院文章引述梁思礼回忆，当时除钱学森外，许多人都没有见过导弹和火箭。[^lsl-cas-article] 在这种条件下，控制系统必须一边仿制、一边消化、一边走向自主。

# 突破过程

1959年，中国开始仿制苏联P-2导弹，梁思礼作为控制系统技术负责人之一参与系统仿制和人员培训。1960年11月5日，东风一号试射成功。随后，他参加东风二号及改进型研制，并在1964年东风二号成功后继续推进全惯性制导系统。[^lsl-cas-article]

1966年“两弹结合”飞行试验中，控制系统精度和稳定性直接关系核弹头能否按预定条件实现爆炸。到东风五号阶段，梁思礼推动采用惯性平台-计算机制导技术；1971年9月10日，携带相关装置的东风五号首飞试验取得成功。[^lsl-cas-article]

# 与世界先进水平的比较

与世界先进水平相比，梁思礼面对的最大差距是从无资料到自主制导的跨越。中国科学院文章指出，当时应用集成电路进行导弹控制的只有美军“民兵”导弹，苏联尚未研制成功；梁思礼决定在东风五号上采用惯性平台-计算机制导技术。[^lsl-cas-article] 这不是简单追赶某个指标，而是把中国导弹控制推向更高自主化层级。

# 关键成果与影响

梁思礼的影响集中在控制系统、可靠性和软件工程化。院士信息页称，他是航天可靠性工程学的开创者和软件工程化的倡导者。[^lsl-casad] 中国科学院文章还记载，他提出质量和可靠性要在设计、生产和管理中形成，而不是单靠检验和统计。[^lsl-cas-article] 这些理念为后续长征火箭和载人航天的安全性提供了方法基础。

# 方法、品格与组织能力

梁思礼的工程方法很“硬”：先把问题变成可计算、可测试、可管理的系统，再把经验沉淀为可靠性规则。控制系统不能靠口号冒险，必须在每一次地面试验、飞行试验和故障复盘中收敛风险。

# 历史评价

梁思礼的历史价值，不只在某一型导弹或火箭，而在他推动中国航天把控制、制导、测试和可靠性作为系统工程来处理。他参与的成果属于集体工程，但他在控制系统和可靠性方法上的开拓，使中国航天的“会飞”进一步走向“可控、可靠、可重复”。
