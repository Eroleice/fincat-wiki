# 摘要

李国豪是桥梁工程专家、中国科学院院士，长期从事桥梁结构理论、工程教育和重大桥梁技术研究。把他写入“中国脊梁”，重点不只是某一座桥，而是现代桥梁工程在中国从人才稀缺、理论薄弱，走向学科建设、结构分析和大型桥梁设计咨询能力的过程。[^li-gh-casad]

# 时代难题

桥梁是交通网络跨越江河海湾的关键节点。新中国早期工程人才和现代桥梁技术基础不足，后来随着铁路、公路和城市交通扩展，大跨度桥梁、复杂结构和抗风、抗震、疲劳等问题越来越重要。李国豪面对的是学科、人才和工程方法同时短缺的局面。

# 突破过程

李国豪的贡献主要体现在桥梁结构理论、工程教育和重大工程咨询。桥梁工程不能只靠经验放大尺寸，大跨度结构需要可靠计算、试验、材料、施工控制和长期监测。李国豪一代工程师把现代力学、结构理论和工程实践结合起来，使中国桥梁工程逐步具备自主设计和判断能力。

# 与世界先进水平的比较

与欧美较早发展现代桥梁工程的国家相比，中国早期处于学习和追赶阶段。随着交通基础设施扩展，中国桥梁工程场景迅速复杂化，并在长大桥梁建设中形成自己的工程能力。[^transport-white-paper] 李国豪的意义，在于推动中国桥梁学科和人才体系具备接近世界先进工程实践的基础。

# 关键成果与影响

李国豪的影响不只在具体工程，也在同济大学等工程教育体系和桥梁学科建设中。桥梁工程大师的价值，往往体现在一代学生、一个学科方向和一批工程咨询判断中：它们共同决定国家能否持续建设更复杂、更安全的桥梁。

# 方法、品格与组织能力

李国豪的工程方法强调理论与实际结合。桥梁既是力学问题，也是施工、材料、维护和公共安全问题。把复杂结构问题讲清楚、算清楚、教给下一代工程师，本身就是一种国家能力建设。

# 历史评价

李国豪是中国桥梁工程从引进学习走向自主发展的代表人物之一。他的“脊梁”意义，在于把个人学术造诣转化为学科、人才和工程咨询能力，为后来中国大型桥梁建设提供长期支撑。
