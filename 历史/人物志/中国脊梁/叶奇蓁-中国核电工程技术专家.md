# 摘要

叶奇蓁是中国工程院院士、核电发电专家。中国工程院资料显示，他长期从事核反应堆与核电工程研究，参与中国多项核电工程技术路线、总体设计和方案审定工作。[^ye-cae] 人民网人物报道把他称为中国核能事业“智囊团”成员，特别强调其在商用核电站和秦山核电二期工程中的技术组织作用。[^ye-people] 他的价值不在于单独完成某一座电站，而在于把核电自主化从口号变成工程流程。

# 人物坐标

- 出生：1934 年。
- 领域：核反应堆工程、核电工程。
- 主要身份：中国工程院院士，核电发电专家。[^ye-cae]
- 主要成果取得年份：20 世纪 80 年代参与商用核电工程论证；1986 年前后承担秦山二期工程关键技术组织工作；1997 年当选中国工程院院士。[^ye-cae][^ye-people]

# 时代难题

中国核电早期要解决的不只是“建一座电站”，而是建立可复制的工程体系。反应堆选型、主要设备国产化、工程质量保证、运行安全和国际合作边界，都直接关系到核电能否从单点示范走向规模建设。[^ye-people]

# 突破过程

叶奇蓁的工作重点在总体论证和工程组织。他参与技术路线选择、主要指标确定、可行性研究和总体设计，并在秦山二期等工程中推进自主设计与中外合作的平衡。[^ye-people] 这种突破不像材料或设备那样直观，却决定了核电站能否在安全边界内按系统工程完成。

# 与世界先进水平的比较

20 世纪后期，国际成熟核电技术主要掌握在少数国家和公司手中。中国若长期依靠整套引进，就难以形成自主审查、设计和改进能力。叶奇蓁参与推动的方向，是在吸收国际经验同时保留工程主导权。较准确的比较是：中国在商用核电工程组织、自主设计和国产化配套上逐步缩小差距，而不是一开始就在全部指标上领先。[^ye-cae][^ye-people]

# 关键成果与影响

叶奇蓁的影响体现在核电工程共同语言的建立。核电站是反应堆、汽轮机、控制系统、土建、设备制造和安全监管的集合体，任何一个环节失配都会放大风险。他参与的总体技术工作，帮助中国核电从“能不能建”进入“怎样自主、安全、可持续地建”的阶段。[^ye-people]

# 方法、品格与组织能力

他的能力更接近工程智囊和技术总成者：既能理解堆型和设备细节，也能把专家争论转化为方案、审查和实施路径。核电工程不适合英雄式冒进，叶奇蓁的价值正在于稳健、审慎和重视安全约束。

# 历史评价

叶奇蓁属于中国核电自主化过程中的关键工程专家。与彭士禄偏重核动力开拓、王大中偏重先进堆路线不同，他的历史位置更靠近商用核电工程体系建设。评价他，应把个人贡献放回工程组织和安全制度中。
