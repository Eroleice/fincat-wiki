# 摘要

黄纬禄是自动控制专家，1991年当选为中国科学院院士。中国科学院学部资料记载，他1957年后主持液体战略导弹控制系统试制及改型设计，20世纪70年代后主持研制潜地和地地固体机动战略导弹，突破水下发射、三轴稳定平台在运动基座上的调平与瞄准等系列关键技术。[^hwl-cas]

# 时代难题

中国导弹事业早期从仿制起步，随后外援撤离，控制系统、制导稳定、发动机、试验设施都要自力更生。到潜地导弹阶段，难度又上升一层：导弹要在运动潜艇平台和水下复杂环境中发射，且要服务二次核打击能力建设。公开报道指出，当时既无资料，也无经验可直接借用。[^hwl-mmcs-life]

# 突破过程

黄纬禄先从控制系统入手，负责让导弹“飞得稳，打得准”。中国科学家博物馆报道记载，1960年11月中国自己制造的第一枚导弹“东风一号”发射成功，实现导弹从无到有的突破。[^hwl-mmcs-wing] 潜地导弹阶段，他担任“巨浪一号”总设计师，提出“台、筒、艇”三步发射试验程序，带队反复验证和修正设计。[^hwl-mmcs-life]

# 与世界先进水平的比较

与已拥有成熟潜射导弹体系的国家相比，中国起步晚且缺少外部资料。黄纬禄团队的意义，在于用有限条件实现从液体到固体、从地地到潜地、从控制系统到总体设计的跨越。中国科学家博物馆转载报道称，1982年10月12日第一代固体潜地导弹研制试验成功，标志中国具有自行研制潜地导弹和水下发射战略导弹能力。[^hwl-mmcs-life]

# 关键成果与影响

黄纬禄的关键成果包括液体战略导弹控制系统、固体战略导弹和潜地导弹总体研制。他突破的水下发射、运动基座稳定平台调平瞄准、导弹设计诸元实时计算装订等技术，直接关系到潜射导弹能否从方案走向实战化工程能力。[^hwl-cas]

# 方法、品格与组织能力

黄纬禄强调技术民主和系统协同。相关报道记载，他提出“有问题共同商量、有困难共同克服、有余量共同掌握、有风险共同承担”的“四共同”原则。[^hwl-mmcs-life] 这类原则恰好说明潜射导弹不是一个专业能解决的任务，而是总体、控制、发动机、试验和使用方共同承担风险的工程。

# 历史评价

黄纬禄是中国导弹事业开拓者之一，也是中国潜射导弹能力形成中的关键总设计师。他的历史贡献不只是一型导弹成功，而是把中国导弹工程从早期地面型号推进到更复杂、更隐蔽、更具战略意义的潜地固体导弹体系。
