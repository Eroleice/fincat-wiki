# 摘要

师昌绪是中国科学院院士、中国工程院院士，高温合金专家。中国工程院院士馆资料记载，他长期从事高温合金、合金钢和材料工程研究，曾获 2010 年度国家最高科学技术奖。[^shi-ysg] 高温合金不是普通金属材料，而是航空发动机、燃气轮机和高温装备的关键基础。把师昌绪列入“中国脊梁”，核心在于他帮助中国补上了高端材料这块工业短板。

# 人物坐标

- 生卒：1918-2014。
- 领域：高温合金、金属材料。
- 主要身份：中国科学院院士、中国工程院院士，发展中国家科学院院士。[^shi-ysg]
- 主要成果取得年份：20 世纪 50 年代回国后投入航空材料建设；20 世纪 60 年代起推动中国高温合金体系；2010 年获国家最高科学技术奖。[^shi-ysg]

# 时代难题

航空发动机被称作工业皇冠上的明珠，一个重要原因就是材料极难。涡轮叶片和高温部件要在高温、高压、高转速环境下长期工作，普通钢材和合金难以承受。新中国早期即使能仿制整机，也会因材料不过关而卡在寿命、可靠性和推力上。

# 突破过程

师昌绪回国后，长期围绕高温合金的成分设计、冶炼工艺、热处理和工程应用组织攻关。他的工作不只是发表材料论文，还要让材料进入真实装备，承受试车和服役检验。院士馆资料强调，他在高温合金和合金钢研究中取得多项重要成果，并培养和组织了材料科研队伍。[^shi-ysg]

# 与世界先进水平的比较

高温合金长期由航空工业强国积累形成。中国起步时缺少完整数据库、设备和工艺经验。师昌绪团队的意义，是在关键材料上建立自主研究和工程验证能力，使中国航空发动机材料从依赖外部经验走向体系化追赶。保守说，这是一项缩小核心材料差距的基础性突破，而不是单一材料立刻全面超越世界。[^shi-ysg]

# 关键成果与影响

高温合金的影响常常隐藏在发动机和装备背后。它提高了高温部件的可靠性和寿命，也带动冶金、测试、失效分析和质量控制体系进步。师昌绪还推动材料科学组织建设，使材料研究不再只是实验室配方，而是服务国家重大装备的工程学科。[^shi-ysg]

# 方法、品格与组织能力

师昌绪的特点是把材料科学与国家需求接上。他重视基础机理，也重视工艺稳定和装备使用条件；既能做学术判断，也能组织跨单位攻关。高温合金需要长期积累，他的品格体现在耐心、严谨和对工程可靠性的坚持。

# 历史评价

师昌绪的历史贡献，是为中国航空、能源和高端制造提供材料底座。没有高温合金，许多装备只能停留在设计图上。他作为“中国高温合金奠基人”的意义，正是把一个看不见但极关键的工业基础能力建立起来。
