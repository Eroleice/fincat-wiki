# 摘要

李德仁，摄影测量与遥感专家，中国科学院院士、中国工程院院士。中国工程院院士馆记载其 1939 年 12 月出生，1991 年当选中国科学院院士，1994 年当选中国工程院院士，2023 年获国家最高科学技术奖。[^li-ysg]

把李德仁放入“中国脊梁”系列，重点在于测绘遥感这类“看不见的基础能力”：高精度定位、测图、对地观测和时空信息服务，支撑自然资源、国土空间、城市治理、灾害应急和数字经济。[^li-xinhua]

# 时代难题

现代国家治理离不开准确的空间信息。传统测绘周期长、覆盖有限，而卫星遥感、无人机、北斗和人工智能带来新的可能：如何把多源空间数据变成及时、可靠、可服务行业和公众的信息，是测绘遥感从学术走向国家能力的关键难题。[^li-xinhua]

# 突破过程

新华网访谈称，李德仁是国际著名摄影测量与遥感学家、中国高精度高分辨率对地观测系统的开创者之一；他带领团队攻克卫星遥感全球高精度定位及测图核心技术，解决遥感卫星影像高精度处理系列难题，研发全自动高精度航空与地面测量系统。[^li-xinhua]

近年来，他又把研究推进到“时空智能”：把通信、导航、遥感和人工智能结合起来，使数据获取、处理、信息提取和知识服务更快进入农业、生态保护、城市管理和应急响应场景。[^li-xinhua]

# 与世界先进水平的比较

院士馆页面引用中国教育报评价称，在以李德仁为首的科学家团体努力下，中国测绘科学“稳立世界三强”。[^li-ysg] 这里应理解为团队和学科体系的整体跃升，而不是单人完成的排名。

# 关键成果与影响

李德仁的成果集中在高精度遥感影像处理、对地观测体系建设和时空智能应用。新华社报道还提到，2023 至 2024 年，武汉大学团队自主研制的多颗“珞珈”系列卫星发射入轨，并推进“东方慧眼”智能遥感星座建设设想。[^li-xinhua]

# 方法、品格与组织能力

他的研究路径强调“读书、思维、创新、实践”，把理论算法、测绘工程、卫星平台和应用场景连起来。测绘遥感不是孤立论文成果，只有进入自然资源、农业、环保和城市运行系统，才会变成国家可使用的能力。

# 历史评价

李德仁的历史位置，是把中国测绘遥感从传统测图能力推进到高精度对地观测和时空智能服务。他的贡献体现了基础算法、工程系统和应用牵引之间的长期耦合。
