# 摘要

黄伯云是中国工程院院士、粉末冶金专家，长期在中南大学从事高性能材料研究。中国工程院院士馆资料列明，其重要成果包括高性能炭/炭航空制动材料，并记载他曾获 2004 年度国家技术发明奖一等奖。[^huang-ysg] 这类材料面向飞机刹车等极端工况，关系到高温摩擦、热冲击、重量控制和可靠性。评价黄伯云，应看到材料从实验室样品到航空产品之间漫长的工程化距离。

# 人物坐标

- 出生：1945 年。
- 领域：粉末冶金、炭/炭复合材料、航空制动材料。
- 主要身份：中国工程院院士，发展中国家科学院院士。[^huang-ysg]
- 主要成果取得年份：20 世纪 80 年代后持续攻关高性能炭/炭材料；2004 年相关成果获国家技术发明奖一等奖；2011 年当选发展中国家科学院院士。[^huang-ysg][^huang-report]

# 时代难题

航空制动材料要在短时间内吸收巨大动能，并承受高温、磨损和热冲击。中国若缺少自主材料，就会在飞机设计、维护成本和关键备件保障上受制于人。炭/炭复合材料难点不只是“烧出一种材料”，还包括纤维预制体、致密化、摩擦性能稳定和批量质量控制。

# 突破过程

黄伯云团队的工作跨越粉末冶金、复合材料、工艺装备和性能评价。他们将材料微结构控制、制备工艺和应用试验结合起来，推动炭/炭航空制动材料进入工程应用。院士馆报道把他的长期工作与“大飞机减重”和关键材料自主化联系起来。[^huang-report]

# 与世界先进水平的比较

高性能航空制动材料长期是航空工业强国的关键技术。黄伯云的成果使中国在这一材料方向形成自主技术体系，并获得国家技术发明奖一等奖的确认。保守表述为：中国在特定航空制动材料上实现重要自主突破，缩小并部分跨越了受制于人的差距；不宜扩展为所有航空材料全面领先。[^huang-ysg][^huang-report]

# 关键成果与影响

炭/炭制动材料的影响体现在飞机安全、重量、维修和保障体系上。它也带动中南大学粉末冶金和复合材料方向的发展，形成从基础研究、工艺装备到工程验证的团队能力。国家技术发明奖一等奖说明该成果兼具原创性和应用价值。[^huang-ysg]

# 方法、品格与组织能力

黄伯云的典型方法是长期围绕一个关键材料问题持续迭代。材料工程常常失败在稳定性和重复性，他的团队必须在一次次试验、检测和应用反馈中寻找工艺窗口。这种组织能力，正是把科学发现变成产业能力的关键。

# 历史评价

黄伯云的历史位置，在于让中国高性能炭/炭航空制动材料从“想做”走向“能做、能用、能获国家确认”。他不是单独解决航空工业全部瓶颈的人，但在关键材料自主化上提供了重要支点。
