# 基本原则
金融喵Wiki允许在内容创作、修订和维护过程中使用AI工具，但AI仅作为辅助工具，不是可靠来源，也不是最终责任主体。

AI参与不改变本站既有的内容要求。页面中的事实、数据、法律规则、政策口径、医学或安全建议等内容，仍须符合【[可靠来源](/规范/内容规范/可靠来源)】和【[列明来源](/规范/内容规范/列明来源)】的要求。本站内容仍适用【[免责声明](/规范/声明/免责声明)】和【[许可协议条款](/规范/版权/许可协议条款)】。

# 使用范围
AI工具可以用于以下辅助性工作：

1. 生成条目提纲、写作草稿或修订建议；
2. 对已有文本进行改写、压缩、扩写、翻译或格式整理；
3. 根据用户提供的材料整理摘要、表格、清单或时间线；
4. 检查Markdown格式、脚注编号、链接路径、表格和图片语法；
5. 辅助生成示意图、流程图、代码片段或说明性素材。

AI工具不得用于以下行为：

1. 编造事实、数据、来源、法规、司法案例、学术文献、文件编号或发布日期；
2. 将AI输出作为事实来源引用；
3. 在未核验原始资料的情况下，直接发布AI对资料的总结；
4. 生成冒充特定自然人、机构或专业人士观点的内容；
5. 绕过本站版权、隐私、署名、来源和免责声明相关要求。

# 来源核验
AI输出不能证明页面内容真实。凡页面包含可验证事实，应当回到原始资料、权威资料或其他可靠来源进行核验。

对于AI给出的来源线索，贡献者应当逐项核对：

1. 来源是否真实存在；
2. 作者、发布机构、标题、发布日期、访问路径是否准确；
3. 来源内容是否能够直接支撑页面中的具体表述；
4. 来源是否符合本站对可靠来源的要求；
5. 引用格式是否足以让读者自行查阅。

如果AI输出与可靠来源不一致，应以可靠来源为准；如果不同可靠来源之间存在冲突，应在页面中说明冲突及各自依据，而不是用AI生成的折中表述掩盖差异。

# 强披露规则
凡AI实质参与页面草拟、改写、汇总、翻译、资料整理、图表生成或代码生成的，应当在页面末尾加入“AI辅助说明”。

页面仅使用AI进行拼写检查、简单Markdown格式修复，且不改变实质内容的，可以不单独披露；但如果无法判断是否属于实质参与，应当披露。

已经完成必要人工核验的页面使用以下格式：

```markdown
# AI辅助说明

> 本页曾使用 AI 工具辅助创作或修订。
>
> - AI工具/模型：
> - 参与方式：
> - 人工核验：
> - 最后核验日期：
{.is-info}
```

尚未完成人工核验的页面使用以下格式：

```markdown
# AI辅助说明

> 本页曾使用 AI 工具辅助创作或修订。
>
> - AI工具/模型：
> - 参与方式：
> - 人工核验：未完成
> - 最后核验日期：
{.is-warning}
```

披露信息应尽量具体。AI工具/模型可以填写工具或模型名称；参与方式可以填写“提纲生成”“初稿草拟”“段落改写”“来源摘要”“表格整理”“Markdown格式修订”等；人工核验可以填写核验者、核验范围或“未完成”。

# 高风险内容
涉及金融、证券、法律、税务、会计、医疗、育儿安全、政策法规、工程安全等高风险内容时，AI只能作为辅助工具。页面发布前应当特别检查：

1. 关键结论是否有可靠来源支撑；
2. 法规、规则、标准、政策、税率、费用、阈值、日期等是否为最新或明确适用的版本；
3. 页面是否容易被读者误认为具体建议；
4. 是否需要补充适用范围、例外情况、风险提示或免责声明；
5. “AI辅助说明”是否标注人工核验状态和最后核验日期。

高风险页面若尚未完成核验，应使用 `{.is-warning}` 的AI辅助说明，或在相关段落中另行提示核验状态。

# 版权与隐私
使用AI工具时，不得向工具输入或通过本站发布不应公开的信息，包括但不限于个人身份信息、联系方式、账户信息、未公开商业信息、未授权合同或文件、受保密义务约束的资料。

不得要求AI复制、改写或规避版权限制生成长篇受版权保护文本。引用第三方内容时，仍应遵守本站许可、合理引用和署名规则。

AI生成或辅助生成的图片、表格、代码、图示、摘要等内容，应在必要时说明来源或生成方式。若素材包含第三方权利或可能影响读者判断，应当在页面中保留相应说明。
